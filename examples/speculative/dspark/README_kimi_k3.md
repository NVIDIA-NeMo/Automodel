# Training a Kimi K3 DSpark drafter

This recipe trains a dense Kimi K3 MLA drafter against the frozen text model
introduced by PR #3259. The draft preserves the target's MLA projections,
output gate, RMSNorm, and SiTU MLP. KDA, routed experts, shared experts, and the
attention-residual mixer stay in the target only.

## Hardware

The target has 896 routed experts. `pp_size` must remain 1 because online
hidden-state capture hooks one complete target forward. Use expert parallelism
to shard the target and choose an `ep_size` that divides 896. The provided
configuration uses 64 ranks across eight 8-GPU nodes.

For every multi-node run, set `NCCL_IB_DISABLE=1` and
`NCCL_SOCKET_IFNAME=eth0` on every node. Set `NCCL_DEBUG=INFO` for the first
smoke and confirm that NCCL reports `NET/Socket : Using [0]eth0`.

## Data and paths

The example uses the cluster's pipeline-smoke PerfectBlend data. Its responses
were generated by Llama 3.1 8B, so regenerate responses with Kimi K3 before a
quality run. Keep the model, caches, checkpoints, logs, and W&B files under
`/llm-align/liuchonghan/`.

The default model location is
`/llm-align/liuchonghan/models/Kimi-K3`. Download the checkpoint directly on
the server with `hf`; do not copy it from a local machine.

## Launch

Run the same command on every node and vary only `--node-rank`. Node 0 provides
the rendezvous address. The recipe fixes `ep_size=64`, so the launch uses eight
nodes with eight processes per node.

Set these environment variables on every node before launching:

```bash
export HF_HOME=/llm-align/liuchonghan/hf_cache PIP_CACHE_DIR=/llm-align/liuchonghan/pip_cache UV_CACHE_DIR=/llm-align/liuchonghan/uv_cache WANDB_DIR=/llm-align/liuchonghan/runs/kimi-k3-dspark/wandb TRANSFORMERS_CACHE=/llm-align/liuchonghan/hf_cache NCCL_IB_DISABLE=1 NCCL_SOCKET_IFNAME=eth0 NCCL_DEBUG=INFO
```

Launch one command per node:

```bash
torchrun --nnodes=8 --node-rank=<RANK> --nproc_per_node=8 --master-addr=<NODE0_IP> --master-port=29500 -m nemo_automodel.recipes.llm.train_dspark -c examples/speculative/dspark/kimi_k3_dspark.yaml
```
