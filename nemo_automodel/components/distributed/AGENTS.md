## Correctness bar

Distributed bugs here are silent: the job runs, the loss looks reasonable, and
the model is wrong. Treat changes to loss normalization, gradient accumulation,
reduction scope, or collective ordering as correctness changes requiring
evidence, not refactors.

- **Rank symmetry.** Every rank must enter compatible collectives on every path;
  an asymmetric branch deadlocks rather than failing fast.
- **Reduction domains.** Reduce a gradient over exactly the mesh dimensions
  across which its parameter is replicated.
- **Exactly-once.** Missing and duplicated reductions both scale gradients
  incorrectly.
- **Dtype agreement.** Every contribution to one reduction must share a dtype;
  zero-fills for unused parameters are a common mismatch source.
- **Async lifetime.** Own each `Work`/event and wait before reading its result or
  reusing its buffer.

## Testing

A single-process loop over simulated ranks proves nothing about collectives.
Use a real multi-process functional test, compare per-parameter gradients with
a reference topology, and respect the 2-GPU PR functional-test cap (see
`tests/AGENTS.md`). Cover the changed topology plus one supported composition.

## Imports and TP plans

Never import a concrete model class at module scope from either
`transformers.models.<arch>.modeling_<arch>` or
`nemo_automodel.components.models.<arch>.model`. Hot-path modules such as
`parallelizer.py` and `optimized_tp_plans.py` otherwise eagerly import the model
zoo. One modeling import measured +2.24 s, and removing the cascade reduced the
parallelizer import from 7.40 s to 4.12 s (local Python 3.10 / PyTorch 2.10).

Use the narrowest alternative:

- Registry keys: use a literal qualname generated by `_get_class_qualname`, not
  the class object.
- Type annotations: import under `TYPE_CHECKING` and enable postponed
  annotations.
- Runtime class access: import inside the function.

Measure import cost with:

```bash
python -X importtime -c "import nemo_automodel.components.distributed.parallelizer"
python -c "import nemo_automodel.components.distributed.parallelizer"
```

If changing `PARALLELIZE_FUNCTIONS` or `_get_model_layer_group_specs`, serialize
the mapping before and after and require byte-identical output. A model missing
from `PARALLELIZE_FUNCTIONS` can silently use a generic plan that leaves modules
replicated and later causes OOM at `tp_size > 1`; check the plan before tuning
memory knobs.
