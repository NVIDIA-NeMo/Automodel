GigaSpeech provides English speech and transcripts. The AutoModel mixture selects the small configuration. The source is hosted as [speechcolab/gigaspeech](https://huggingface.co/datasets/speechcolab/gigaspeech).

## Task

**English speech recognition.** The example uses the s configuration. The waveform is omitted from the illustrative record.

| Property | Description |
| --- | --- |
| Input | A segment of speech audio. |
| Target | The corresponding transcript. |
| Modality | Audio and text |
| Language | en |
| License Metadata | apache-2.0 |

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. Media paths, when shown, stand in for binary image or audio data and do not refer to downloadable files.

```json
{
  "audio": {
    "path": "synthetic-speech.wav",
    "bytes": null
  },
  "text": "THE MEETING BEGINS AT NINE"
}
```

## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| Mixed-Corpus Speech Fine-Tuning | Qwen2.5-Omni 3B; six English sources | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/audio_finetune/qwen2_5_omni_asr/multi_en_sft_3b.yaml) |

**Adapter:** [`make_multi_en_asr_dataset`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/audio/multi_en.py).

The mixture maps `text` to `text`, adds a source label, normalizes transcripts to uppercase, removes punctuation except apostrophes, and decodes audio lazily at 16,000 Hz. The mixture enables `trust_remote_code` for this source; use a datasets version compatible with that source loader. The recipe uses AMI, Earnings22, VoxPopuli, GigaSpeech, SPGISpeech, and LibriSpeech together. Override `dataset.sources` to change the mixture.

The mixture uses `s` / `train` from this source. The recipe does not configure a validation dataset; duration and empty-text filtering can reduce the loaded count.
