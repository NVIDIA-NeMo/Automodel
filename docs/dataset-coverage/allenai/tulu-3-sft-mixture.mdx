Tulu 3 combines instruction and conversation data. The source is hosted as [allenai/tulu-3-sft-mixture](https://huggingface.co/datasets/allenai/tulu-3-sft-mixture).

## Task

**Instruction following and conversation.**

| Property | Description |
| --- | --- |
| Input | A user instruction and any preceding conversation. |
| Target | The assistant response or subsequent assistant turns. |
| Modality | Text |
| Language | Multilingual; see upstream language list |
| License Metadata | odc-by |

The publisher labels the collection ODC-BY and notes that individual components have different terms, including non-commercial components. See the pinned upstream card for the source-level terms.

## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| Chat Fine-Tuning | Qwen3-4B; FSDP2; 8 GPUs | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/convergence/tulu3/models/qwen3-4b/qwen3_4b_cp1_flashoptim.yaml) |
| Joint Drafter Training | Gemma 4 4B; Tulu 3/Magicoder mixture | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/vlm_finetune/gemma4_joint_drafter/gemma4_4b_joint_drafter_tulu_magicoder_mix.yaml) |

**Adapter:** [`ChatDataset`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/llm/chat_dataset.py).

The chat loader renders messages with the selected tokenizer and chat template. The Qwen example sets `truncation: false`; follow its [preparation instructions](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/convergence/tulu3/models/qwen3-4b/README.md) to filter sequences for the intended length. The joint-drafter loader samples Tulu 3 and Magicoder with probabilities 0.8 and 0.2, drops Tulu conversations longer than 16 turns, and interleaves until both sources are exhausted. Sampling probabilities do not specify exact final row proportions.

The Qwen example evaluates `train[:128]` while training on `train`, so these validation rows overlap training. The joint-drafter validation mixture also reuses training sources. Use a separate holdout for an independent evaluation.
