SPGISpeech supplies audio and transcripts from public earnings calls. The NeMo AutoModel mixture selects configuration `S`. The source is hosted as [kensho/spgispeech](https://huggingface.co/datasets/kensho/spgispeech).

## Task

**English speech recognition.** The example uses the `S` configuration. The waveform is omitted from the illustrative record.

| Property | Description |
| --- | --- |
| Input | A segment of speech audio. |
| Target | The corresponding transcript. |
| Modality | Audio and text |
| Language | English (`en`) |
| License Metadata | `other`; custom [Kensho Terms of Usage](https://huggingface.co/datasets/kensho/spgispeech/blob/14e69dd3b80e968282ca55d3eb2b39cc9db2b62e/README.md). |

Access is gated. Before running the recipe, accept the dataset's terms on its [Hub page](https://huggingface.co/datasets/kensho/spgispeech) and authenticate with a Hugging Face account that has access.

## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| Mixed-Corpus Speech Fine-Tuning | Qwen2.5-Omni 3B; six English sources | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/audio_finetune/qwen2_5_omni_asr/multi_en_sft_3b.yaml) |

**Adapter:** [`make_multi_en_asr_dataset`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/audio/multi_en.py).

The mixture maps `transcript` to `text`, adds a `source` label, normalizes transcripts to uppercase, removes punctuation except apostrophes, and decodes audio lazily at 16,000 Hz. The recipe uses AMI, Earnings22, VoxPopuli, GigaSpeech, SPGISpeech, and LibriSpeech together. Override `dataset.sources` to change the mixture.

The mixture uses the `train` split of configuration `S` from this source. The recipe does not configure a validation dataset. It keeps audio clips from 1 to 30 seconds and removes empty transcripts after normalization, so the loaded count can be lower than the Hub count.
