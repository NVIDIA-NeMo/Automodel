Shopify Product Catalogue contains product images and taxonomy labels. The source is hosted as [Shopify/product-catalogue](https://huggingface.co/datasets/Shopify/product-catalogue).

## Task

**Product taxonomy classification.** Additional fields include descriptions, candidate categories, brand, and secondhand status. The AutoModel adapter uses the image to predict the category.

| Property | Description |
| --- | --- |
| Input | A product image, with additional catalog attributes available in the source. |
| Target | A category from the product taxonomy. |
| Modality | Image and text |
| Language | Not declared in Hub metadata |
| License Metadata | apache-2.0 |

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. Media paths, when shown, stand in for binary image or audio data and do not refer to downloadable files.

```json
{
  "product_title": "Ceramic tea mug",
  "product_image": {
    "path": "synthetic-mug.png",
    "bytes": null
  },
  "ground_truth_category": "Home & Garden > Kitchen & Dining > Tableware > Drinkware > Mugs"
}
```

## Schema and Splits

The table describes the task-bearing fields in the example. The source may also include identifiers and other metadata.

| Field | Type | Meaning |
| --- | --- | --- |
| `product_title` | string | Product title. |
| `product_image` | image | Product photo. |
| `ground_truth_category` | string | Reference taxonomy category. |

These are upstream splits or source files, before any AutoModel sampling or preprocessing.

| Configuration | Split or Source | Rows |
| --- | --- | --- |
| `default` | `train` | 38,631 |
| `default` | `test` | 9,658 |

Counts come from [upstream metadata at the linked revision](https://huggingface.co/datasets/Shopify/product-catalogue/blob/002ca15536bb015ebc47b99cc2d716d7040bb09e/README.md) before local filtering. A dash means this page does not assert a count for that source.

**Adapter:** [`make_shopify_product_catalogue_dataset`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/vlm/datasets.py).

The loader uses the image and a fixed classification prompt, then supervises the `ground_truth_category` text. Other catalog fields are not included in this prompt. Images stay undecoded until data access; bound image-token growth through the recipe processor or collator.

The full example trains on `train` and evaluates at most 500 rows of upstream `test`. The LoRA example limits training to 2,000 rows and evaluation to 200. Here, the test split is used during training as validation.
