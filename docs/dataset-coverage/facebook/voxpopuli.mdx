VoxPopuli provides speech from European Parliament recordings. The AutoModel mixture selects its English configuration. The source is hosted as [facebook/voxpopuli](https://huggingface.co/datasets/facebook/voxpopuli).

## Task

**Parliamentary speech recognition.** Transcribe a speech segment into text. The example uses the English (`en`) configuration.

| Property | Description |
| --- | --- |
| Input | A segment of speech audio. |
| Target | The corresponding transcript. |
| Modality | Audio and text |
| Language | Multilingual source; English (`en`) in this recipe |
| License Metadata | `cc0-1.0`, `other`; see the [upstream licensing information](https://huggingface.co/datasets/facebook/voxpopuli/blob/42f01879c780b4a2e90ec0b4f616c2ece526e4f1/README.md#licensing-information), which also links the raw-data terms. |

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. The `audio` object shows an undecoded path-and-bytes representation with the waveform omitted. Its path is a placeholder, not a downloadable file.

```json
{
  "audio": {
    "path": "synthetic-speech.wav",
    "bytes": null
  },
  "normalized_text": "the meeting begins at nine."
}
```

## Schema and Splits

The table describes the task-bearing fields in the example. The source may also include identifiers and other metadata.

| Field | Type | Meaning |
| --- | --- | --- |
| `audio` | `Audio` | A speech segment sampled at 16,000 Hz; shown undecoded in the example. |
| `normalized_text` | string | Normalized transcript for the audio segment; distinct from the source's `raw_text` field. |

The table shows the `en` Hub configuration. Other configurations, when available, are listed on the [Hub dataset page](https://huggingface.co/datasets/facebook/voxpopuli).

| Configuration | Split or Source | Rows |
| --- | --- | --- |
| `en` | `train` | 182,482 |
| `en` | `validation` | 1,753 |
| `en` | `test` | 1,842 |

Counts come from [upstream metadata at the linked revision](https://huggingface.co/datasets/facebook/voxpopuli/blob/42f01879c780b4a2e90ec0b4f616c2ece526e4f1/README.md) before local filtering.

## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| Mixed-Corpus Speech Fine-Tuning | Qwen2.5-Omni 3B; six English sources | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/audio_finetune/qwen2_5_omni_asr/multi_en_sft_3b.yaml) |

**Adapter:** [`make_multi_en_asr_dataset`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/audio/multi_en.py).

The mixture maps `normalized_text` to `text`, adds a source label, normalizes transcripts to uppercase, removes punctuation except apostrophes, and decodes audio lazily at 16,000 Hz. The loader takes at most 4,000 English training rows before later filtering. The recipe uses AMI, Earnings22, VoxPopuli, GigaSpeech, SPGISpeech, and LibriSpeech together. Override `dataset.sources` to change the mixture.

The mixture uses the `train` split of the `en` configuration from this source. The recipe does not configure a validation dataset; duration and empty-text filtering can reduce the loaded count.
