LibriSpeech provides English speech read from LibriVox audiobooks for automatic speech recognition (ASR). The AutoModel mixture selects the clean 100-hour training split. The source is hosted as [openslr/librispeech_asr](https://huggingface.co/datasets/openslr/librispeech_asr).

## Task

**Read-speech recognition.** Transcribe an audio segment into written text. The example uses the `clean` configuration.

| Property | Description |
| --- | --- |
| Input | A segment of speech audio. |
| Target | The corresponding transcript. |
| Modality | Audio and text |
| Language | English (`en`) |
| License Metadata | `cc-by-4.0` |

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. The `audio` object illustrates the encoded representation before decoding, with audio bytes omitted. The placeholder path does not refer to a downloadable file.

```json
{
  "audio": {
    "path": "synthetic-speech.wav",
    "bytes": null
  },
  "text": "THE MEETING BEGINS AT NINE"
}
```

## Schema and Splits

The source schema includes the audio and transcript shown in the example, plus file and identifier fields.

| Field | Type | Meaning |
| --- | --- | --- |
| `audio` | audio | Audio segment with a sampling rate of 16,000 Hz; decoding yields a waveform. |
| `text` | string | Transcript for the audio segment. |
| `file` | string | Path to the audio file. |
| `speaker_id` | int64 | Speaker identifier. |
| `chapter_id` | int64 | Audiobook chapter identifier. |
| `id` | string | Sample identifier. |

The table shows the `clean` Hub configuration used by the recipe. The upstream metadata also lists `other` and `all`; `all` is the Hub default configuration.

| Configuration | Split or Source | Rows |
| --- | --- | --- |
| `clean` | `train.100` | 28,539 |
| `clean` | `train.360` | 104,014 |
| `clean` | `validation` | 2,703 |
| `clean` | `test` | 2,620 |

Counts come from [upstream metadata at the linked revision](https://huggingface.co/datasets/openslr/librispeech_asr/blob/71cacbfb7e2354c4226d01e70d77d5fca3d04ba1/README.md) before local filtering.

## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| Mixed-Corpus Speech Fine-Tuning | Qwen2.5-Omni 3B; six English sources | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/audio_finetune/qwen2_5_omni_asr/multi_en_sft_3b.yaml) |

**Adapter:** [`make_multi_en_asr_dataset`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/audio/multi_en.py).

The mixture retains the `text` field, adds a `source` label, normalizes transcripts to uppercase, removes punctuation except apostrophes, and decodes and resamples audio lazily to 16,000 Hz. The recipe uses AMI, Earnings22, VoxPopuli, GigaSpeech, SPGISpeech, and LibriSpeech together. Override `dataset.sources` to change the mixture.

The mixture uses the `train.100` split of the `clean` configuration from this source. The recipe does not configure a validation dataset. It keeps clips between 1 and 30 seconds, inclusive, and removes empty transcripts after normalization, which can reduce the loaded count.
