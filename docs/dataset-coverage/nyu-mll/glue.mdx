The General Language Understanding Evaluation (GLUE) benchmark groups natural language understanding datasets. This card covers the Microsoft Research Paraphrase Corpus (MRPC), a sentence-pair paraphrase classification task. The source is hosted as [nyu-mll/glue](https://huggingface.co/datasets/nyu-mll/glue).

## Task

**Natural language understanding.** GLUE is a collection of classification, entailment, paraphrase, and similarity tasks. The record and field table below use `mrpc`, the subset used by the AutoModel example.

| Property | Description |
| --- | --- |
| Input | Sentence pairs for the MRPC paraphrase task illustrated here. |
| Target | A binary equivalence label for MRPC. |
| Modality | Text |
| Language | English |
| License Metadata | `other`; the [upstream card](https://huggingface.co/datasets/nyu-mll/glue/blob/bcdcba79d07bc864c1c254ccfcedcce55bcc9a8c/README.md) refers readers to each source dataset's original license. |

## Example Record

This **synthetic example** uses invented values in the MRPC source fields; it is not a copied dataset row.

```json
{
  "sentence1": "The train arrived at noon.",
  "sentence2": "At midday, the train reached the station.",
  "label": 1,
  "idx": 0
}
```

## Schema and Splits

The table describes the four fields in the upstream `mrpc` schema.

| Field | Type | Meaning |
| --- | --- | --- |
| `sentence1` | string | First sentence in the pair. |
| `sentence2` | string | Second sentence in the pair. |
| `label` | class label | `0` is `not_equivalent`; `1` is `equivalent`. |
| `idx` | int32 | Example index. |

The table shows `mrpc`, the configuration illustrated on this page. GLUE also provides other task configurations on the [Hub dataset page](https://huggingface.co/datasets/nyu-mll/glue).

| Configuration | Split or Source | Rows |
| --- | --- | --- |
| `mrpc` | `train` | 3,668 |
| `mrpc` | `validation` | 408 |
| `mrpc` | `test` | 1,725 |

Counts come from [upstream metadata at the linked revision](https://huggingface.co/datasets/nyu-mll/glue/blob/bcdcba79d07bc864c1c254ccfcedcce55bcc9a8c/README.md) before local filtering.

## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| Sequence Classification | RoBERTa-large LoRA; MRPC | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/llm_seq_cls/glue/mrpc_roberta_lora.yaml) |

**Adapter:** [`GLUE_MRPC`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/llm/seq_cls.py).

The loader calls `load_dataset("glue", "mrpc", ...)`, using the legacy Hub alias for `nyu-mll/glue`. It tokenizes both sentences together and returns a classification label. The example covers MRPC; it does not establish recipe coverage for every GLUE task.

The example uses MRPC `train` and `validation`. The upstream test split is included for reference.
