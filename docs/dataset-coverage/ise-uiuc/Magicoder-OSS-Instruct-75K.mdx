## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| Joint Drafter Training | Gemma 4 4B; Tulu 3 and Magicoder mixture | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/vlm_finetune/gemma4_joint_drafter/gemma4_4b_joint_drafter_tulu_magicoder_mix.yaml) |

**Adapter:** [`make_tulu3_magicoder_text_mix_dataset`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/vlm/datasets.py).

The loader turns each nonempty problem and solution into user and assistant turns. It interleaves Tulu 3 and Magicoder with sampling probabilities 0.8 and 0.2 and `stopping_strategy="all_exhausted"`. The recipe trains on both sources; it is not a Magicoder-only run.

The recipe reads `train` from both sources. Validation builds another mixture from the same training splits with a different seed and a 200-row cap, so it is not a disjoint holdout.
