FineWeb provides web text for language model pretraining. The source is hosted as [HuggingFaceFW/fineweb](https://huggingface.co/datasets/HuggingFaceFW/fineweb).

## Task

**Causal language modeling.** The record shows raw Hub fields before any tokenizer-specific preprocessing.

| Property | Description |
| --- | --- |
| Input | The preceding tokens in a web document. |
| Target | The next token; source rows contain documents rather than instruction/answer pairs. |
| Modality | Text |
| Language | en |
| License Metadata | odc-by |

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. Media paths, when shown, stand in for binary image or audio data and do not refer to downloadable files.

```json
{
  "text": "A bicycle uses gears to trade pedaling force for speed.",
  "url": "https://example.org/synthetic-article",
  "language": "en"
}
```

## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| Pretraining | GPT-2-style model; nanoGPT binary shards | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/llm_pretrain/nanogpt_pretrain.yaml) |

**Adapter:** [`NanogptDataset`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/llm/nanogpt_dataset.py).

The example expects modded-nanoGPT shards at `modded-nanogpt/data/fineweb_10BT_max_500M/fineweb_train_*.bin`. Prepare compatible shards first, or update `dataset.file_pattern`. The model vocabulary and special-token IDs must match the tokenizer used for preprocessing. `NanogptDataset` does not accept raw Hub Parquet files or Megatron `.bin/.idx` pairs.

The example reads local files matching `fineweb_train_*.bin`. It does not select a Hub split at runtime or configure validation data.
