The rdr-items dataset provides image/text pairs used by several. The source is hosted as [quintend/rdr-items](https://huggingface.co/datasets/quintend/rdr-items).

## Task

**Image-to-text generation.** The Hub exposes image/text pairs without a detailed prose dataset card. This page describes those fields and the example-backed image-to-text use without inferring additional collection details.

| Property | Description |
| --- | --- |
| Input | An image. |
| Target | The paired text description. |
| Modality | Image and text |
| Language | Not declared in Hub metadata |
| License Metadata | Not declared in Hub metadata; consult the upstream source |

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. Media paths, when shown, stand in for binary image or audio data and do not refer to downloadable files.

```json
{
  "image": {
    "path": "synthetic-item.png",
    "bytes": null
  },
  "text": "A brown leather satchel with a shoulder strap."
}
```

## Schema and Splits

The table describes the task-bearing fields in the example. The source may also include identifiers and other metadata.

| Field | Type | Meaning |
| --- | --- | --- |
| `image` | image | Visual input. |
| `text` | string | Text paired with the image. |

These are upstream splits or source files, before any AutoModel sampling or preprocessing.

| Configuration | Split or Source | Rows |
| --- | --- | --- |
| `default` | `train` | 48 |

Counts come from [Hub viewer metadata, retrieved 2026-10-05](https://datasets-server.huggingface.co/info?dataset=quintend%2Frdr-items) before local filtering. A dash means this page does not assert a count for that source.
