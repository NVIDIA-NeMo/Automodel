This preprocessed Natural Instructions dataset expresses tasks through definitions, inputs, and targets. The source is hosted as [Muennighoff/natural-instructions](https://huggingface.co/datasets/Muennighoff/natural-instructions).

## Task

**Instruction-conditioned text generation.** This Hub repository is a preprocessed version of Natural Instructions. Different tasks can request classification, extraction, or generation through the same text fields.

| Property | Description |
| --- | --- |
| Input | A task definition and task input. |
| Target | The text output requested by the definition. |
| Modality | Text |
| Language | en |
| License Metadata | Not declared in Hub metadata; consult the upstream source |

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. Media paths, when shown, stand in for binary image or audio data and do not refer to downloadable files.

```json
{
  "task_name": "synthetic_animal_classification",
  "id": "synthetic-ni-1",
  "definition": "Name the animal described in the input.",
  "inputs": "It has whiskers and says meow.",
  "targets": "cat"
}
```

## Schema and Splits

The table describes the task-bearing fields in the example. The source may also include identifiers and other metadata.

| Field | Type | Meaning |
| --- | --- | --- |
| `definition` | string | Natural-language task instruction. |
| `inputs` | string | Instance to solve. |
| `targets` | string | Expected output for this instance. |

These are upstream splits or source files, before any AutoModel sampling or preprocessing.

| Configuration | Split or Source | Rows |
