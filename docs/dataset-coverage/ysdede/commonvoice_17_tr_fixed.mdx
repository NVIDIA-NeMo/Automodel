The [ysdede/commonvoice_17_tr_fixed](https://huggingface.co/datasets/ysdede/commonvoice_17_tr_fixed) dataset is a processed version of Common Voice 17 Turkish speech used by the NeMo AutoModel Phi-4 multimodal fine-tuning example.

The upstream card describes resampling audio to 16 kHz, trimming silence, removing clips shorter than one second, and normalizing transcripts before publishing the dataset.

## Task

**Turkish speech recognition.** Train a model to transcribe Turkish speech into text.

| Property | Description |
| --- | --- |
| Input | A segment of speech audio. |
| Target | The corresponding transcript. |
| Modality | Audio and text |
| Language | Turkish (`tr`) |
| License Metadata | `cc0-1.0` |
| Access | Public and not gated in the retrieved Hub metadata. |

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. The audio path is a placeholder, and the waveform is omitted.

```json
{
  "audio": {
    "path": "synthetic-speech.wav",
    "bytes": null
  },
  "transcription": "Bugün hava güzel."
}
```

## Schema and Splits

The table describes the task-bearing fields in the example. The source also includes `duration`, `up_votes`, `down_votes`, `age`, `gender`, and `accent` metadata.

| Field | Type | Meaning |
| --- | --- | --- |
| `audio` | Audio | Audio segment with a declared sampling rate of 16,000 Hz. |
| `transcription` | string | Transcript for the audio segment. |

The upstream `default` configuration provides four splits:

| Configuration | Split | Rows |
| --- | --- | --- |
| `default` | `train` | 26,501 |
| `default` | `test` | 9,650 |
| `default` | `validation` | 8,639 |
| `default` | `validated` | 46,345 |

Counts come from [upstream metadata at the linked revision](https://huggingface.co/datasets/ysdede/commonvoice_17_tr_fixed/blob/9d8a025f1ae7c5a2f5c43298c7c4910b03995a4b/README.md). The upstream card reports removing records shared with `train`, `test`, or `validation` from this derivative's `validated` split.

## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| Speech Fine-Tuning | Phi-4 multimodal; Turkish transcripts | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/vlm_finetune/phi4/phi4_mm_cv17.yaml) |

**Adapter:** [`make_cv17_dataset`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/audio/datasets.py).

The loader retains `audio` and `transcription`, builds conversations from the transcript, and decodes audio lazily into mono `float32` waveforms at 16,000 Hz by default. Use the example's `phi4_mm_collate_fn` collator to pass these waveforms and conversations to the Phi-4 processor.

The example loads `train` and `validation` without additional row filtering. The other upstream splits are listed for reference.
