This Glaive function-calling conversion is used by. The source is hosted as [llamafactory/glaive_toolcall_en](https://huggingface.co/datasets/llamafactory/glaive_toolcall_en).

## Task

**Function calling.** The example preserves the source's serialized tools field. JSON inside that string must be decoded before treating it as a tool list.

| Property | Description |
| --- | --- |
| Input | A conversation and the available tool definitions. |
| Target | The assistant tool call and, when present, its follow-up response. |
| Modality | Text |
| Language | en |
| License Metadata | apache-2.0 |

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. Media paths, when shown, stand in for binary image or audio data and do not refer to downloadable files.

```json
{
  "conversations": [
    {
      "from": "human",
      "value": "What is 4 plus 5?"
    },
    {
      "from": "function_call",
      "value": "{\"name\":\"add\",\"arguments\":{\"a\":4,\"b\":5}}"
    }
  ],
  "tools": "[{\"name\":\"add\",\"description\":\"Add two integers.\",\"parameters\":{\"type\":\"object\",\"properties\":{\"a\":{\"type\":\"integer\"},\"b\":{\"type\":\"integer\"}},\"required\":[\"a\",\"b\"]}}]"
}
```

## Schema and Splits

The table describes the task-bearing fields in the example. The source may also include identifiers and other metadata.

| Field | Type | Meaning |
| --- | --- | --- |
| `conversations` | list of objects | ShareGPT-style from/value turns, including tool-call turns. |
| `tools` | JSON string | Available function definitions. |

These are upstream splits or source files, before any AutoModel sampling or preprocessing.

| Configuration | Split or Source | Rows |
| --- | --- | --- |
| `default` | `train` | - |

Counts come from [upstream metadata at the linked revision](https://huggingface.co/datasets/llamafactory/glaive_toolcall_en/blob/8e31881f7a149e3fab97e829a2958f8433c5d997/README.md) before local filtering. A dash means this page does not assert a count for that source.
