FineProofs-SFT contains mathematical problems, reasoning, and proofs with a chat representation. The source is hosted as [lm-provers/FineProofs-SFT](https://huggingface.co/datasets/lm-provers/FineProofs-SFT).

## Task

**Mathematical reasoning and proof generation.**

| Property | Description |
| --- | --- |
| Input | A mathematical problem. |
| Target | A worked reasoning trace and proof, also represented as chat messages. |
| Modality | Text |
| Language | en |
| License Metadata | apache-2.0 |

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. Media paths, when shown, stand in for binary image or audio data and do not refer to downloadable files.

```json
{
  "problem": "Show that the sum of two even integers is even.",
  "reasoning_content": "Write the integers as 2a and 2b.",
  "proof": "Their sum is 2(a+b), which is even.",
  "messages": [
    {
      "role": "user",
      "content": "Show that the sum of two even integers is even."
    },
    {
      "role": "assistant",
      "content": "Write them as 2a and 2b. Their sum is 2(a+b), so it is even."
    }
  ]
}
```

## Schema and Splits

The table describes the task-bearing fields in the example. The source may also include identifiers and other metadata.

| Field | Type | Meaning |
| --- | --- | --- |
| `problem` | string | Mathematical problem statement. |
| `reasoning_content` | string | Reasoning associated with the solution. |
| `proof` | string | Proof text. |
| `messages` | list of objects | Conversation representation of the example. |

## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| Chat Fine-Tuning | Qwen2.5 0.5B; 2,048-token limit | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/llm_finetune/qwen/qwen2_5_0p5b_instruct_fineproofs_chat.yaml) |

**Adapter:** [`ChatDataset`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/llm/chat_dataset.py).

The recipe reads the `messages` column, uses a custom chat template, and sets `mask_reasoning_content: false`. It truncates at 2,048 tokens. The recipe does not select the upstream `all` configuration; the default configuration has a different row count.

Training uses `train[:1024]`; validation uses the non-overlapping `train[1024:1152]` slice. These are recipe holdouts from the upstream training split.
