Naruto BLIP Captions pairs images with automatically generated captions. The source is hosted as [lambda/naruto-blip-captions](https://huggingface.co/datasets/lambda/naruto-blip-captions). Existing AutoModel examples use its `lambdalabs/naruto-blip-captions` alias.

## Task

**Text-conditioned image generation.** Each source record pairs a Naruto image with a BLIP-generated caption that conditions image generation.

| Property | Description |
| --- | --- |
| Input | A caption describing an image. |
| Target | The paired image. |
| Modality | Image and text |
| Language | Not declared in Hub metadata |
| License Metadata | Not declared in Hub metadata; consult the upstream source |

## Example Record

This **synthetic example** uses an invented scene and caption; it is not a copied dataset row. The `image` object is a JSON representation of image data. Its path is a placeholder, not a downloadable file; loaded source images are PIL images.

```json
{
  "image": {
    "path": "synthetic-illustration.png",
    "bytes": null
  },
  "text": "An illustrated traveler wearing a green scarf stands beside a river."
}
```

## Schema and Splits

The upstream card documents two source fields:

| Field | Type | Meaning |
| --- | --- | --- |
| `image` | image | JPEG image of varying size, decoded as a PIL image. |
| `text` | string | BLIP-generated caption for the source image. |

These are upstream splits or source files, before any AutoModel sampling or preprocessing.

| Configuration | Split or Source | Rows |
| --- | --- | --- |
| `default` | `train` | - |

The [upstream card at the linked revision](https://huggingface.co/datasets/lambda/naruto-blip-captions/blob/1ed13e8ef280bd45e3bbac4cfa8bbd9d64ec9f89/README.md) documents the `train` split but does not state its row count. The dash means this page does not assert a count.

## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| Text-to-Image Fine-Tuning | Qwen-Image-2.1; prepared cache; 8 GPUs | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/diffusion/finetune/qwen_image_21_t2i_flow.yaml) |

**Adapter:** [`build_text_to_image_multiresolution_dataloader`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/diffusion/collate_fns.py#L256).

The checked-in recipe refers to the older Hub alias `lambdalabs/naruto-blip-captions`, which now resolves to `lambda/naruto-blip-captions`. The preprocessing command in the linked recipe materializes the images and captions, then produces the latent/text-embedding cache expected by the diffusion dataloader. Set `data.dataloader.cache_dir` to the preprocessing output directory and choose `checkpoint.checkpoint_dir` before training with [the diffusion entry point](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/diffusion/finetune/finetune.py). This workflow requires a diffusers build containing `QwenImage21Pipeline`.

The upstream card provides a single `train` split. The selected recipe does not configure validation data.
