Embed Nemotron Dataset v1 packages retrieval training sources. The source is hosted as [nvidia/embed-nemotron-dataset-v1](https://huggingface.co/datasets/nvidia/embed-nemotron-dataset-v1).

## Task

**Text retrieval and representation learning.** This example illustrates a query row. Companion corpus configurations store the text for those IDs; a query row is not a self-contained passage pair.

| Property | Description |
| --- | --- |
| Input | A query and candidate documents in a referenced corpus. |
| Target | Relevant document IDs, contrasted with negative document IDs. |
| Modality | Text queries and documents |
| Language | multilingual |
| License Metadata | Not declared in Hub metadata; consult the upstream source |

The collection aggregates separately sourced datasets. Consult the pinned upstream card and each component source for its terms; the top-level Hub metadata does not declare a single license.

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. Media paths, when shown, stand in for binary image or audio data and do not refer to downloadable files.

```json
{
  "question_id": 0,
  "question": "Where are penguins found?",
  "corpus_id": "synthetic_corpus",
  "pos_doc": [
    {
      "id": "doc-1"
    }
  ],
  "neg_doc": [
    {
      "id": "doc-2"
    }
  ]
}
```

## Schema and Splits

The table describes the task-bearing fields in the example. The source may also include identifiers and other metadata.

| Field | Type | Meaning |
| --- | --- | --- |
| `question_id` | integer or string by subset | Query identifier. |
| `question` | string | Query text. |
| `corpus_id` | string | Identifier of the associated corpus. |
| `pos_doc` | list of objects | Relevant document references. |
| `neg_doc` | list of objects | Negative document references. |

The table shows the `FEVER` query configuration. The paired `FEVER_corpus` configuration contains documents. Other query/corpus pairs are available on the [Hub dataset page](https://huggingface.co/datasets/nvidia/embed-nemotron-dataset-v1).

| Configuration | Split or Source | Rows |
| --- | --- | --- |
| `FEVER` | `train` | 140,085 |

Counts come from [Hub viewer metadata, retrieved 2026-10-05](https://datasets-server.huggingface.co/info?dataset=nvidia%2Fembed-nemotron-dataset-v1) before local filtering. A dash means this page does not assert a count for that source.
