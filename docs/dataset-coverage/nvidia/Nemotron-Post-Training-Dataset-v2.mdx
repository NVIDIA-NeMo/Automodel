Nemotron Post-Training Dataset v2 provides domain-specific conversation splits. The source is hosted as [nvidia/Nemotron-Post-Training-Dataset-v2](https://huggingface.co/datasets/nvidia/Nemotron-Post-Training-Dataset-v2).

## Task

**Instruction following and reasoning.** The Hub repository includes chat, STEM, math, code, and multilingual splits. The AutoModel examples select a subset of these domains.

| Property | Description |
| --- | --- |
| Input | A prompt or conversation from a domain-specific split. |
| Target | Assistant responses, with reasoning content depending on the source. |
| Modality | Text |
| Language | en, de, it, fr, es, ja |
| License Metadata | cc-by-4.0 |

## Example Record

This **synthetic example** uses invented values in selected source fields; it is not a copied dataset row. Media paths, when shown, stand in for binary image or audio data and do not refer to downloadable files.

```json
{
  "category": "math",
  "messages": [
    {
      "role": "user",
      "content": "A box holds 6 pencils. How many pencils are in 3 boxes?"
    },
    {
      "role": "assistant",
      "content": "There are 6 * 3 = 18 pencils."
    }
  ]
}
```

## Use with NeMo AutoModel

| Workflow | Example Setup | Recipe |
| --- | --- | --- |
| I-DLM Training | Qwen3 8B; math and code | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/dllm_sft/qwen3_8b_idlm.yaml) |
| DFlash Training | Nemotron; chat, math, and code | [View YAML](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/examples/dllm_sft/nemotron_nano30b_dflash.yaml) |

**Adapter:** [`ChatDataset`](https://github.com/NVIDIA-NeMo/Automodel/blob/03429168a27bfffd10d109d2adf436b49f1c82a7/nemo_automodel/components/datasets/llm/chat_dataset.py).

The Qwen example concatenates `math+code`, sets a 4,096-token length limit, and requests unshifted labels for the diffusion objective. The Nemotron example selects `chat+math+code`. Follow each recipe's target-model response regeneration guidance when reproducing its intended draft-training setup.

The table lists the domain splits selected by these examples. Neither listed recipe configures a separate validation dataset.
