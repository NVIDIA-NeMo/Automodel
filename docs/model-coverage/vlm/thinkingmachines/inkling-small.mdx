[Inkling-Small](https://huggingface.co/thinkingmachines/Inkling-Small) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `InklingForConditionalGeneration` architecture.

## Fine-Tune Inkling-Small

Follow the [installation instructions](/get-started/installation), then review the checked-in recipe and
its declared topology below before choosing a local or cluster launcher.

Use the [Slurm launcher guide](/job-launchers/slurm-cluster) for the multi-node run.

## Standard Recipe Configuration

Start with the [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/vlm_finetune/inkling/Inkling_small_medpix_ep64.yaml).

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, pp_size=1, cp_size=1, ep_size=64 |
| Nodes | 8 |
| Features | Activation checkpointing (activation_checkpointing=true), HybridEP (dispatcher=hybridep) |
| Advanced | bfloat16, attention=sdpa, linear=torch, experts=torch_mm, dispatcher=hybridep |
