[SmolVLM](https://huggingface.co/blog/smolvlm) is HuggingFace's compact vision language model designed for on-device and memory-constrained deployment, featuring an efficient image token compression strategy.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/vlm_finetune/huggingfacetb/smolvlm_instruct_medpix_peft.yaml --nproc-per-node 8
```

## Model Context

SmolVLM-Instruct is used for image-text-to-text. Its model size is 2.25B parameters.

| Property | Value |
| --- | --- |
| Task | Image-Text-to-Text |
| **Architecture** | `SmolVLMForConditionalGeneration` |
| Parameters | 2.25B |
| Hugging Face Organization | [HuggingFaceTB](https://huggingface.co/HuggingFaceTB) |
| Decoder Layers | 24 |
| Hidden Size | 2,048 |
| Attention | 32 attention heads / 32 key-value heads |
| Context Length | 16,384 tokens (checkpoint configuration) |
| Vocabulary Size | 49,155 |
| Configured Dtype | `bfloat16` |
