[Gemma-4-E4B-it](https://huggingface.co/google/gemma-4-E4B-it) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `Gemma4ForConditionalGeneration` architecture.

## Fine-Tune Gemma-4-E4B-it

Follow the [installation instructions](/get-started/installation), then review the checked-in recipe and
its declared topology below before choosing a local or cluster launcher.

```bash
uv run automodel examples/vlm_finetune/gemma4/gemma4_4b.yaml \
  --nproc-per-node 8
```

## Standard Recipe Configuration

Start with the [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/vlm_finetune/gemma4/gemma4_4b.yaml).

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, cp_size=1 |
| Nodes | - |
| Features | Checkpointing (enabled=true) |
| Advanced | torch.bfloat16 |
