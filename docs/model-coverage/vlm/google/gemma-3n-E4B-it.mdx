[`google/gemma-3n-E4B-it`](https://huggingface.co/google/gemma-3n-E4B-it) has checked-in NeMo AutoModel recipes for image-text-to-text fine-tuning.
The Hugging Face configuration declares the `Gemma3nForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation) with the `vlm` extra and complete the [model access setup](#model-context). From the repository root, launch vision-language fine-tuning on MedPix-VQA using the example eight-GPU setup:

```bash
automodel examples/vlm_finetune/gemma3n/gemma3n_vl_4b_medpix.yaml --nproc-per-node 8
```

## Model Context

`google/gemma-3n-E4B-it` is used for image-text-to-text. Its model size is 7.85B checkpoint parameters. Both recipes load pretrained weights and fine-tune the language model while freezing the vision and audio encoders.

| Property | Value |
| --- | --- |
| Task | Image-text-to-text |
| **Architecture** | `Gemma3nForConditionalGeneration` |
| Parameters | 7.85B checkpoint parameters |
| Decoder Layers | 35 |
| Hidden Size | 2,048 |
| Attention | 8 attention heads and 2 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 262,400 |
| Configured Dtype | `bfloat16` |

Before running either recipe, accept the Gemma license on the [Hugging Face checkpoint page](https://huggingface.co/google/gemma-3n-E4B-it). Set `HF_TOKEN` in the training environment to a token from the account granted access.

### Configuration

These settings describe the primary MedPix recipe. The Quick Start illustrates an eight-GPU launch.

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs in the example command; GPU model not specified |
| Strategy | Fully sharded data parallel (FSDP2); `tp_size=1`, `cp_size=1` |
| Nodes | Not specified in the YAML |
| Features | Checkpoint saving enabled (`checkpoint.enabled=true`) |
| Advanced | `torch.bfloat16`; eager attention |
