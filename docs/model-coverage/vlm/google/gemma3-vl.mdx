[Gemma 3](https://ai.google.dev/gemma/docs/core) includes text-only and
multimodal checkpoints. Gemma 3n is a next-generation efficiency-focused
variant. This is the single coverage page for the Gemma 3 generation.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Fine-Tune gemma-3-270m

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/vlm_finetune/gemma3/gemma3_vl_4b_cord_v2.yaml
```
