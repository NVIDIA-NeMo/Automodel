[gemma-3-4b-it](https://huggingface.co/google/gemma-3-4b-it) is a multimodal Gemma 3 checkpoint for image-text inputs. NeMo AutoModel provides full-parameter and Low-Rank Adaptation (LoRA) recipes for supervised fine-tuning.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Fine-Tune gemma-3-4b-it

From the repository root, run:

```bash
uv run automodel examples/vlm_finetune/gemma3/gemma3_vl_4b_cord_v2.yaml --nproc-per-node 8
```
