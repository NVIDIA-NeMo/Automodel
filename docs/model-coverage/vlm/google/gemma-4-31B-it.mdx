[gemma-4-31B-it](https://huggingface.co/google/gemma-4-31B-it) is a multimodal Gemma 4 checkpoint for image-text inputs. NeMo AutoModel provides full-parameter and Low-Rank Adaptation (LoRA) recipes, including tensor-parallel and pipeline-parallel variants.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

From the repository root, run the 8-GPU recipe:

```bash
uv run automodel examples/vlm_finetune/gemma4/gemma4_31b.yaml --nproc-per-node 8
```

## Model Context

The checkpoint contains 31.27B parameters. The recipes load pretrained weights and train on MedPix-VQA, keeping the vision tower frozen. Full-parameter variants update language-model weights; the LoRA variant trains adapters.

| Property | Value |
| --- | --- |
| Task | Image-text-to-text |
| **Hugging Face Architecture** | `Gemma4ForConditionalGeneration` |
| Checkpoint | [`google/gemma-4-31B-it`](https://huggingface.co/google/gemma-4-31B-it) |
| Parameters | 31.27B checkpoint parameters |
| Decoder Layers | 60 |
| Hidden Size | 5,376 |
| Attention | 32 attention heads; 16 key-value heads in sliding layers / 4 in global layers |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 262,144 |
| Configured Dtype | `bfloat16` |
