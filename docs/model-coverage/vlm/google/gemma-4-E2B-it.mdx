[Gemma-4-E2B-it](https://huggingface.co/google/gemma-4-E2B-it) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `Gemma4ForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run this example from the
repository root on one node with two GPUs. Review the recipe settings below before launching.

```bash
uv run automodel examples/vlm_finetune/gemma4/gemma4_2b.yaml \
  --nproc-per-node 2
```

## Model Context

`google/gemma-4-E2B-it` has 5.12B checkpoint parameters. The example fine-tunes pretrained weights
on MedPix-VQA while freezing the vision and audio towers.

| Property | Value |
| --- | --- |
| Task | Image-text-to-text |
| **Architecture** | `Gemma4ForConditionalGeneration` |
| Parameters | 5.12B checkpoint parameters |
| Decoder Layers | 35 |
| Hidden Size | 1,536 |
| Attention | 8 attention heads and 1 key-value head |
| Context Length | 131,072 tokens (checkpoint configuration) |
| Vocabulary Size | 262,144 |
| Configured Dtype | `bfloat16` |

### Configuration

These settings describe `gemma4_2b.yaml` and its example launch, not minimum hardware requirements.

| Setting | Configuration |
| --- | --- |
| Hardware | 2 GPUs in the example launch; GPU model not specified |
| Strategy | Fully Sharded Data Parallel (FSDP2); `tp_size=1`, `cp_size=1` |
| Nodes | 1 |
| Features | Checkpoint saving enabled (`checkpoint.enabled=true`) |
| Advanced | `torch.bfloat16` |
