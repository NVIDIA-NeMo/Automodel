[Gemma-4-E4B-it](https://huggingface.co/google/gemma-4-E4B-it) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `Gemma4ForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run this command from the repository root
to fine-tune the pretrained checkpoint on MedPix-VQA using one node with eight GPUs.
This is the recipe's example topology; review its batch and parallelism settings before changing the GPU count.

```bash
uv run automodel examples/vlm_finetune/gemma4/gemma4_4b.yaml \
  --nproc-per-node 8
```

## Model Context

gemma-4-E4B-it is used for image-text-to-text. Its model size is 8.00B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Image-text-to-text |
| **Architecture** | `Gemma4ForConditionalGeneration` |
| Drafter Architecture (Joint-Training Recipes) | `Gemma4AssistantForCausalLM` (separate assistant checkpoint) |
| Parameters | 8.00B checkpoint parameters |
| Decoder Layers | 42 |
| Hidden Size | 2,560 |
| Attention | 8 attention heads and 2 key-value heads |
| Context Length | 131,072 tokens (checkpoint configuration) |
| Vocabulary Size | 262,144 |
| Configured Dtype | `bfloat16` |

### Configuration

The Quick Start recipe loads pretrained weights and fine-tunes the language model while freezing the vision and audio towers.

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs in the example launch; GPU model unspecified |
| Strategy | Fully Sharded Data Parallel version 2 (FSDP2); `tp_size=1`, `cp_size=1` |
| Nodes | 1 in the example launch |
| Checkpoint Saving | Enabled; output directory: `vlm_checkpoints/gemma4_4b/` |
| Training Dtype | `torch.bfloat16` |

The synthetic-data recipe loads the same pretrained checkpoint but disables checkpoint saving, so it does not save fine-tuned weights.
The two Tulu 3 text recipes also disable checkpoint saving.
The joint-drafter recipes load both the base checkpoint and the separate `google/gemma-4-E4B-it-assistant` checkpoint.
