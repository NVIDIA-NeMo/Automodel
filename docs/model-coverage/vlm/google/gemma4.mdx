[gemma-4-31B-it](https://huggingface.co/google/gemma-4-31B-it) is a multimodal Gemma 4 checkpoint for image-text inputs. NeMo AutoModel provides full-parameter and Low-Rank Adaptation (LoRA) recipes, including tensor-parallel and pipeline-parallel variants.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Fine-Tune gemma-4-31B-it

From the repository root, run the 8-GPU recipe:

```bash
uv run automodel examples/vlm_finetune/gemma4/gemma4_31b.yaml --nproc-per-node 8
```
