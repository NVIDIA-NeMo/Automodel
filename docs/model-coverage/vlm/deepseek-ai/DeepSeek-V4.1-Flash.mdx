[DeepSeek-V4.1-Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `DeepseekV41ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). Allocate 16 nodes with 8 GPUs each; run on every node with `NODE_RANK` and `MASTER_ADDR` set. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run torchrun --nnodes 16 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/vlm_finetune/deepseek_v41/deepseek_v41_flash_medpix_4k_ep64.yaml
```

## Model Context

DeepSeek-V4.1-Flash is used for image-text-to-text. Its model size is approximately 749B native backbone, including Engram and vision; excludes auxiliary prediction modules parameters.

| Property | Value |
| --- | --- |
| Task | Image-text-to-text |
| **Architecture** | `DeepseekV41ForCausalLM` |
| Decoder Layers | 40 |
| Hidden Size | 5,120 |
| Attention | 64 attention heads / 1 key-value heads |
| Context Length | 1,048,576 tokens (checkpoint configuration) |
| Vocabulary Size | 129,280 |
| Experts | 384 routed / 1 shared / 6 selected per token |
| Configured Dtype | `bfloat16` |
| Parameters | Approximately 749B native backbone, including Engram and vision; excludes auxiliary prediction modules |

### Configuration

| Setting | Configuration |
| --- | --- |
| Hardware | - |
