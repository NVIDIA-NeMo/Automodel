[DeepSeek-V4.1-Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `DeepseekV41ForCausalLM` architecture.

## Quick Start

Complete the [recipe setup](#recipe-setup). Allocate the recipe's 16 nodes with 4 GPUs each in one NVLink domain. From the repository root, run on every node with `NODE_RANK` set to its unique rank (0-15) and `MASTER_ADDR` set to the rank-0 node's reachable address.

```bash
uv run --extra all --extra moe torchrun --nnodes 16 --nproc-per-node 4 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/vlm_finetune/deepseek_v41/deepseek_v41_flash_medpix_4k_ep64.yaml
```

## Model Context

DeepSeek-V4.1-Flash is used for image-text-to-text. Its native backbone has approximately 749 billion parameters, including Engram and vision components and excluding auxiliary prediction modules.

### Recipe Setup

Follow the [source installation instructions](/get-started/installation) and use the same checkout and environment on every node. Select the `all` and `moe` extras, as in the Quick Start command: `all` supplies the vision-language dependencies, TileLang, and Transformer Engine for the configured `FusedAdam` optimizer and gradient clipping; `moe` supplies the pinned DeepEP build with HybridEP. HybridEP also requires `nvcc` for kernel compilation at runtime.

The [recipe](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/vlm_finetune/deepseek_v41/deepseek_v41_flash_medpix_4k_ep64.yaml) loads the pretrained checkpoint and processor at the same revision and downloads `mmoukouba/MedPix-VQA`. Ensure every node can access these assets. For local snapshots, update both model checkpoint paths and the processor path together, preserving the shared revision.

Use the [Slurm launcher guide](/job-launchers/slurm-cluster) to prepare the distributed allocation. The 64-GPU topology is the recipe target, not a hardware minimum; changing it also requires compatible batch and parallelism settings.

### Workflow Notes

The recipe fine-tunes both the language model and vision tower for up to 100 steps, using 4,096-token inputs. It sets `checkpoint.enabled=false`, so it does not save trained weights or optimizer state. The recipe notes that saving and restoring the full-model Transformer Engine optimizer state has not been validated.
