[DeepSeek-V4-Flash-Vision-Exp](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash-Vision-Exp) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `DeepseekV4ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). Allocate 16 nodes with 8 GPUs each; run on every node with `NODE_RANK` and `MASTER_ADDR` set. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run torchrun --nnodes 16 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/vlm_finetune/deepseek_v4/deepseek_v4_flash_vision_medpix_4k_ep32pp4_100steps.yaml
```

## Model Context

DeepSeek-V4-Flash-Vision-Exp is used for image-text-to-text. Its model size is 304.6B native parameters: 284.3B language backbone / 0.47B vision / 19.83B auxiliary MTP.

| Property | Value |
| --- | --- |
| Task | Image-text-to-text |
| **Architecture** | `DeepseekV4ForCausalLM` |
| Decoder Layers | 43 |
| Hidden Size | 4,096 |
| Attention | 64 attention heads / 1 key-value heads |
| Context Length | 1,048,576 tokens (checkpoint configuration) |
| Vocabulary Size | 129,280 |
| Experts | 256 routed / 1 shared / 6 selected per token |
| Vision Encoder | 32 layers / 1,024 hidden size / 16 attention heads / 14 x 14 patches |
| Configured Dtype | `bfloat16` |
| Parameters | 304.6B native parameters: 284.3B language backbone / 0.47B vision / 19.83B auxiliary MTP |

The parameter split includes three auxiliary prediction modules; the fine-tuning recipe sets `num_nextn_predict_layers: 0` and trains the language and vision backbone.

### Configuration

| Setting | Configuration |

| Features | Activation checkpointing (activation_checkpointing=true), HybridEP (dispatcher=hybridep) |
| Advanced | bfloat16, attention=tilelang, linear=torch, experts=torch_mm, dispatcher=hybridep |
