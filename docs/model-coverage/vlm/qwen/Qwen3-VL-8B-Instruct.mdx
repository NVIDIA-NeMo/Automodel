[Qwen3-VL-8B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-8B-Instruct) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `Qwen3VLForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/vlm_finetune/qwen3/qwen3_vl_8b_instruct_rdr.yaml --nproc-per-node 8
```

## Model Context

Qwen3-VL-8B-Instruct is used for image-text-to-text. Its model size is 8.77B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Image-text-to-text |
| **Architecture** | `Qwen3VLForConditionalGeneration` |
| Parameters | 8.77B checkpoint parameters |
| Decoder Layers | 36 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads / 8 key-value heads |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 151,936 |

### Configuration

The settings below describe the Quick Start recipe. It loads pretrained weights and fine-tunes on `quintend/rdr-items` with the vision tower frozen.

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; `tp_size=1`, `cp_size=1` |
| Nodes | - |
| Features | Training checkpoint saving (`checkpoint.enabled: true`) |
| Advanced | - |

The context-parallel recipe also enables vision frame sharding and activation checkpointing. It sets `checkpoint.enabled: false`, so it does not save trained checkpoints.
