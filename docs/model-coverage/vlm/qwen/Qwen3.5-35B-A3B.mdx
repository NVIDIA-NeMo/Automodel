## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:


## Model Context

Qwen3.5-35B-A3B is used for image-text-to-text. Its model size is 35.95B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Image-text-to-text |
| **Architecture** | `Qwen3_5MoeForConditionalGeneration` |
| Parameters | 35.95B checkpoint parameters |
