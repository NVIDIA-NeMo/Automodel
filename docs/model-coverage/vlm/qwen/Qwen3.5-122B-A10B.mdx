[Qwen3.5-122B-A10B](https://huggingface.co/Qwen/Qwen3.5-122B-A10B) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `Qwen3_5MoeForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). Allocate 16 nodes with 8 GPUs each; run on every node with `NODE_RANK` and `MASTER_ADDR` set. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run torchrun --nnodes 16 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/vlm_finetune/qwen3_5_moe/qwen3_5_122b_128k_ep8cp32.yaml
```

## Model Context

Qwen3.5-122B-A10B is used for image-text-to-text. Its model size is 125.09B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Image-text-to-text |
| **Architecture** | `Qwen3_5MoeForConditionalGeneration` |
| Parameters | 125.09B checkpoint parameters |
| Decoder Layers | 48 |
| Hidden Size | 3,072 |
| Attention | 32 attention heads / 2 key-value heads |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 248,320 |
| Experts | 256 routed / 8 selected per token |
