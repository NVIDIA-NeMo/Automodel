Qwen3.8-27B is Qwen's dense 27B native vision-language model for text, image,
and video inputs. It retains the Qwen3.5 hybrid Gated DeltaNet and gated-attention
architecture, so NeMo AutoModel uses its existing native
`Qwen3_5ForConditionalGeneration` implementation for the checkpoint.

## Quick Start

Follow the [installation instructions](/get-started/installation) and complete the [recipe setup](#recipe-setup). From the repository root, choose full language-model or low-rank adaptation (LoRA) fine-tuning. These examples use one node with 8 GPUs.

```bash
uv run automodel --nproc-per-node=8 examples/vlm_finetune/qwen3_8/qwen3_8_27b.yaml
uv run automodel --nproc-per-node=8 examples/vlm_finetune/qwen3_8/qwen3_8_27b_lora.yaml
```

## Model Context

Qwen3.8-27B is used for image-text-to-text. Its model size is 27B dense parameters.

| Property | Value |
|---|---|
| **Task** | Image-Text-to-Text |
| **Architecture** | `Qwen3_5ForConditionalGeneration` |
| **Parameters** | 27B dense |
| **Context length** | 262,144 tokens (checkpoint configuration) |
| **HF Org** | [Qwen](https://huggingface.co/Qwen) |
| Decoder Layers | 64 |
| Hidden Size | 5,120 |
| Full Attention | 24 query heads and 4 key-value heads |
| Vocabulary Size | 248,320 |

### Recipe Setup

Install the `vlm-media` extra before running either recipe. See the
[Installation Guide](/get-started/installation) and the
[Qwen3.8 fine-tuning guide](/recipes-e2e-examples/qwen3-8-27b) for setup,
validation details, and measured training-loss curves.

### Workflow Notes

Both recipes load pretrained weights and use MedPix-VQA with the vision tower
frozen. The full fine-tuning recipe trains the language model and enables
checkpoint saving. The LoRA recipe trains rank-8 adapters and sets
`checkpoint.enabled: false`, so it does not save the trained adapters.

The checked-in recipes use Fully Sharded Data Parallel version 2 (FSDP2) on
eight GPUs. The shared Qwen3.5 dense model implementation also supports tensor,
context, and pipeline parallelism, but the Qwen3.8 runs documented here validate
eight-way data parallelism specifically.
