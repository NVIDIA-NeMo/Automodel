Qwen3.6 is Alibaba Cloud's unified vision-language model generation following Qwen3.5. NeMo AutoModel supports both the dense 27B checkpoint and the 35B-A3B MoE checkpoint.

## Fine-Tune Qwen3.6-27B

This quick start requires Docker, the NVIDIA Container Toolkit, and eight GPUs.
If Hugging Face requires authentication, export `HF_TOKEN` in the host shell
first. For other installation methods, see the
[Installation Guide](/get-started/installation).

Run this complete block in a host shell. It downloads the container, installs
the VLM dependencies, starts fine-tuning, and keeps downloaded files and
checkpoints on the host.

```bash
git clone --depth=1 https://github.com/NVIDIA-NeMo/Automodel.git
cd Automodel
mkdir -p .cache/huggingface checkpoints/qwen3-6-27b

docker pull nvcr.io/nvidia/nemo-automodel:26.08.00
docker run --gpus all --network=host -it --rm \
  --shm-size=32g \
  -e HF_TOKEN \
  -v "$(pwd)":/opt/Automodel \
  -v "$(pwd)/.cache/huggingface":/root/.cache/huggingface \
  -w /opt/Automodel \
  nvcr.io/nvidia/nemo-automodel:26.08.00 \
  /bin/bash -lc '
    bash docker/common/update_pyproject_pytorch.sh /opt/Automodel &&
    uv sync --locked --extra all --extra vlm-media --all-groups &&
    uv run automodel --nproc-per-node=8 examples/vlm_finetune/qwen3_5/qwen3_6_27b.yaml \
      --checkpoint.checkpoint_dir checkpoints/qwen3-6-27b
  '
```

The quick start installs the `vlm-media` extra required by the recipe. See the
[VLM Fine-Tuning Guide](/recipes-e2e-examples/gemma-3-3n) for additional
configuration details.

## Model Reference

### Model Architecture

| Property | Value |
|---|---|
| **Task** | Image-Text-to-Text |
| **Architecture** | `Qwen3_5ForConditionalGeneration`, `Qwen3_5MoeForConditionalGeneration` |
| **Parameters** | 27B dense; 35B total / 3B active MoE |
| **HF Org** | [Qwen](https://huggingface.co/Qwen) |
