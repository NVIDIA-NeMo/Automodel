[Qwen3.5-27B](https://huggingface.co/Qwen/Qwen3.5-27B) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `Qwen3_5ForConditionalGeneration` architecture.

## Fine-Tune Qwen3.5-27B

Follow the [installation instructions](/get-started/installation), then review the checked-in recipe and
its declared topology below before choosing a local or cluster launcher.

Use the [Slurm launcher guide](/job-launchers/slurm-cluster) for the multi-node run.

Full-parameter FSDP2 training requires fp32 parameter storage: set `model.dtype: float32` and keep `mp_policy.param_dtype: bfloat16`. The model's fp32 parameters (the GatedDeltaNet `A_log` and `dt_bias`) then stay in fp32 inside each layer's FSDP unit; bf16 storage fails at sharding time.
