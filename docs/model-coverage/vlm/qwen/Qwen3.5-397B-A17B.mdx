[Qwen3.5-397B-A17B](https://huggingface.co/Qwen/Qwen3.5-397B-A17B) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `Qwen3_5MoeForConditionalGeneration` architecture.

## Quick Start

This example uses 32 nodes with 8 GPUs each. Complete the [recipe prerequisites](#model-context), then run from the repository root on every node. Set `NODE_RANK` uniquely from 0 to 31 and `MASTER_ADDR` to the same reachable rank-0 address.

```bash
export PYTORCH_CUDA_ALLOC_CONF=expandable_segments:True
uv run --no-sync torchrun --nnodes 32 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/vlm_finetune/qwen3_5_moe/qwen3_5_moe_medpix.yaml
```

## Model Context

Qwen3.5-397B-A17B is used for image-text-to-text. Its model size is 403.40B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Image-text-to-text |
| **Architecture** | `Qwen3_5MoeForConditionalGeneration` |
| Parameters | 403.40B checkpoint parameters |
| Decoder Layers | 60 |
| Hidden Size | 4,096 |
| Attention | Gated DeltaNet with full attention every fourth layer; full attention uses 32 query heads and 2 key-value heads |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 248,320 |
| Experts | 512 routed experts; 10 routed experts selected per token and 1 shared expert |

| Nodes | 32 |
| Features | HybridEP (`dispatcher=hybridep`) |

### Workflow Notes

Follow the [installation instructions](/get-started/installation) and prepare an environment with the `vlm` and `moe` extras. The `moe` extra supplies the pinned `deep_ep` package, which builds HybridEP; `all` omits this package. For this multi-node recipe, build HybridEP with `HYBRID_EP_MULTINODE=1` and its communication dependencies, as configured in the [repository Dockerfile](https://github.com/NVIDIA-NeMo/Automodel/blob/main/docker/Dockerfile). The launch command uses `--no-sync` to reuse the prepared environment.

The recipe loads pretrained weights and fine-tunes on MedPix-VQA with the vision tower frozen. It sets `checkpoint.enabled: false`, so it does not save fine-tuned weights.
