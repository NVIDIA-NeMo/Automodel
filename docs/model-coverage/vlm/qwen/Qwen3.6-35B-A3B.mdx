[Qwen3.6-35B-A3B](https://huggingface.co/Qwen/Qwen3.6-35B-A3B) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `Qwen3_5MoeForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation) and [recipe setup notes](#model-context), then fine-tune on MedPix-VQA from the repository root:

```bash
automodel examples/vlm_finetune/qwen3_5_moe/qwen3_6_35b.yaml --nproc-per-node 8
```

## Model Context

Qwen3.6-35B-A3B is used for image-text-to-text. Its model size is 35.95B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Image-text-to-text |
| **Architecture** | `Qwen3_5MoeForConditionalGeneration` |
| Parameters | 35.95B checkpoint parameters |
| Decoder Layers | 40 |
| Hidden Size | 2,048 |
| Attention | Hybrid linear and full attention: 16 query/key and 32 value heads in linear layers; 16 query and 2 key-value heads in full-attention layers |
| Context Length | 262,144 tokens (checkpoint configuration); primary recipe limits inputs to 2,048 tokens |
| Vocabulary Size | 248,320 |
| Experts | 256 routed experts; 8 routed experts and 1 shared expert active per token |

The Quick Start launches on eight GPUs with expert parallelism (`ep_size: 8`). For a source installation, add `--extra moe` to the installation guide's `uv sync` command to install DeepEP; the `all` extra omits it.

The LoRA and EP8/CP2 recipes disable checkpoint saving (`checkpoint.enabled: false`), so they do not save trained weights unless you enable it.

### Configuration

These settings describe the primary recipe.

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, pp_size=1, cp_size=1, ep_size=8 |
| Nodes | - |
| Features | Checkpointing (enabled=true), Activation checkpointing (activation_checkpointing=true), DeepEP (dispatcher=deepep) |
| Advanced | `attn=sdpa`, `linear=torch`, `experts=torch_mm`, `dispatcher=deepep` |
