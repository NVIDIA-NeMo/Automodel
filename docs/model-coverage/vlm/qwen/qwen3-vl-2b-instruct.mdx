[Qwen3-VL-2B-Instruct](https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct) uses
the dense `Qwen3VLForConditionalGeneration` architecture for image-text inputs.

## Fine-Tune with Zephon

Follow the [installation instructions](/get-started/installation), then run
from the repository root:

```bash
uv run automodel examples/vlm_finetune/qwen3/zephon.yaml --nproc-per-node 8
```

The [recipe](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/vlm_finetune/qwen3/zephon.yaml)
reads embedded MedPix-VQA image conversations and packs complete documents online.
It follows the native packed Qwen3-VL example: FSDP2, Flash Attention 2,
an 8,192-token window, AdamW and a frozen vision tower.
Image preprocessing expands image tokens and constructs multi-axis positions
before packing.

See [Zephon](/datasets/zephon) for configuration, checkpointing and supported
parallelism, and [Zephon Image Data](/datasets/zephon-images) for source formats
and offline image export.
