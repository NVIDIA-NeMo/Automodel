Qwen3.6 is Alibaba Cloud's vision-language model generation following Qwen3.5. NeMo AutoModel provides fine-tuning and Low-Rank Adaptation (LoRA) recipes for the dense Qwen3.6-27B checkpoint and the related Qwen3.6-35B-A3B mixture-of-experts (MoE) checkpoint.

## Quick Start

Install NeMo AutoModel with the `vlm-media` extra using the [Installation Guide](/get-started/installation). From the repository root, launch MedPix-VQA fine-tuning with eight GPUs. See [Model Context](#model-context) for recipe settings and [Fine-Tune Gemma 3n](/recipes-e2e-examples/gemma-3-3n) for a related example.

```bash
uv run automodel --nproc-per-node=8 examples/vlm_finetune/qwen3_5/qwen3_6_27b.yaml
```

## Model Context

Qwen3.6-27B combines a dense language model with a vision encoder for image-text-to-text tasks. Its decoder alternates three Gated DeltaNet layers with one full-attention layer. The properties below describe Qwen3.6-27B; Qwen3.6-35B-A3B is a separate MoE checkpoint.

| Property | Value |
|---|---|
| **Task** | Image-Text-to-Text |
| **Architecture** | `Qwen3_5ForConditionalGeneration` |
| **Parameters** | 27B dense language model (upstream model size) |
| **HF Org** | [Qwen](https://huggingface.co/Qwen) |
| Decoder Layers | 64 |
| Hidden Size | 5,120 |
| Attention | Full attention: 24 query heads and 4 key-value heads; Gated DeltaNet: 16 query/key heads and 48 value heads |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 248,320 |

All four recipes load pretrained weights, use Fully Sharded Data Parallel (FSDP2), and keep the vision tower frozen. Both LoRA recipes set `checkpoint.enabled: false`, so they do not save trained adapters. Enable checkpoint saving to retain them.

The Qwen3.6-35B-A3B recipes use eight-way expert parallelism (`ep_size: 8`) with DeepEP (`dispatcher: deepep`). Install the `moe` extra for DeepEP; it is not included in `all`.
