[LLaVA-OneVision-1.5-8B-Instruct](https://huggingface.co/lmms-lab/LLaVA-OneVision-1.5-8B-Instruct) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `LLaVAOneVision1_5_ForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation) and [recipe prerequisites](#workflow-notes). In your installed environment, run low-rank adaptation (LoRA) fine-tuning on `quintend/rdr-items` from the repository root. This example uses eight GPUs on one node:

```bash
automodel examples/vlm_finetune/llava_onevision/llava_ov_1_5_8b_lora.yaml --nproc-per-node 8
```

### Workflow Notes

The recipe selects FlashAttention 2, which requires the `fa` extra in addition to the VLM dependencies. For a source installation, add `--extra fa` to the installation guide's `uv sync` command. The `fa` extra is excluded from `all`.

The recipe loads pretrained weights and trains on image descriptions from `quintend/rdr-items`. It saves checkpoints under `checkpoints/`. The eight-GPU launch is an example topology; the recipe does not specify a minimum GPU memory requirement.
