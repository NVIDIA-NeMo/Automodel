[LLaVA-OneVision 1.5](https://github.com/EvolvingLMMs-Lab/LLaVA-OneVision-2) is a vision-language model combining a **Rice ViT** encoder with a **Qwen3** language backbone, capable of handling both image and video understanding. NeMo AutoModel ships a custom NVIDIA implementation (`LLaVAOneVision1_5_ForConditionalGeneration`) with FSDP2/HSDP support, LoRA fine-tuning and distributed training.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

This example fine-tunes pretrained weights on RDR Items using eight GPUs. Review the [recipe prerequisites](#model-context), then run from the repository root:

```bash
uv run automodel --nproc-per-node=8 examples/vlm_finetune/llava_onevision/llava_ov_1_5_4b_finetune.yaml
```

## Model Context

LLaVA-OneVision-1.5-4B-Instruct generates text from image and text inputs. The 4B label describes its Qwen3 language backbone; the full checkpoint contains approximately 4.74 billion parameters.

| Property | Value |
| --- | --- |
| Task | Image-Text-to-Text |
| Architecture | `LLaVAOneVision1_5_ForConditionalGeneration` |
| Parameters | [4,741,610,528 total](https://huggingface.co/api/models/lmms-lab/LLaVA-OneVision-1.5-4B-Instruct/revision/ae6819dedee37f667accb33cd4bed14a14eec147) |
| Hugging Face Organization | [lmms-lab](https://huggingface.co/lmms-lab) |
| Decoder Layers | 36 |
| Hidden Size | 2,560 |
| Attention | 32 attention heads / 8 key-value heads |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 151,936 |
| Configured Dtype | `bfloat16` |

The recipe uses pretrained weights and the `quintend/rdr-items` dataset with FSDP2. It freezes the vision tower, trains the language model, and saves checkpoints to `checkpoints/`.

The recipe selects FlashAttention 2 (`flash_attention_2`), which requires `flash-attn`. For source installations, add `--extra fa` to the installation guide's `uv sync` command. The standard `all` extra includes VLM dependencies but excludes `fa`.

The **Rice Transformer** vision tower uses 14x14 patch embeddings with two-dimensional rotary position embeddings (RoPE), Transformer blocks with layer normalization, attention, and a multilayer perceptron (MLP), and a 2x2 spatial patch merger that projects to the language-model hidden size.
