[LLaVA-OneVision 1.5](https://github.com/EvolvingLMMs-Lab/LLaVA-OneVision-2) is a vision-language model combining a **Rice ViT** encoder with a **Qwen3** language backbone, capable of handling both image and video understanding. NeMo AutoModel ships a custom NVIDIA implementation (`LlavaOneVisionForConditionalGeneration`) with FSDP2/HSDP support, LoRA fine-tuning and distributed training.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Fine-Tune LLaVA-OneVision-1.5-4B-Instruct

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/vlm_finetune/llava_onevision/llava_ov_1_5_4b_finetune.yaml
```

## Model Reference

### Model Summary

| Property | Value |
| --- | --- |
| Task | Image-Text-to-Text |
| Architecture | `LlavaOneVisionForConditionalGeneration` |
| Parameters | 4B / 8B |
| Hugging Face Organization | [lmms-lab](https://huggingface.co/lmms-lab) |

### Available Models

- **LLaVA-OneVision 1.5 4B**: Qwen3 4B text backbone + Rice ViT (1024 hidden, 24 layers)
- **LLaVA-OneVision 1.5 8B**: Qwen3 8B text backbone + Rice ViT (1024 hidden, 24 layers)

### Model Architecture

- `LlavaOneVisionForConditionalGeneration`

Vision tower is the **Rice Transformer**: 14x14 patch embed with 2D RoPE, standard Transformer blocks (LayerNorm + Attention + MLP), and a 2x2 spatial Patch Merger that projects to the language-model hidden size.
