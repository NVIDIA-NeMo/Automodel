[LLaVA](https://llava-vl.github.io/) (Large Language and Vision Assistant) is a pioneering open-source multimodal model connecting a vision encoder to a language model via a projection layer. Multiple versions and variants are supported via the `llava-hf` organization on Hugging Face.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/vlm_finetune/llava_hf/llava_1_5_7b_hf_medpix_peft.yaml --nproc-per-node 8
```

## Model Context

llava-1.5-7b-hf is used for image-text-to-text. Its model size is 7B parameters.

| Property | Value |
| --- | --- |
| Task | Image-Text-to-Text |
| **Architecture** | `LlavaForConditionalGeneration` / `LlavaNextForConditionalGeneration` |
| Parameters | 7B |
| Hugging Face Organization | [llava-hf](https://huggingface.co/llava-hf) |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 32,064 |
| Configured Dtype | `float16` |

- `LlavaForConditionalGeneration` - LLaVA 1.5
- `LlavaNextForConditionalGeneration` - LLaVA-NeXT / 1.6
- `LlavaNextVideoForConditionalGeneration` - LLaVA-NeXT-Video
- `LlavaOnevisionForConditionalGeneration` - LLaVA-OneVision
