[Kimi-VL](https://huggingface.co/moonshotai/Kimi-VL-A3B-Instruct) and Kimi-K25-VL are vision language models from Moonshot AI. Kimi-VL-A3B uses a MoE language backbone (3B active parameters) with a vision encoder, supporting image understanding and multimodal reasoning.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/vlm_finetune/kimi/kimi2vl_cordv2.yaml
```

## Model Context

Kimi-VL-A3B-Instruct is used for image-text-to-text. Its model size is ~3B active (MoE) parameters.

| Property | Value |
| --- | --- |
| Task | Image-Text-to-Text |
| **Architecture** | `KimiVLForConditionalGeneration` |
| Parameters | ~3B active (MoE) |
| Hugging Face Organization | [moonshotai](https://huggingface.co/moonshotai) |
| Decoder Layers | 27 |
| Hidden Size | 2,048 |
| Attention | 16 attention heads / 16 key-value heads |
| Context Length | 131,072 tokens (checkpoint configuration) |
| Vocabulary Size | 163,840 |
| Experts | 64 routed / 2 shared / 6 selected per token |
| Configured Dtype | `bfloat16` |
