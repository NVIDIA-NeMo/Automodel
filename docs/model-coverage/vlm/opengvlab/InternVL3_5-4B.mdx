[InternVL](https://github.com/OpenGVLab/InternVL) is a vision language model from Shanghai AI Laboratory (OpenGVLab), combining a large vision encoder with an InternLM language backbone for strong multimodal performance.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/vlm_finetune/internvl/internvl_3_5_4b.yaml
```

## Model Context

InternVL3_5-4B is used for image-text-to-text. Its model size is 4B parameters.

| Property | Value |
| --- | --- |
| Recipe Checkpoint | [OpenGVLab/InternVL3_5-4B-hf](https://huggingface.co/OpenGVLab/InternVL3_5-4B-hf) |
| Task | Image-Text-to-Text |
| **Architecture** | `InternVLForConditionalGeneration` |
| Parameters | 4B |
| Hugging Face Organization | [OpenGVLab](https://huggingface.co/OpenGVLab) |
| Decoder Layers | 36 |
| Hidden Size | 2,560 |
| Attention | 32 attention heads / 8 key-value heads |
| Context Length | 40,960 tokens (checkpoint configuration) |
| Vocabulary Size | 151,936 |
| Configured Dtype | `bfloat16` |

The recipe loads `OpenGVLab/InternVL3_5-4B-hf`, the Hugging Face-compatible checkpoint for `OpenGVLab/InternVL3_5-4B`.
