[Mistral Large 4](https://huggingface.co/mistralai/Mistral-Large-4-1T-A52B) is Mistral AI's
1T-parameter (52B active) multimodal MoE model. NeMo AutoModel provides native text
(`MistralLarge4ForCausalLM`) and image-text (`MistralLarge4ForConditionalGeneration`)
implementations.

## Fine-Tune Mistral Large 4

Follow the [installation instructions](/get-started/installation). The full-model recipes run on
32 nodes x 4 GB200 (128 GPUs); use the [Slurm launcher guide](/job-launchers/slurm-cluster) for
multi-node runs.

```bash
uv run torchrun --nnodes=32 --nproc-per-node=4 \
  --node-rank="$NODE_RANK" --master-addr="$MASTER_ADDR" --master-port="$MASTER_PORT" \
  examples/vlm_finetune/finetune.py \
  --config examples/vlm_finetune/mistral/mistral_large4_medpix_ep64_pp2.yaml
```

### Configuration

| Setting | MedPix SFT | Tulu3 128K |
| --- | --- | --- |
| GPUs | 128 | 128 |
| Parallelism | EP64, PP2, CP1, TP1; FSDP2 | EP64, PP2, CP32, TP1, DP2; FSDP2 |
| Pipeline schedule | Interleaved 1F1B, four stages of 18 layers | 1F1B, two stages of 36 layers |
| Sequence | Nonpacked, 4,096 tokens | Packed THD, 131,072 tokens |
| Batch | Global 2,048, local 32 | Global 8, local 4 |
| Attention | SDPA | TileLang sparse MLA |
| Experts | `torch_mm`, HybridEP dispatcher | `torch_mm`, HybridEP dispatcher |
| Optimizer | AdamW, LR 5e-6, betas 0.9/0.95, weight decay 0.1, clip 1.0 | FusedAdam, LR 5e-6, BF16 moments, FP32 master weights |

Both SFT recipes use full activation checkpointing and keep the DSA indexer frozen.
The MedPix recipe also freezes the vision tower; the Tulu3 recipe builds only the text model.
W&B is opt-in: set `wandb.enable: true` and configure your entity and project when launching.
With TP1, the data-parallel degree for batch accounting is `world_size / (PP * CP)`.

## Prepare the Checkpoint

The native checkpoint contains `params.json`, `tekken.json`, `chat_template.jinja`,
`consolidated.safetensors.index.json` and the weight shards. Create a metadata view for
image-text training; the FP8 shards are linked, not copied:

```bash
uv run python tools/checkpoint/prepare_mistral_large4.py \
  /path/to/checkpoint /path/to/prepared-mistral-large4 --multimodal
```

Set `model.pretrained_model_name_or_path` and `processor.pretrained_model_name_or_path` to the
prepared directory. `checkpoint.dequantize_base_checkpoint: true` reconstructs the FP8 payloads in
FP32 and stores the weights in BF16. Router, LeRoPE and indexer-normalization state stays in FP32.
FP8 indexer and KV-cache execution are disabled for training.

## Prepare Packed Tulu3 Data

The 128K recipe reads prepacked data. Build it once with the same environment as training:

```bash
uv run python examples/llm_finetune/mistral/prepare_tulu3_packed.py \
  --model-path /path/to/checkpoint \
  --output data/mistral_large4_tulu3_packed128k/train
```

Labels are assistant-only. Documents and packs are shuffled with seed 1234 and aligned to 64 tokens.

## Known Limitations

- Tensor parallelism is not supported.
- HybridEP supports full fine-tuning; expert LoRA uses the Torch dispatcher.
- Packed context parallelism requires `backend.attn: tilelang`.
- The DSA indexer is frozen.
- In BF16, some comparisons exceed a 0.5% relative L2 gate: TileLang sparse MLA vs. SDPA logits
  (0.57%), packed CP2 pixel gradients (0.95%), packed PP2/CP2/EP2 HybridEP gradients (0.57%), and
  40-layer gradients vs. an independent reference (0.75% to 1.02%).

## Model Reference

### Model Architecture

| Property | Value |
| --- | --- |
| Task | Image-Text-to-Text |
| Architectures | `MistralLarge4ForCausalLM`, `MistralLarge4ForConditionalGeneration`; `model_type: mistral_large4` |
| Parameters | 1T total, 52B active |
| Language model | 72 layers, hidden size 6,144, vocabulary 204,800 |
| Attention | MLA with sparse DSA selection (top-k 2,048) and IndexShare; 64 heads, 512-dimensional KV latent |
| Experts | 128 routed (top-4) and one shared; the first layer uses a dense FFN |
| Positions | Trainable LeRoPE/YaRN, periodic NoPE layers, SSMax, cross-layer KV sharing from layer 35 |
| Vision | 30 layers, hidden size 2,048, 16 heads, patch size 14, 2x2 patch merger |
| Output | Logit soft cap 30 |
| Checkpoint precision | FP8 linear and expert weights with FP32 scales; BF16 vision and projector |
