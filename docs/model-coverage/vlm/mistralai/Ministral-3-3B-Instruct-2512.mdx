[Ministral3](https://mistral.ai/news/ministraux/) is Mistral AI's efficient small model series. The vision-capable variants support image-text inputs for multimodal tasks.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run automodel examples/llm_finetune/mistral/ministral3_3b_squad_peft.yaml --nproc-per-node 8
```

## Model Context

Ministral-3-3B-Instruct-2512 is used for image-text-to-text. Its model size is 3B parameters.

| Property | Value |
| --- | --- |
| Task | Image-Text-to-Text |
| **Architecture** | `Mistral3ForConditionalGeneration` |
| Parameters | 3B |
| Hugging Face Organization | [mistralai](https://huggingface.co/mistralai) |
| Decoder Layers | 26 |
| Hidden Size | 3,072 |
| Attention | 32 attention heads / 8 key-value heads |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 131,072 |
| Configured Dtype | `bfloat16` |
