[Mistral-Medium-3.5-128B](https://huggingface.co/mistralai/Mistral-Medium-3.5-128B) has a checked-in NeMo AutoModel recipe for image-text-to-text.
The Hugging Face configuration declares the `Mistral3ForConditionalGeneration` architecture.

## Fine-Tune Mistral-Medium-3.5-128B

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
uv run automodel <recipe-path>
```

Use the [Slurm launcher guide](/job-launchers/slurm-cluster) for the multi-node run.

## Standard Recipe Configuration

Start with the [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/vlm_finetune/mistral3p5/mistral3p5_128b_medpix.yaml).

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=8, pp_size=8, cp_size=1, ep_size=1 |
| Nodes | 8 |
| Features | Activation checkpointing (activation_checkpointing=true) |
| Advanced | torch.bfloat16 |
