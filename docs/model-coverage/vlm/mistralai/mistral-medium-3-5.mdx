[Devstral-2-123B-Instruct-2512](https://huggingface.co/mistralai/Devstral-2-123B-Instruct-2512) is a text-only, code-focused checkpoint from Mistral AI. NeMo AutoModel includes a LoRA fine-tuning recipe for the checkpoint.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Fine-Tune Devstral-2-123B-Instruct-2512

Run the checked-in recipe on one node with eight GPUs:

```bash
uv run automodel examples/llm_finetune/devstral/devstral2_123b_2512_squad_peft.yaml \
  --nproc-per-node 8
```
