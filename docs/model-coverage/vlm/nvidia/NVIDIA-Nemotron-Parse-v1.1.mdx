[Nemotron-Parse-v1.1](https://huggingface.co/nvidia/NVIDIA-Nemotron-Parse-v1.1) is NVIDIA's document parsing VLM, specializing in extracting structured information from complex documents including tables, forms, and mixed-content PDFs.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/vlm_finetune/nemotron/nemotron_parse_v1_1.yaml
```

## Model Context

The example uses eight GPUs with fully sharded data parallelism (FSDP2). It fine-tunes the language model on CORD-v2 while keeping the vision encoder frozen, and saves checkpoints to `vlm_checkpoints/`.

| Property | Value |
| --- | --- |
| Task | Document Parsing |
| **Architecture** | `NemotronParseForConditionalGeneration` |
| Parameters | < 1B |
| Hugging Face Organization | [nvidia](https://huggingface.co/nvidia) |
| Context Length | 9,000 tokens (checkpoint configuration) |
| Vocabulary Size | 52,327 |
| Configured Dtype | `bfloat16` |
