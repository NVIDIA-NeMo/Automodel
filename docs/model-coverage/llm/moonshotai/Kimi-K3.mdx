[Kimi K3](https://huggingface.co/moonshotai/Kimi-K3) is Moonshot AI's 2.8T-parameter, 104B-active Mixture-of-Experts model. NeMo AutoModel provides a native implementation of the text model and loads its public checkpoint without `trust_remote_code`.

## Quick Start

Fine-tune on HellaSwag using the recipe's 64-node NVIDIA GB200 setup with four GPUs per node. Complete the prerequisites in [Model Context](#model-context), then run this command from the repository root on every node:

```bash
uv run torchrun --nnodes 64 --nproc-per-node 4 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/kimi/k3_hellaswag.yaml
```

## Model Context

The recipe fine-tunes Kimi-K3's text decoder for text generation. Its mixture-of-experts (MoE) architecture combines Kimi Delta Attention with Gated Multi-head Latent Attention.

| Property | Value |
|---|---|
| **Task** | Text Generation (MoE, hybrid attention) |
| **Architecture** | `KimiK3ForCausalLM` |
| **Parameters** | 2.8T total / 104B activated |
| **Layers** | 93 (69 KDA + 24 Gated MLA) |
| **Context Length** | 1,048,576 tokens |
| **HF Org** | [moonshotai](https://huggingface.co/moonshotai) |
| Hidden Size | 7,168 |
| Attention | 96 attention heads / 96 key-value heads |
| Vocabulary Size | 163,840 |
| Experts | 896 routed / 2 shared / 16 selected per token |
| Configured Dtype | `bfloat16` |

### Prepare to Launch

As configured, the [example recipe](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/kimi/k3_hellaswag.yaml) stops after 100 steps (`step_scheduler.max_steps: 100`) and does not save trained weights (`checkpoint.enabled: false`).

1. [Install NeMo AutoModel](/get-started/installation) and make the repository checkout available on every node.
2. Set `NODE_RANK` to a unique integer from `0` to `63` on each node.
3. Set `MASTER_ADDR` on every node to the same hostname or IP address of the rank-zero node, reachable by all nodes. Ensure port `29500` is available for the rendezvous.

See the [Slurm Launcher Guide](/job-launchers/slurm-cluster) for cluster setup and the [Large MoE Fine-Tuning Guide](/recipes-e2e-examples/large-moe-fine-tuning) for distributed configuration.

### Architecture

- Hybrid attention uses groups of three Kimi Delta Attention (KDA) layers followed by a Gated Multi-head Latent Attention (MLA) layer, with an additional Gated MLA layer at the end.
- Attention Residuals operate over 12-layer blocks. Pipeline stages preserve these block boundaries and carry the residual state between stages.
- Stable LatentMoE routes each token to 16 of 896 routed experts and includes two shared experts. The expert MLPs use SiTU-GLU.
- The released checkpoint uses MXFP4 weights. The example recipe dequantizes the base checkpoint while loading it for BF16 training.

### Parallelism

| Parallelism | Validated Configuration |
|---|---|
| FSDP2 | Full-parameter training |
| Expert Parallelism | EP32 |
| Pipeline Parallelism | PP8 with Attention Residual block-aligned stages |
| Context Parallelism | CP2 full-model loss parity at 2K sequence length |

The combined EP32 and PP8 configuration is validated on 256 GB200 GPUs.
