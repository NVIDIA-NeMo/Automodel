[Moonlight-16B-A3B](https://huggingface.co/moonshotai/Moonlight-16B-A3B) is a Mixture-of-Experts language model from Moonshot AI with 16B total parameters and 3B active parameters. Moonshot AI reports training it on 5.7T tokens with the Muon optimizer.

NeMo AutoModel includes standard and packed-sequence fine-tuning recipes, an 8-GPU pretraining template, and Tulu-3 convergence configurations for the base checkpoint.

## Quick start: fine-tune Moonlight

Run the standard fine-tuning recipe with `--nproc-per-node 8`:

```bash
git clone https://github.com/NVIDIA-NeMo/Automodel.git
cd Automodel
uv sync --locked --all-groups --all-extras
uv run automodel examples/llm_finetune/moonlight/moonlight_16b_te.yaml --nproc-per-node 8
```

To use packed sequences, run:

```bash
uv run automodel examples/llm_finetune/moonlight/moonlight_16b_te_packed_sequence.yaml --nproc-per-node 8
```

## What this command runs

The runnable example uses [`moonlight_16b_te.yaml`](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/moonlight/moonlight_16b_te.yaml).

| Setting | Configuration |
|---|---|
| Hardware | 8 GPUs in the example command; adjust `--nproc-per-node` to the GPUs available |
| Strategy | FSDP2; TP=1, PP=1, CP=1, EP=8 |
| Nodes | Single node in the local AutoModel CLI workflow |
| Features | Transformer Engine attention, linear layers, and experts; DeepEP dispatch; FSDP optimizations |
| Advanced | HellaSwag; `packed_sequence_size=0`; Adam with `lr=1.0e-4` and `foreach=false` |

### Parallelism and backend settings

| Capability | Moonlight configuration |
|---|---|
| Expert parallelism | Supported; the included recipes use EP=8 |
| Context parallelism | Supported; the Tulu-3 configurations include CP=1 and CP=2 |
| Pipeline parallelism | Supported; the included recipes use PP=1 |
| Tensor parallelism | Disabled for this model; the included recipes use TP=1 |

The standard fine-tuning recipe uses Transformer Engine experts. The packed and Tulu-3 recipes use `torch_mm` experts. Both fine-tuning recipes use Transformer Engine for attention and linear layers and use DeepEP for expert dispatch.

## Configuration notes

### Packed sequences

The packed recipe uses THD collation with `packed_sequence_size: 1024` and `torch_mm` experts.

<Warning>

Keep `rope_fusion: false` for the packed recipe. Its configuration disables fused Transformer Engine RoPE because that path can produce NaN/Inf values for the MLA `k_pe` tensor in THD mode.

</Warning>

### Pretraining

The pretraining template initializes Moonlight from its Hugging Face configuration and uses FSDP2 with DP=8 and EP=8 on one 8-GPU node. Replace the dataset and index-mapping paths before submitting it through Slurm.

### Tulu-3 training example

The Moonlight Tulu-3 report covers EP=8 runs on 8 GPUs through step 999, including a CP=2 run. All three configurations report training loss decreasing from 0.875 at step 0 to 0.570 at step 999.

| Configuration | CP | Validation loss | IFEval prompt strict | IFEval instruction strict |
|---|---:|---:|---:|---:|
| TE FusedAdam | 1 | 0.655 | 0.381 | 0.534 |
| FlashAdamW | 1 | 0.657 | 0.412 | 0.559 |
| FlashAdamW | 2 | 0.656 | 0.573 | 0.668 |

The Tulu-3 workflow uses Moonlight's TikToken tokenizer with `trust_remote_code: true`. Its evaluation command stops generation at `<|im_end|>`, and its training data is prefiltered to a 2,048-token sequence length to limit memory spikes from the 163,840-token vocabulary.

## Model reference

### Model architecture

| Property | Value |
|---|---|
| Hugging Face architecture | `DeepseekV3ForCausalLM` |
| Parameters | 16B total / 3B active |
| Decoder layers | 27 |
| Hidden size | 2,048 |
| Attention | 16 attention heads and 16 key-value heads |
| Feed-forward sizes | 11,264 dense / 1,408 per expert |
| Experts | 64 routed / 2 shared / 6 selected per token |
| Context length | 8,192 tokens |
| Vocabulary size | 163,840 |
| Weight dtype | `bfloat16` |
| Upstream training | 5.7T tokens with Muon |
