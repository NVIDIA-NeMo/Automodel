[Kimi-K2-Base](https://huggingface.co/moonshotai/Kimi-K2-Base) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `DeepseekV3ForCausalLM` architecture.

## Fine-Tune Kimi-K2-Base

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_benchmark/kimi/kimi_k2_te_deepep.yaml --nproc-per-node 8
```

Use the [Slurm launcher guide](/job-launchers/slurm-cluster) for the multi-node run.

## Standard Recipe Configuration

Start with the [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_benchmark/kimi/kimi_k2_te_deepep.yaml).

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, pp_size=8, cp_size=1, ep_size=32 |
| Nodes | 32 |
| Features | Activation checkpointing (activation_checkpointing=true), Transformer Engine, DeepEP (dispatcher=deepep) |
| Advanced | attention=te, linear=te, experts=gmm, dispatcher=deepep |
