[Kimi-K2-Base](https://huggingface.co/moonshotai/Kimi-K2-Base) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `DeepseekV3ForCausalLM` architecture.

## Quick Start

Allocate 32 nodes with 8 GPUs each. Set `NODE_RANK` and `MASTER_ADDR` on every node; complete the recipe prerequisites in Model Context before launching.

```bash
uv run torchrun --nnodes 32 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_benchmark/kimi/kimi_k2_te_deepep.yaml
```
