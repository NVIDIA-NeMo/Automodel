[Seed-OSS-36B-Instruct](https://huggingface.co/ByteDance-Seed/Seed-OSS-36B-Instruct) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `SeedOssForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then launch full fine-tuning on HellaSwag from the repository root with eight GPUs:

```bash
automodel examples/llm_finetune/seed/seed_oss_36B_hellaswag.yaml --nproc-per-node 8
```

## Model Context

Seed-OSS-36B-Instruct is used for text generation. Its model size is 36.15B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `SeedOssForCausalLM` |
| Parameters | 36.15B checkpoint parameters |
| Decoder Layers | 64 |
| Hidden Size | 5,120 |
| Attention | 80 attention heads / 8 key-value heads |
| Context Length | 524,288 tokens (checkpoint configuration) |
| Vocabulary Size | 155,136 |
| Configured Dtype | `bfloat16` |

### Configuration

The table describes the full fine-tuning recipe used in Quick Start. The low-rank adaptation (LoRA) recipe instead sets `tp_size=1` and uses rank-8 adapters (`dim=8`, `alpha=32`).

| Setting | Configuration |
| --- | --- |
| Hardware | GPU model and memory not specified in the recipe |
| Strategy | Fully Sharded Data Parallel (FSDP2); `tp_size=8`, `cp_size=1` |
| Nodes | Not specified in the recipe |
| Features | Sequence parallelism and sequence packing disabled |
| Advanced | `torch.compile` disabled |
