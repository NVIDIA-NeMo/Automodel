[Cohere Command-R](https://cohere.com/command) is a series of enterprise-grade language models optimized for retrieval-augmented generation (RAG) and tool use. Command-R7B uses the updated `Cohere2ForCausalLM` architecture.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Fine-Tune c4ai-command-r-v01

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/cohere/cohere_command_r_7b_squad.yaml
```
