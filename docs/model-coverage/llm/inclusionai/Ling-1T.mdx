[Ling-1T](https://huggingface.co/inclusionAI/Ling-1T) has NeMo AutoModel recipes for full fine-tuning and low-rank adaptation (LoRA) for text generation.
The Hugging Face configuration declares the `BailingMoeV2ForCausalLM` architecture.

## Quick Start

Complete the prerequisites in [Model Context](#model-context). From the repository root on each of the 32 nodes, run the following command to fully fine-tune Ling-1T on HellaSwag with 8 GPUs per node.

```bash
uv run torchrun --nnodes 32 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/ling/ling_1t_sft.yaml
```

## Model Context

Ling-1T is used for text generation. Its model size is 999.71B checkpoint parameters.
In the workflow table, PP denotes pipeline parallelism and EP denotes expert parallelism.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `BailingMoeV2ForCausalLM` |
| Parameters | 999.71B checkpoint parameters |
| Decoder Layers | 80 |
| Hidden Size | 8,192 |
| Attention | 64 attention heads / 8 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 157,184 |
| Experts | 256 routed / 1 shared / 8 selected per token |
| Configured Dtype | `bfloat16` |

### Prepare the Recipe Environment

The full fine-tuning recipe documents 32 nodes with 8 H100 80 GB GPUs per node. The LoRA recipe documents 8 nodes with 8 H100 80 GB GPUs per node. These are recipe configurations, not general hardware minimums.

Follow the [installation instructions](/get-started/installation) and use the same NeMo AutoModel environment with Transformer Engine and HybridEP on every node.
For the Quick Start, set `NODE_RANK` to a unique value from `0` to `31` on each node and `MASTER_ADDR` to the same reachable address of node `0`.
Export the full fine-tuning recipe's required HybridEP settings on every node before launching:

```bash
export NUM_OF_HYBRID_EP_RANKS_PER_NVLINK_DOMAIN=8
export NUM_OF_STAGES_G2S_COMBINE_API=4
```

### Full Fine-Tuning Configuration

| Setting | Configuration |
| --- | --- |
| Hardware | H100 GPUs with 80 GB each; 8 GPUs per node |
| Strategy | Fully Sharded Data Parallel (FSDP2); `tp_size=1`, `pp_size=4`, `cp_size=1`, `ep_size=64` |
| Nodes | 32 |
| Features | Checkpointing (`enabled=true`), activation checkpointing (`activation_checkpointing=true`), Transformer Engine, HybridEP (`dispatcher=hybridep`) |
| Advanced | `bfloat16`, `attn=sdpa`, `linear=te`, `experts=torch_mm`, `dispatcher=hybridep` |
