[Ling-flash-2.0](https://huggingface.co/inclusionAI/Ling-flash-2.0) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `BailingMoeV2ForCausalLM` architecture.

## Fine-Tune Ling-flash-2.0

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/ling/ling_flash_2_0_sft.yaml --nproc-per-node 8
```

Use the [Slurm launcher guide](/job-launchers/slurm-cluster) for the multi-node run.

## Standard Recipe Configuration

Start with the [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/ling/ling_flash_2_0_sft.yaml).

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, pp_size=1, cp_size=1, ep_size=32 |
| Nodes | 4 |
| Features | Checkpointing (enabled=true), Activation checkpointing (activation_checkpointing=true), Transformer Engine, HybridEP (dispatcher=hybridep) |
| Advanced | bfloat16, attention=te, linear=torch, experts=torch_mm, dispatcher=hybridep |
