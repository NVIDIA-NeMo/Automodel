[Ling-flash-2.0](https://huggingface.co/inclusionAI/Ling-flash-2.0) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `BailingMoeV2ForCausalLM` architecture.

## Quick Start

Complete the [prerequisites](#prerequisites). From the repository root, run full fine-tuning on HellaSwag on each of 4 nodes with 8 GPUs. Set `NODE_RANK` to a unique value from `0` to `3` and `MASTER_ADDR` to node 0's reachable address on every node.

```bash
uv run torchrun --nnodes 4 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/ling/ling_flash_2_0_sft.yaml
```

## Model Context

Ling-flash-2.0 is used for text generation. Its model size is 102.89B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `BailingMoeV2ForCausalLM` |
| Parameters | 102.89B checkpoint parameters |
| Decoder Layers | 32 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads / 4 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 157,184 |
| Experts | 256 routed / 1 shared / 8 selected per token |
| Configured Dtype | `bfloat16` |

### Prerequisites

Follow the [installation guide](/get-started/installation) and use the same repository checkout and NeMo AutoModel environment on every node. Both recipes select Transformer Engine attention; ensure HybridEP is installed for full fine-tuning and DeepEP for LoRA. The recipes load the checkpoint and the `rowan/hellaswag` dataset from Hugging Face.

### Configuration

The following settings describe the full fine-tuning recipe. Both recipes use Fully Sharded Data Parallel v2 (FSDP2); expert parallelism (EP) spans 32 ranks for full fine-tuning and 8 ranks for LoRA.

| Setting | Configuration |
| --- | --- |
| Hardware | 32 H100 GPUs with 80 GB each (recipe recommendation) |
| Strategy | FSDP2; `tp_size=1`, `pp_size=1`, `cp_size=1`, `ep_size=32` |
| Nodes | 4 |
| Features | Checkpointing (`checkpoint.enabled=true`), activation checkpointing (`activation_checkpointing=true`), Transformer Engine, HybridEP (`dispatcher=hybridep`) |
| Advanced | `bfloat16`, `attn=te`, `linear=torch`, `experts=torch_mm`, `dispatcher=hybridep` |
