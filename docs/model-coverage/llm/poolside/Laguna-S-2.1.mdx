[Laguna S 2.1](https://huggingface.co/poolside/Laguna-S-2.1) belongs to Poolside's mixture-of-experts (MoE) language model family with hybrid attention. NeMo AutoModel supports full supervised fine-tuning (SFT) with expert parallelism (EP) for Laguna S 2.1 and Laguna XS 2.1.

## Quick Start

Follow the [installation instructions](/get-started/installation). For this recipe's example topology, allocate two nodes with eight GPUs each and complete the [recipe setup](#recipe-setup). From the repository root, run this command on both nodes to fine-tune on HellaSwag:

```bash
uv run torchrun --nnodes 2 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/laguna/laguna_s_2p1_hellaswag_ep16.yaml
```

## Model Context

Laguna-S-2.1 is a text-generation model with hybrid attention and 117.56B checkpoint parameters.

| Property | Value |
|---|---|
| **Task** | Text Generation (MoE, hybrid attention) |
| **Architecture** | `LagunaForCausalLM` |
| **Checkpoints** | [Laguna S 2.1](https://huggingface.co/poolside/Laguna-S-2.1) (118B total, ~8B activated); [Laguna XS 2.1](https://huggingface.co/poolside/Laguna-XS-2.1) (33B total, ~3B activated) |
| **Hugging Face Organization** | [poolside](https://huggingface.co/poolside) |
| Parameters | 117.56B checkpoint parameters |
| Decoder Layers | 48 |
| Hidden Size | 3,072 |
| Attention | 48 query heads in full-attention layers; 72 in sliding-window layers; 8 key-value heads in both |
| Context Length | 1,048,576 tokens (checkpoint configuration) |
| Vocabulary Size | 100,352 |
| Experts | 256 routed experts; 10 selected per token; 1 shared expert |
| Configured Dtype | `bfloat16` |

### Architecture

- `LagunaForCausalLM`
- Layer-specific attention head counts, QK RMSNorm, and softplus attention output gating.
- Full and sliding-window attention layers can use separate RoPE settings.
- MoE blocks use `nemo_automodel.components.moe.layers.MoE` with sigmoid routing, top-k probability normalization, fp32 gate compute, correction bias loading, one shared expert, and grouped expert weights for EP.

### Run the Laguna XS Example

```bash
# Laguna XS 2.1 on one 8-GPU node
uv run automodel --nproc-per-node=8 examples/llm_finetune/laguna/laguna_xs_2p1_hellaswag_ep8.yaml
```

The Laguna XS 2.1 recipe uses `ep_size: 8` on one 8-GPU node and packs documents into 1,024-token sequences with `packing_strategy: neat`. Laguna currently supports expert parallelism, but not native THD packing or context parallelism; keep `cp_size: 1`. For Laguna S 2.1, use the two-node command in [Quick Start](#quick-start) for the default `ep_size: 16`.

### Recipe Setup

Use the [Slurm launcher guide](/job-launchers/slurm-cluster) to prepare the distributed allocation. On the two Laguna S nodes, set `NODE_RANK` to `0` and `1`, respectively, and set `MASTER_ADDR` on both nodes to the address of node 0 that both nodes can reach. Both nodes must use port `29500` for the rendezvous and have NeMo AutoModel installed with access to the recipe and Hugging Face downloads.

### Workflow Notes

Both recipes load pretrained weights and train on the `rowan/hellaswag` dataset for at most 100 steps. They set `checkpoint.enabled: false`, so they do not save fine-tuned model checkpoints. Enable checkpoint saving before launching if you need to retain the trained weights.
