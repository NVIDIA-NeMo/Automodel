[Hy-MT2-30B-A3B](https://huggingface.co/tencent/Hy-MT2-30B-A3B) is Tencent's mixture-of-experts (MoE) translation model with 30B total parameters and 3B active parameters per token. Its checkpoint configuration specifies 48 transformer layers and a maximum context length of 262,144 tokens.

## Quick Start

Follow the [NeMo AutoModel Installation Guide](/get-started/installation), including the `cuda` extra for Transformer Engine. From the repository root, run this eight-GPU example:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/hy_mt2/hy_mt2_30b_a3b_sft.yaml
```

## Model Context

The example loads pretrained weights and fine-tunes all model parameters on HellaSwag for up to 100 steps.

| Property | Value |
| --- | --- |
| Task | Translation |
| Architecture | `HyMT2ForCausalLM` (AutoModel implementation) |
| Checkpoint Architecture | `HYV3ForCausalLM` (resolved to `HyMT2ForCausalLM` by AutoModel) |
| Parameters | 30B total; 3B active per token |
| Hugging Face Organization | [tencent](https://huggingface.co/tencent) |
| Decoder Layers | 48 (1 dense layer followed by 47 MoE layers) |
| Hidden Size | 2,048 |
| Attention | Grouped query attention with 32 query heads and 4 key-value heads |
| Attention Normalization | Per-head query and key RMS normalization |
| Position Embeddings | Rotary position embeddings (RoPE) |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 120,832 |
| Experts | 128 routed experts and 1 shared expert; 8 routed experts selected per token with sigmoid routing |

The example uses Fully Sharded Data Parallelism version 2 (FSDP2) with expert parallelism across eight GPUs (EP8), BF16 weights, and activation checkpointing. The YAML targets eight GPUs with at least 80 GB of memory each.

The recipe sets `distributed.moe.lm_head_precision: float32` to run the language-model head in FP32. The model casts hidden states to FP32 for this projection and casts logits back to the hidden states' original dtype.

### Prepare the Environment

Set up NeMo AutoModel with the [NeMo AutoModel container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation) with the `cuda` extra, which is also included in the `all` bundle. The recipe selects Transformer Engine attention (`model.backend.attn: te`), which requires this optional dependency.
