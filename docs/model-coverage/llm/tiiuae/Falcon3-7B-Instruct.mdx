[Falcon3-7B-Instruct](https://huggingface.co/tiiuae/Falcon3-7B-Instruct) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `LlamaForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/falcon/falcon3_7b_instruct_squad.yaml --nproc-per-node 8
```
