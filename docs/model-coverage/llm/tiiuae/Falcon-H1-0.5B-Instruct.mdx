[Falcon-H1-0.5B-Instruct](https://huggingface.co/tiiuae/Falcon-H1-0.5B-Instruct) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `FalconH1ForCausalLM` architecture.

## Quick Start

After [installing NeMo AutoModel](/get-started/installation), run full fine-tuning on SQuAD from the repository root. This example launches on one node with eight GPUs:

```bash
automodel examples/llm_finetune/falcon/falcon_h1_0p5b_instruct_squad.yaml --nproc-per-node 8
```
