[Falcon-H1-34B-Instruct](https://huggingface.co/tiiuae/Falcon-H1-34B-Instruct) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `FalconH1ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/falcon/falcon_h1_34b_instruct_squad_peft.yaml --nproc-per-node 8
```
