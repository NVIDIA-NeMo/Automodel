[Falcon-H1-34B-Instruct](https://huggingface.co/tiiuae/Falcon-H1-34B-Instruct) has a checked-in NeMo AutoModel recipe for low-rank adaptation (LoRA) fine-tuning on SQuAD.
The Hugging Face configuration declares the `FalconH1ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run LoRA fine-tuning on SQuAD from the repository root. This example launches eight GPU processes on one node:

```bash
automodel examples/llm_finetune/falcon/falcon_h1_34b_instruct_squad_peft.yaml --nproc-per-node 8
```

## Model Context

Falcon-H1-34B-Instruct combines Transformer attention and Mamba state space layers for text generation. Its checkpoint contains 33.64B parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `FalconH1ForCausalLM` |
| Parameters | 33.64B checkpoint parameters |
| Decoder Layers | 72 |
| Hidden Size | 5,120 |
| Attention | 20 attention heads and 4 key-value heads |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 261,120 |
| Configured Dtype | `bfloat16` |

### Configuration

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs in the example launch; GPU model unspecified |
| Strategy | Fully Sharded Data Parallel (FSDP2); tensor parallel size `tp_size=4`, context parallel size `cp_size=1` |
| Nodes | 1 |
| Features | LoRA |
| Precision | `bfloat16` (`bf16` in the recipe) |

### Workflow Notes

The recipe loads pretrained weights and fine-tunes on SQuAD for 100 steps. Checkpoint saving is disabled (`checkpoint.enabled: false`), so this example does not save fine-tuned weights. Set `checkpoint.enabled: true` in the YAML to save checkpoints.
