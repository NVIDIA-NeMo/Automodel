[Falcon-H1-1.5B-Deep-Instruct](https://huggingface.co/tiiuae/Falcon-H1-1.5B-Deep-Instruct) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `FalconH1ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/falcon/falcon_h1_1p5b_instruct_squad.yaml --nproc-per-node 8
```

## Model Context

Falcon-H1-1.5B-Deep-Instruct is used for text generation. Its model size is 1.55B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `FalconH1ForCausalLM` |
| Parameters | 1.55B checkpoint parameters |
| Decoder Layers | 66 |
| Hidden Size | 1,280 |
| Attention | 6 attention heads / 2 key-value heads |
| Context Length | 131,072 tokens (checkpoint configuration) |
| Vocabulary Size | 65,537 |
| Configured Dtype | `bfloat16` |
