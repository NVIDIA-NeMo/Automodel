[Falcon](https://falconllm.tii.ae/) is a series of open language models from the Technology Innovation Institute (TII) in Abu Dhabi, known for being trained on a high-quality curated web corpus (RefinedWeb).

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Fine-Tune falcon-7b

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/falcon/falcon3_7b_instruct_squad.yaml
```
