[Bamba](https://huggingface.co/ibm-ai-platform/Bamba-9B) is a hybrid SSM-attention language model from IBM, combining Mamba-2 selective state space layers with standard transformer attention for efficient long-context processing.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/ibm_ai_platform/bamba_9b_squad_peft.yaml --nproc-per-node 8
```

## Model Context

Bamba-9B is used for text generation. Its model size is 9B parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `BambaForCausalLM` |
| Parameters | 9B |
| Hugging Face Organization | [ibm-ai-platform](https://huggingface.co/ibm-ai-platform) |
| Decoder Layers | 32 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads / 8 key-value heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 128,256 |
