[T5](https://huggingface.co/google-t5/t5-small) is a compact member of Google's encoder-decoder text-to-text transformer family.

## Quick Start

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/t5/t5_small_squad.yaml
```

## Model Context

t5-small is used for text-to-text generation. Its model size is 60.5M checkpoint parameters.

| Property | Value |
|---|---|
| **Task** | Text-to-Text Generation |
| **Architecture** | `T5ForConditionalGeneration` |
| **HF Org** | [google-t5](https://huggingface.co/google-t5) |
| Parameters | 60.5M checkpoint parameters |
| Decoder Layers | 6 |
| Hidden Size | 512 |
| Attention | 8 attention heads |
| Context Length | 512 tokens (checkpoint configuration) |
| Vocabulary Size | 32,128 |
