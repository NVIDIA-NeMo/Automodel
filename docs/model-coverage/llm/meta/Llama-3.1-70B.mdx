[Llama-3.1-70B](https://huggingface.co/meta-llama/Llama-3.1-70B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `LlamaForCausalLM` architecture.

## Quick Start


This launches packed-sequence fine-tuning on SQuAD across four nodes with eight
GPUs each. Follow the [installation instructions](/get-started/installation)
and complete [recipe setup](#recipe-setup). From the repository root, run on
each node with `MASTER_ADDR` and `NODE_RANK` set:

```bash
uv run torchrun --nnodes 4 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" \
  --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_pretrain/llama3_70b_pretrain.yaml
```

## Model Context

Llama-3.1-70B is used for text generation. Its model size is 70.55B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `LlamaForCausalLM` |
| Parameters | 70.55B checkpoint parameters |

### Recipe Setup

Set `MASTER_ADDR` to the first node hostname and give each node its own `NODE_RANK` from 0 to 3. The recipe configures DP2, TP4, and PP4 for 32 GPU processes.

Read [llama3_70b_pretrain.yaml](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_pretrain/llama3_70b_pretrain.yaml) for checkpoint access, data paths, and backend dependencies.
