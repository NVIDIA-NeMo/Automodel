[Llama-3.1-70B](https://huggingface.co/meta-llama/Llama-3.1-70B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `LlamaForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run automodel examples/llm_pretrain/llama3_70b_pretrain.yaml --nproc-per-node 8
```
