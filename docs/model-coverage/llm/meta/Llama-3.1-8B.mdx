[Llama-3.1-8B](https://huggingface.co/meta-llama/Llama-3.1-8B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `LlamaForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/llama3_1/llama3_1_8b_squad_qlora.yaml --nproc-per-node 8
```

## Model Context

Llama-3.1-8B is used for text generation. Its model size is 8.03B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `LlamaForCausalLM` |
| Parameters | 8.03B checkpoint parameters |
| Decoder Layers | 32 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads / 8 key-value heads |
| Context Length | 131,072 tokens (checkpoint configuration) |
| Vocabulary Size | 128,256 |
| Configured Dtype | `bfloat16` |
