NeMo AutoModel provides SQuAD recipes for full fine-tuning and low-rank adaptation (LoRA) of [Llama-3.2-3B-Instruct](https://huggingface.co/meta-llama/Llama-3.2-3B-Instruct).
The Hugging Face configuration declares the `LlamaForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). Request access to the [gated checkpoint](https://huggingface.co/meta-llama/Llama-3.2-3B-Instruct) and authenticate with a token from the approved account using `HF_TOKEN`. From the repository root, launch full fine-tuning on SQuAD with the recipe's example setup of eight GPUs on one node:

```bash
automodel examples/llm_finetune/llama3_2/llama_3_2_3b_instruct_squad.yaml --nproc-per-node 8
```

## Model Context

Llama-3.2-3B-Instruct is used for text generation. Its model size is 3.21B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `LlamaForCausalLM` |
| Parameters | 3.21B checkpoint parameters |
| Decoder Layers | 28 |
| Hidden Size | 3,072 |
| Attention | 24 attention heads and 8 key-value heads |
| Context Length | 131,072 tokens (checkpoint configuration) |
| Vocabulary Size | 128,256 |
| Configured Dtype | `bfloat16` |

### Recipe Configuration

Both recipes use Fully Sharded Data Parallel (FSDP2). These settings describe the checked-in recipes and their example launch.

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs in the example launch; GPU model not specified |
| Strategy | FSDP2; `tp_size: 1`, `cp_size: 1` |
| Nodes | 1 in the example launch |
| Features | Checkpointing (`enabled: true`) |
| Precision | `bf16` |
