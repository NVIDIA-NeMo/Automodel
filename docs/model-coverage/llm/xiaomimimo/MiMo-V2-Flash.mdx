[MiMo-V2-Flash](https://huggingface.co/XiaomiMiMo/MiMo-V2-Flash) is a Mixture-of-Experts (MoE) language model with a hybrid attention architecture. It interleaves sliding-window and global attention.

NeMo AutoModel also includes text and vision-language fine-tuning recipes for [MiMo-V2.6-Flash-RL](https://huggingface.co/XiaomiMiMo/MiMo-V2.6-Flash-RL).

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

Fine-tune MiMo-V2-Flash on HellaSwag using the recipe's 16-node, 8-GPU-per-node setup. Complete the [recipe setup](#recipe-setup), then run this command from the repository root on every node with `NODE_RANK` and `MASTER_ADDR` set.

```bash
uv run torchrun --nnodes 16 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/mimo_v2_flash/mimo_v2_flash_hellaswag.yaml
```

## Model Context

MiMo-V2-Flash is used for text generation. Its model size is 309.79B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| Model Implementation | `MiMoV2FlashForCausalLM` backs MiMo-V2-Flash. |
| Model Implementation | `MiMoV2ForCausalLM` backs MiMo-V2.6-Flash-RL. |
| Sliding-Window Attention | Sliding-window attention uses the `MiMoV2FlashAttention(is_swa=True)` path. |
| Expert Routing | Expert routing maps `scoring_func="sigmoid"` to `score_func="sigmoid_with_bias"`; the recipes set `gate_precision=float32`. |
| **Architecture** | `MiMoV2FlashForCausalLM` |
| Parameters | 309.79B checkpoint parameters |
| Decoder Layers | 48 |
| Hidden Size | 4,096 |
| Attention | 64 attention heads; 4 key-value heads for global attention and 8 for sliding-window attention |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 152,576 |
| Experts | 256 routed / 8 selected per token |
| Configured Dtype | `bfloat16` |

PP, CP, and EP in the workflow table refer to pipeline, context, and expert parallelism.

### Recipe Setup

1. Follow the [installation instructions](/get-started/installation) and make the repository available on each node. All three recipes require HybridEP built for multi-node execution (`backend.dispatcher: hybridep`), which the AutoModel container build includes. For a source installation, include the `moe` extra and build HybridEP with `HYBRID_EP_MULTINODE=1`, providing the RDMA/libibverbs and NVSHMEM communication dependencies shown in the [Dockerfile](https://github.com/NVIDIA-NeMo/Automodel/blob/c79ba55eb77527138337288220df04bc5939483c/docker/Dockerfile#L150-L181). Selecting `moe` alone does not enable multi-node support.
2. For either MiMo-V2.6-Flash-RL recipe, install Transformer Engine for `backend.attn: te` and `cut-cross-entropy` for `FusedLinearCrossEntropy`. Transformer Engine is in the `cuda` extra, which `moe` includes. `cut-cross-entropy` is in the `dev` dependency group; include it with `--group dev` or `--all-groups` when running `uv sync`.
3. Prepare the allocation using the [Slurm launcher guide](/job-launchers/slurm-cluster). The HellaSwag example uses 16 nodes with 8 H100 GPUs each; the MiMo-V2.6 examples use 8 nodes with 8 H100 GPUs each. These are recipe configurations, not minimum hardware requirements.
4. For the Quick Start, set `NODE_RANK` to a unique value from `0` through `15` on each node. Set `MASTER_ADDR` to the rank-zero node's address, reachable from every node, and use the same master port on all nodes.

### Training and Checkpoints

All three recipes load pretrained weights with `load_base_model: true`. The MedPix-VQA recipe freezes the vision tower while training the language model.

The HellaSwag recipe enables checkpoint saving to `checkpoints/mimo_v2_flash`. Both MiMo-V2.6-Flash-RL recipes run for up to 100 steps with `checkpoint.enabled: false`, so they do not save trained weights. Enable checkpoint saving and choose a save schedule before using either recipe to produce a reusable checkpoint.
