[Mistral AI](https://mistral.ai/) models are efficient transformer decoder models featuring sliding window attention for long context support. Mistral-Nemo is a 12B model developed jointly with NVIDIA.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Fine-Tune Mistral-7B-v0.1

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/mistral/mistral_7b_squad.yaml
```
