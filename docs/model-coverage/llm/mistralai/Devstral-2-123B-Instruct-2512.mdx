[Devstral-2-123B-Instruct-2512](https://huggingface.co/mistralai/Devstral-2-123B-Instruct-2512) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Ministral3ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/devstral/devstral2_123b_2512_squad_peft.yaml --nproc-per-node 8
```

## Model Context

Devstral-2-123B-Instruct-2512 is used for text generation. Its model size is 125.03B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `Ministral3ForCausalLM` |
| Parameters | 125.03B checkpoint parameters |
| Decoder Layers | 88 |
| Hidden Size | 12,288 |
| Attention | 96 attention heads and 8 key-value heads |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 131,072 |
| Configured Dtype | `bfloat16` |

### Configuration

The checked-in recipe specifies the following example setup.

| Setting | Configuration |
| --- | --- |
| Hardware | 8 NVIDIA H100 80 GB GPUs |
| Strategy | Fully Sharded Data Parallel v2 (FSDP2); `tp_size=8`, `pp_size=1`, `cp_size=1`, `ep_size=1` |
| Nodes | 1 |
| Features | Checkpointing (`enabled=true`), activation checkpointing (`activation_checkpointing=true`), LoRA |
| Advanced | `bfloat16` |

### Workflow Notes

The checkpoint stores FP8 weights. The recipe loads each rank's shard and dequantizes it to `bfloat16`. Leave `model.force_hf` and `model.quantization_config` unset, as in the recipe, to retain this loading path.
