[Mixtral-8x7B-Instruct-v0.1](https://huggingface.co/mistralai/Mixtral-8x7B-Instruct-v0.1) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `MixtralForCausalLM` architecture.

## Quick Start

### Fine-Tune Mixtral-8x7B-Instruct-v0.1

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/mistral/mixtral-8x7b-v0-1_squad_peft.yaml --nproc-per-node 8
```

Use the [Slurm launcher guide](/job-launchers/slurm-cluster) for the multi-node run.
