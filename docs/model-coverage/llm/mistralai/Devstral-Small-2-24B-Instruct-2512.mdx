[Devstral-Small-2-24B-Instruct-2512](https://huggingface.co/mistralai/Devstral-Small-2-24B-Instruct-2512) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Mistral3ForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run full fine-tuning on SQuAD with the recipe's eight-GPU example launch from the repository root:

```bash
automodel examples/llm_finetune/devstral/devstral2_small_2512_squad.yaml --nproc-per-node 8
```

## Model Context

Devstral-Small-2-24B-Instruct-2512 is used for text generation. Its model size is 24.01B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `Mistral3ForConditionalGeneration` |
| Parameters | 24.01B checkpoint parameters |
| Decoder Layers | 40 |
| Hidden Size | 5,120 |
| Attention | 32 query heads and 8 key-value heads |
| Context Length | 393,216 tokens (checkpoint configuration) |
| Vocabulary Size | 131,072 |
| Configured Dtype | `bfloat16` |
