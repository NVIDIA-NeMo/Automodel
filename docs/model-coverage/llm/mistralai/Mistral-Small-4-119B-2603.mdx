[Mistral-Small-4-119B-2603](https://huggingface.co/mistralai/Mistral-Small-4-119B-2603) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Mistral3ForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). Allocate 4 nodes with 8 GPUs each; run on every node with `NODE_RANK` and `MASTER_ADDR` set. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run torchrun --nnodes 4 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/vlm_finetune/mistral4/mistral4_medpix.yaml
```

## Model Context

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `Mistral3ForConditionalGeneration` |
| Parameters | 119.40B checkpoint parameters |
| Decoder Layers | 36 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads / 32 key-value heads |
| Context Length | 1,048,576 tokens (checkpoint configuration) |
| Vocabulary Size | 131,072 |
| Experts | 128 routed / 1 shared / 4 selected per token |
| Configured Dtype | `bfloat16` |
