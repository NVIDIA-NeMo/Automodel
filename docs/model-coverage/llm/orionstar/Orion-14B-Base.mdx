[Orion-14B-Base](https://huggingface.co/OrionStarAI/Orion-14B-Base/blob/b988a511e9c880a465e704c57e3f297a3e7ef282/README.md) is a 14B-parameter multilingual language model from OrionStarAI. It was pretrained on 2.5 trillion tokens in languages including Chinese, English, Japanese, and Korean.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/orionstarai/orion_14b_base_squad_peft.yaml --nproc-per-node 8
```

## Model Context

Orion-14B-Base is used for text generation. Its model size is 14B parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `OrionForCausalLM` |
| Parameters | 14B |
| Hugging Face Organization | [OrionStarAI](https://huggingface.co/OrionStarAI) |
| Decoder Layers | 40 |
| Hidden Size | 5,120 |
| Attention | 40 attention heads / 40 key-value heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 84,608 |
| Configured Dtype | `bfloat16` |

### Recipe Setup

The [LoRA recipe](https://github.com/NVIDIA-NeMo/Automodel/blob/538848ea2e2dcc6f80a6eb8899fef72ede173ca5/examples/llm_finetune/orionstarai/orion_14b_base_squad_peft.yaml) loads the pretrained checkpoint with `trust_remote_code: true`. It uses fully sharded data parallelism (FSDP2), activation checkpointing, and LoRA with rank 8 and alpha 32.

The example runs for 100 steps on 1,024 SQuAD training examples, with 64 validation examples and a sequence length of 512 tokens. Checkpoint saving is enabled, with output under `checkpoints/orion_14b_base`.
