[MiniMax-M2.7](https://huggingface.co/MiniMaxAI/MiniMax-M2.7) has NeMo AutoModel recipes for full fine-tuning and low-rank adaptation (LoRA) on HellaSwag.
The Hugging Face configuration declares the `MiniMaxM2ForCausalLM` architecture.

## Quick Start

For full fine-tuning on HellaSwag, complete the prerequisites in Model Context. This example uses 8 nodes with 8 GPUs each. Set `NODE_RANK` to a unique value from `0` to `7` and `MASTER_ADDR` to node 0's reachable hostname or IP address. Run from the repository root on every node.

```bash
uv run torchrun --nnodes 8 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/minimax_m2/minimax_m2.7_hellaswag_pp.yaml
```

## Model Context

MiniMax-M2.7 is used for text generation. Its model size is 228.69B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `MiniMaxM2ForCausalLM` |
| Parameters | 228.69B checkpoint parameters |
| Decoder Layers | 62 |
| Hidden Size | 3,072 |
| Attention | 48 attention heads and 8 key-value heads |
| Context Length | 204,800 tokens (checkpoint configuration) |
| Vocabulary Size | 200,064 |
| Experts | 256 routed experts; 8 selected per token |
| Configured Dtype | `bfloat16` |

### Prepare the Environment

Follow the [installation guide](/get-started/installation) and make the same repository checkout and environment available on every node. The recipes use Transformer Engine for attention and HybridEP for expert dispatch; both must be available in that environment. For the Quick Start launch, every node must be able to reach `MASTER_ADDR` on port `29500`.

Both recipes set `checkpoint.enabled: false`. Set `checkpoint.enabled: true` to save trained weights.

### Configuration

These settings describe the full fine-tuning recipe used in Quick Start. The node count comes from the recipe's `ci.nodes` setting. PP denotes pipeline parallelism; EP denotes expert parallelism. FSDP2 denotes Fully Sharded Data Parallel version 2.

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs per node in the example launch |
| Strategy | FSDP2; `tp_size=1`, `pp_size=2`, `cp_size=1`, `ep_size=16` |
| Nodes | 8 |
| Features | Activation checkpointing (`activation_checkpointing=true`), Transformer Engine, HybridEP (`dispatcher=hybridep`) |
| Advanced | `attn=te`, `linear=te`, `experts=torch_mm`, `dispatcher=hybridep` |
