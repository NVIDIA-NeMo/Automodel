[StableLM](https://huggingface.co/stabilityai) is Stability AI's series of open language models, available in base and instruction-tuned variants across multiple sizes.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/stabilityai/stablelm_3b_4e1t_squad_peft.yaml --nproc-per-node 8
```

## Model Context

`stabilityai/stablelm-3b-4e1t` is a pretrained base model for text generation with approximately 2.8 billion parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `StableLmForCausalLM` |
| Parameters | 2,795,443,200 (approximately 2.8B) |
| Hugging Face Organization | [stabilityai](https://huggingface.co/stabilityai) |
| Decoder Layers | 32 |
| Hidden Size | 2,560 |
| Attention | 32 attention heads / 32 key-value heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 50,304 |
| Configured Dtype | `bfloat16` |

Read [stablelm_3b_4e1t_squad_peft.yaml](https://github.com/NVIDIA-NeMo/Automodel/blob/538848ea2e2dcc6f80a6eb8899fef72ede173ca5/examples/llm_finetune/stabilityai/stablelm_3b_4e1t_squad_peft.yaml) for checkpoint access, data paths, and backend dependencies.
