[GLM-5.3](https://huggingface.co/zai-org/GLM-5.3) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `GlmMoeDsaForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). Allocate 32 nodes with 8 GPUs each; run on every node with `NODE_RANK` and `MASTER_ADDR` set. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run torchrun --nnodes 32 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/glm/glm_5.3_tulu3_4k_cudnn_100step.yaml
```

## Model Context

GLM-5.3 is used for text generation. Its model size is 753.33B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `GlmMoeDsaForCausalLM` |
| Parameters | 753.33B checkpoint parameters |
| Decoder Layers | 78 |
| Hidden Size | 6,144 |
| Attention | 64 attention heads / 64 key-value heads |
| Context Length | 1,048,576 tokens (checkpoint configuration) |
| Vocabulary Size | 154,880 |
| Experts | 256 routed / 1 shared / 8 selected per token |
| Configured Dtype | `bfloat16` |

### Configuration

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, pp_size=4, cp_size=1, ep_size=64 |
| Nodes | 32 |
| Features | Activation checkpointing (activation_checkpointing=true), Packed sequences (packed_sequence_size=4096), HybridEP (dispatcher=hybridep) |
| Advanced | attention=cudnn, linear=torch, dispatcher=hybridep, sequence length 4096 |
