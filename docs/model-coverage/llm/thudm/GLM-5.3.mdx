[GLM-5.3](https://huggingface.co/zai-org/GLM-5.3) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `GlmMoeDsaForCausalLM` architecture.

## Quick Start

Complete the [installation instructions](/get-started/installation) and [recipe setup](#recipe-setup). This example uses 32 nodes with 8 GPUs each. From the repository root on every node, set `NODE_RANK` to its rank (0-31) and `MASTER_ADDR` to node 0's reachable address, then run:

```bash
uv run torchrun --nnodes 32 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/glm/glm_5.3_tulu3_4k_cudnn_100step.yaml
```

## Model Context

GLM-5.3 is used for text generation. Its model size is 753.33B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `GlmMoeDsaForCausalLM` |
| Parameters | 753.33B checkpoint parameters |
| Decoder Layers | 78 |
| Hidden Size | 6,144 |
| Attention | 64 attention heads and 64 key-value heads |
| Context Length | 1,048,576 tokens (checkpoint configuration) |
| Vocabulary Size | 154,880 |
| Experts | 256 routed experts, 1 shared expert, and 8 routed experts selected per token |
| Configured Dtype | `bfloat16` |

### Configuration

| Setting | Configuration |
| --- | --- |
| Hardware | GPU model not specified in the recipe; the cuDNN DSA backend requires CUDA compute capability 9.0 or later |
| Strategy | FSDP2; `tp_size=1`, `pp_size=4`, `cp_size=1`, `ep_size=64` |
| Nodes | 32, with 8 GPUs per node (example topology) |
| Features | Activation checkpointing (`activation_checkpointing=true`), packed sequences (`packed_sequence_size=4096`), HybridEP (`dispatcher=hybridep`) |
| Advanced | `attn=cudnn`, `linear=torch`, `dispatcher=hybridep`, sequence length 4,096 |

### Recipe Setup

1. Prepare an environment with `nvidia-cudnn-frontend[cutedsl]`, FlashMLA providing `flash_mla_sparse_fwd`, and HybridEP. The [repository Dockerfile](https://github.com/NVIDIA-NeMo/Automodel/blob/main/docker/Dockerfile) contains the pinned FlashMLA and HybridEP builds. FlashMLA is installed separately from the standard `uv sync --locked --all-groups --extra all` source installation.
2. Ensure all nodes can access `zai-org/GLM-5.3` and `allenai/tulu-3-sft-mixture`. The recipe loads pretrained weights with base-checkpoint dequantization enabled and uses the dataset's `train[:100000]` split.
3. Use the [Slurm launcher guide](/job-launchers/slurm-cluster) to prepare the 32-node allocation. The recipe uses 256 ranks with pipeline parallelism 4 and expert parallelism 64; this topology is an example configuration, not a hardware minimum for the model.

### Workflow Notes

The recipe runs for at most 100 steps and sets `checkpoint.enabled=false`, so it does not save trained weights. Enable checkpoint saving and configure an output directory before running if you need to retain the fine-tuned model.
