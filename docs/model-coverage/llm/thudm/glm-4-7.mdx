[GLM-4.7](https://huggingface.co/zai-org/GLM-4.7) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Glm4MoeForCausalLM` architecture.

## Quick Start

### Fine-Tune GLM-4.7

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/glm/glm_4.7_te_deepep.yaml --nproc-per-node 8
```

Use the [Slurm launcher guide](/job-launchers/slurm-cluster) for the multi-node run.
