[ChatGLM](https://github.com/zai-org/ChatGLM-6B) is a bilingual (Chinese-English) conversational language model from Zhipu AI. ChatGLM2 and ChatGLM3 extend the original with improved performance, longer context, and more efficient attention.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/zai_org/chatglm3_6b_squad_peft.yaml --nproc-per-node 8
```

## Model Context

chatglm3-6b is used for text generation. Its model size is 6B parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `ChatGLMModel` |
| Parameters | 6B |
| Hugging Face Organization | [zai-org](https://huggingface.co/zai-org) |
| Decoder Layers | 28 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads / 2 key-value heads |
| Context Length | 8,192 tokens (checkpoint configuration) |
| Vocabulary Size | 65,024 |
| Checkpoint Dtype | `float16` |

The checkpoint declares `ChatGLMModel`; its `AutoModelForCausalLM` mapping loads `ChatGLMForConditionalGeneration`.

### Recipe Setup

The [recipe](https://github.com/NVIDIA-NeMo/Automodel/blob/538848ea2e2dcc6f80a6eb8899fef72ede173ca5/examples/llm_finetune/zai_org/chatglm3_6b_squad_peft.yaml) loads pretrained weights in `bfloat16` with `trust_remote_code: true` and applies low-rank adaptation (LoRA). It configures fully sharded data parallelism (`fsdp2`), activation checkpointing, and up to 100 training steps. The SQuAD subsets contain 1,024 training and 64 validation examples, with a 512-token sequence length. Checkpoint saving is enabled under `checkpoints/chatglm3_6b`.
