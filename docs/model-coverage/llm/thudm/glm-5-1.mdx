[GLM-5.1](https://huggingface.co/zai-org/GLM-5.1) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `GlmMoeDsaForCausalLM` architecture.

## Fine-Tune GLM-5.1

Follow the [installation instructions](/get-started/installation), then review the checked-in recipe and
its declared topology below before choosing a local or cluster launcher.

Use the [Slurm launcher guide](/job-launchers/slurm-cluster) for the multi-node run.

## Standard Recipe Configuration

Start with the [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/glm/glm_5.1_lora.yaml).

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, pp_size=4, cp_size=1, ep_size=32 |
| Nodes | 16 |
| Features | LoRA, HybridEP (dispatcher=hybridep) |
| Advanced | attention=sdpa, linear=torch, experts=gmm, dispatcher=hybridep |
