[GLM-4](https://github.com/zai-org/GLM-4) is Zhipu AI's fourth-generation General Language Model, featuring strong multilingual capabilities and tool-use support.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Fine-Tune glm-4-9b-chat-hf

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/glm/glm_4_9b_chat_hf_squad.yaml
```
