[Phi-3-mini-4k-instruct](https://huggingface.co/microsoft/Phi-3-mini-4k-instruct) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Phi3ForCausalLM` architecture.

## Quick Start

### Fine-Tune Phi-3-mini-4k-instruct

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/phi/phi_3_mini_it_squad.yaml --nproc-per-node 8
```
