[Phi-3](https://azure.microsoft.com/en-us/products/phi) and [Phi-4](https://azure.microsoft.com/en-us/products/phi) are Microsoft's high-capability small language models using a shared transformer decoder architecture (`Phi3ForCausalLM`). Phi-4-mini and Phi-4 achieve strong benchmark results at relatively small parameter counts.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

Launch the checked-in recipe from the repository root on 8 GPUs. Validate memory use for your hardware:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/phi/phi_4_squad.yaml
```

## Model Context

Phi-4 uses the Phi3 transformer decoder for text generation. The architecture table records the dimensions of the checkpoint used by the SQuAD examples.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `Phi3ForCausalLM` |
| Parameters | 14B |
| Hugging Face Organization | [microsoft](https://huggingface.co/microsoft) |
| Decoder Layers | 40 |
| Hidden Size | 5,120 |
| Attention | 40 attention heads / 10 key-value heads |
| Context Length | 16,384 tokens (checkpoint configuration) |
| Vocabulary Size | 100,352 |
| Configured Dtype | `bfloat16` |
