[Phi-3-Small](https://azure.microsoft.com/en-us/products/phi) is Microsoft's 7B model using a distinct `Phi3SmallForCausalLM` architecture with blocksparse attention, separate from the standard Phi-3 family.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/microsoft/phi_3_small_8k_instruct_squad_peft.yaml --nproc-per-node 8
```

### Recipe Setup

Read [phi_3_small_8k_instruct_squad_peft.yaml](https://github.com/NVIDIA-NeMo/Automodel/blob/538848ea2e2dcc6f80a6eb8899fef72ede173ca5/examples/llm_finetune/microsoft/phi_3_small_8k_instruct_squad_peft.yaml) for checkpoint access, data paths, and backend dependencies. It provides a small LoRA fine-tuning example.

### Flash Attention Requirement

Install the FlashAttention dependency from the [installation guide](/get-started/installation) before using this recipe. The checkpoint implementation requires FlashAttention for its dense attention layers.
