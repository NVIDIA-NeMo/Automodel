IBM Granite MoE models extend the Granite architecture with Mixture-of-Experts layers for more efficient scaling. PowerMoE (IBM Research) also uses this architecture.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/ibm_granite/granite_3_0_1b_a400m_base_squad_peft.yaml --nproc-per-node 8
```

## Model Context

| Property | Value |
| --- | --- |
| Task | Text Generation (MoE) |
| **Architecture** | `GraniteMoeForCausalLM` |
| Parameters | 1B total / 400M active |
| Hugging Face Organization | [ibm-granite](https://huggingface.co/ibm-granite) |
| Decoder Layers | 24 |
| Hidden Size | 1,024 |
| Attention | 16 attention heads / 8 key-value heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 49,152 |
| Experts | 32 routed / 8 selected per token |

- `GraniteMoeForCausalLM`
- `GraniteMoeSharedForCausalLM` - variant with shared experts
