[ERNIE-4.5-21B-A3B-PT](https://huggingface.co/baidu/ERNIE-4.5-21B-A3B-PT) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Ernie4_5_MoeForCausalLM` architecture.

## Fine-Tune ERNIE-4.5-21B-A3B-PT

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/ernie4_5/ernie4_5_21b_a3b_hellaswag.yaml --nproc-per-node 8
```

## Standard Recipe Configuration

Start with the [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/ernie4_5/ernie4_5_21b_a3b_hellaswag.yaml).

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, pp_size=1, cp_size=1, ep_size=8 |
