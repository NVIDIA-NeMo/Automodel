[ERNIE 4.5](https://huggingface.co/baidu) is Baidu's dense and Mixture-of-Experts language model family with long-context text checkpoints on Hugging Face.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/ernie4_5/ernie4_5_0p3b_hellaswag.yaml
```

## Model Context

ERNIE-4.5-0.3B-PT is used for text generation. Its model size is 0.36B parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| Architectures | `Ernie4_5ForCausalLM`, `Ernie4_5_MoeForCausalLM` |
| Parameters | 0.36B |
| Context Length | 131,072 tokens |
| Hugging Face Organization | [baidu](https://huggingface.co/baidu) |
| **Architecture** | `Ernie4_5ForCausalLM` |
| Decoder Layers | 18 |
| Hidden Size | 1,024 |
| Attention | 16 attention heads / 2 key-value heads |
| Vocabulary Size | 103,424 |
| Configured Dtype | `bfloat16` |

- `Ernie4_5ForCausalLM`: dense Hugging Face implementation path.
- `Ernie4_5_MoeForCausalLM`: custom NeMo AutoModel implementation with expert parallelism support.
