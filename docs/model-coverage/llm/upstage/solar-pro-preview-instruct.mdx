[Solar Pro Preview](https://huggingface.co/upstage/solar-pro-preview-instruct) is an instruction-tuned language model from Upstage, developed by applying an enhanced depth up-scaling method to Phi-3-medium.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/upstage/solar_pro_preview_instruct_squad_peft.yaml --nproc-per-node 8
```

## Model Context

solar-pro-preview-instruct is used for text generation. Its model size is 22B parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `SolarForCausalLM` |
| Parameters | 22B |
| Hugging Face Organization | [upstage](https://huggingface.co/upstage) |
| Decoder Layers | 64 |
| Hidden Size | 5,120 |
| Attention | 40 attention heads / 10 key-value heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 32,128 |
| Configured Dtype | `bfloat16` |
