[Muse-Glimmer-30B](https://huggingface.co/meta-models/Muse-Glimmer-30B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `MuseGlimmerForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root. This example uses eight GPUs on one node and runs 100 steps without saving checkpoints:

```bash
automodel \
  examples/llm_finetune/muse_glimmer/muse_glimmer_30b_tulu3_te_tp2_cp4_packed_16k.yaml \
  --nproc-per-node 8
```

## Model Context

Muse-Glimmer-30B is used for text generation. Its model size is 29.78B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `MuseGlimmerForConditionalGeneration` |
| Parameters | 29.78B checkpoint parameters |
| Decoder Layers | 52 |
| Hidden Size | 6,656 |
| Attention | 32 attention heads / 2 key-value heads |
| Context Length | 131,072 tokens (checkpoint configuration) |
| Vocabulary Size | 202,048 |
| Configured Dtype | `bfloat16` |

### Configuration

These settings describe the example recipe.

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs on 1 node; GPU model and memory are not specified in the recipe |
| Strategy | Fully Sharded Data Parallelism (FSDP2); `tp_size=2`, `pp_size=1`, `cp_size=4`, `ep_size=1` |
| Nodes | 1 |
| Features | Activation checkpointing (`activation_checkpointing=true`), packed sequences (`packed_sequence_size=16384`), Transformer Engine |
| Advanced | `bfloat16`; Transformer Engine attention (`model.backend.attn: te`); documents truncated to 1,024 tokens (`dataset.seq_length`) before packing |

### Workflow Notes

The recipe sets `checkpoint.enabled: false`. To save fine-tuned weights, enable checkpoint saving and choose a save interval with `step_scheduler.ckpt_every_steps`. Activation checkpointing reduces training memory use; it does not save model weights.
