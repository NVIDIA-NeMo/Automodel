[Muse-Glimmer-30B](https://huggingface.co/meta-models/Muse-Glimmer-30B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `MuseGlimmerForConditionalGeneration` architecture.

## Quick Start

### Fine-Tune Muse-Glimmer-30B

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel \
  examples/llm_finetune/muse_glimmer/muse_glimmer_30b_tulu3_te_tp2_cp4_packed_16k.yaml \
  --nproc-per-node 8
```
