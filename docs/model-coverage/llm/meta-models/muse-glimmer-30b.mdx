[Muse-Glimmer-30B](https://huggingface.co/meta-models/Muse-Glimmer-30B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `MuseGlimmerForConditionalGeneration` architecture.

## Fine-Tune Muse-Glimmer-30B

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel \
  examples/llm_finetune/muse_glimmer/muse_glimmer_30b_tulu3_te_tp2_cp4_packed_16k.yaml \
  --nproc-per-node 8
```

## Standard Recipe Configuration

Start with the [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/muse_glimmer/muse_glimmer_30b_tulu3_te_tp2_cp4_packed_16k.yaml).

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=2, pp_size=1, cp_size=4, ep_size=1 |
| Nodes | 1 |
| Features | Activation checkpointing (activation_checkpointing=true), Packed sequences (packed_sequence_size=16384), Transformer Engine |
| Advanced | bfloat16, attention=te, sequence length 1024 |
