`parasail-ai/GritLM-7B-vllm` is Parasail AI's fork of [GritLM](https://github.com/ContextualAI/gritlm), a Mistral-based model for text generation and text embedding. The fork changes the architecture name in the checkpoint configuration for use with vLLM.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Run this low-rank adaptation (LoRA) example from the repository root on one node with 8 GPUs. GPU training and memory use still require validation on your hardware.

```bash
uv run automodel examples/llm_finetune/parasail_ai/gritlm_7b_vllm_squad_peft.yaml --nproc-per-node 8
```

## Model Context

GritLM-7B-vllm is a 7B-class model for text generation and text embedding. The example recipe fine-tunes next-token prediction on SQuAD.

| Property | Value |
| --- | --- |
| Task | Text Generation and Text Embedding |
| **Architecture** | `GritLM` |
| Parameters | 7B |
| Hugging Face Organization | [parasail-ai](https://huggingface.co/parasail-ai) |
| Decoder Layers | 32 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads and 8 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 32,000 |
| Configured Dtype | `bfloat16` |

### Recipe Setup

The [recipe](https://github.com/NVIDIA-NeMo/Automodel/blob/538848ea2e2dcc6f80a6eb8899fef72ede173ca5/examples/llm_finetune/parasail_ai/gritlm_7b_vllm_squad_peft.yaml) loads pretrained weights with `trust_remote_code: true` and applies LoRA with rank 8 and alpha 32. It uses Fully Sharded Data Parallel (FSDP2) with activation checkpointing and runs for 100 steps on 1,024 SQuAD training examples truncated to at most 512 tokens.

Checkpoint saving is enabled under `checkpoints/gritlm_7b_vllm`.
