[GritLM](https://github.com/ContextualAI/gritlm) (Generative Representational Instruction Tuning) is a unified model that performs both generative language modeling and text embedding in a single model, from Parasail AI.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/parasail_ai/gritlm_7b_vllm_squad_peft.yaml --nproc-per-node 8
```

## Model Context

GritLM-7B-vllm is used for text generation + embedding. Its model size is 7B parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation + Embedding |
| **Architecture** | `GritLM` |
| Parameters | 7B |
| Hugging Face Organization | [parasail-ai](https://huggingface.co/parasail-ai) |
| Decoder Layers | 32 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads / 8 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 32,000 |
| Configured Dtype | `bfloat16` |
