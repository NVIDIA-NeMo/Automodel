[GPT-2](https://huggingface.co/openai-community/gpt2) is OpenAI's foundational decoder-only transformer. NeMo AutoModel uses it as a baseline for the Megatron pretraining smoke test and tutorials - its small footprint makes it a convenient target to validate data pipelines, distributed configs, and logging without needing large compute.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation) and complete the [recipe setup](#recipe-setup). From the repository root, launch this example on one node with 8 GPUs.

```bash
uv run automodel examples/llm_pretrain/megatron_pretrain_gpt2.yaml --nproc-per-node 8
```

## Model Context

GPT-2 is a 124M-parameter text generation model. This recipe initializes it from the `openai-community/gpt2` configuration using `NeMoAutoModelForCausalLM.from_config`, without loading pretrained weights. Checkpoint saving is enabled, with `torch_save` output under `checkpoints/`.

| Property | Value |
| --- | --- |
| Task | Text Generation (pretraining baseline) |
| **Architecture** | `GPT2LMHeadModel` |
| Parameters | 124M |
| Hugging Face Organization | [openai-community](https://huggingface.co/openai-community) |
| Decoder Layers | 12 |
| Hidden Size | 768 |
| Attention | 12 attention heads |
| Context Length | 1,024 tokens (checkpoint configuration) |
| Vocabulary Size | 50,257 |

### Recipe Setup

Before launching [megatron_pretrain_gpt2.yaml](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_pretrain/megatron_pretrain_gpt2.yaml):

1. Use an environment with Transformer Engine for the configured `FusedAdam` optimizer.
2. Prepare Megatron-format data with the `openai-community/gpt2` tokenizer, following the [LLM Pretraining Guide](/recipes-e2e-examples/pretraining).
3. In both `dataset` and `validation_dataset`, replace `paths` with your prepared data paths and set `index_mapping_dir` to a writable directory for index mappings.

### Workflow Notes

The launch example uses one node with 8 GPUs. The recipe uses fully sharded data parallelism (FSDP2), a global batch size of 512, and a local batch size of 32. Tensor and context parallel sizes are both 1.
