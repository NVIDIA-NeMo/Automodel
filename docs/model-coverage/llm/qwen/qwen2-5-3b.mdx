[Qwen2.5-3B](https://huggingface.co/Qwen/Qwen2.5-3B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Qwen2ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/agent/qwen2_5_3b_synthtraces.yaml --nproc-per-node 8
```
