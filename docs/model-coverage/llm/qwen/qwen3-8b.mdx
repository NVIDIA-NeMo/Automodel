[Qwen3-8B](https://huggingface.co/Qwen/Qwen3-8B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Qwen3ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/qwen/qwen3_8b_squad_spark.yaml --nproc-per-node 8
```
