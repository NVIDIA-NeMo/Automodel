[Qwen2.5-0.5B](https://huggingface.co/Qwen/Qwen2.5-0.5B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Qwen2ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/qwen/qwen2_5_0p5b_packed_cp2.yaml --nproc-per-node 2
```
