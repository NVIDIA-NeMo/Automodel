[Qwen3-235B-A22B](https://huggingface.co/Qwen/Qwen3-235B-A22B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Qwen3MoeForCausalLM` architecture.

## Quick Start

Allocate 32 nodes with 8 GPUs each. Set `NODE_RANK` and `MASTER_ADDR` on every node; complete the recipe prerequisites in Model Context before launching.

```bash
uv run torchrun --nnodes 32 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_benchmark/qwen/qwen3_moe_235b_te_deepep.yaml
```
