[Qwen3 MoE](https://qwenlm.github.io/blog/qwen3/) is the mixture-of-experts (MoE) variant of the Qwen3 series from Alibaba Cloud, activating a small fraction of parameters per token for efficient large-scale training.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

The example uses eight GPUs. After completing the [prerequisites](#model-context), run from the repository root:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/qwen/qwen3_moe_30b_te_deepep.yaml
```

## Model Context

Qwen3-30B-A3B is a MoE model for text generation with approximately 30.5 billion total parameters and 3.3 billion active parameters per token.

| Property | Value |
| --- | --- |
| Task | Text Generation (MoE) |
| **Architecture** | `Qwen3MoeForCausalLM` |
| Parameters | 30.5B total; 3.3B active per token |
| Hugging Face Organization | [Qwen](https://huggingface.co/Qwen) |
| Decoder Layers | 48 |
| Hidden Size | 2,048 |
| Attention | 32 attention heads / 4 key-value heads |
| Context Length | 40,960 tokens (checkpoint configuration) |
| Vocabulary Size | 151,936 |
| Experts | 128 routed / 8 selected per token |
| Configured Dtype | `bfloat16` |

Both recipes load pretrained weights and fine-tune on HellaSwag using Fully Sharded Data Parallel version 2 (FSDP2) and eight-way expert parallelism (EP8). LoRA uses low-rank adaptation.

Both recipes require Transformer Engine (`attn: te`) and DeepEP (`dispatcher: deepep`). Use the container setup above or select the `moe` extra when installing from source; it includes both dependencies. The base installation and the `all` extra omit DeepEP.
