[Qwen3](https://qwenlm.github.io/blog/qwen3/) is Alibaba Cloud's third-generation dense language model series, featuring improved reasoning, instruction following, and multilingual capabilities over Qwen2.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/qwen/qwen3_0p6b_hellaswag.yaml
```

## Model Context

Qwen3-0.6B is used for text generation. Its model size is 0.6B parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `Qwen3ForCausalLM` |
| Parameters | 0.6B |
| Hugging Face Organization | [Qwen](https://huggingface.co/Qwen) |
| Decoder Layers | 28 |
| Hidden Size | 1,024 |
| Attention | 16 attention heads / 8 key-value heads |
| Context Length | 40,960 tokens (checkpoint configuration) |
| Vocabulary Size | 151,936 |
| Configured Dtype | `bfloat16` |
