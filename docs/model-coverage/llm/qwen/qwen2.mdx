[Qwen2.5](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct) is Qwen's latest series of large language models for text generation. The Qwen2.5-7B-Instruct checkpoint uses the `Qwen2ForCausalLM` architecture and supports long-context extension through YaRN.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

### Fine-Tune Qwen2.5-7B-Instruct

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/qwen/qwen2_5_7b_squad.yaml
```
