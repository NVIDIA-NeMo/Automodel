[Qwen1.5-MoE-A2.7B](https://huggingface.co/Qwen/Qwen1.5-MoE-A2.7B/blob/1a758c50ecb6350748b9ce0a99d2352fd9fc11c9/README.md) is a pretrained mixture-of-experts (MoE) language model for further training. It has 14.3 billion total parameters and activates 2.7 billion parameters per token.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

Run this eight-GPU example from the repository root. The `cuda_source` extra provides bitsandbytes, which this QLoRA recipe requires:

```bash
uv run --extra cuda_source automodel --nproc-per-node=8 examples/llm_finetune/qwen/qwen1_5_moe_a2_7b_qlora.yaml
```

## Model Context

The QLoRA recipe loads pretrained weights with 4-bit quantization and fine-tunes low-rank adapters on SQuAD. It uses fully sharded data parallelism (FSDP2) and enables checkpoint saving to `checkpoints/qwen_moe_lora`.

| Property | Value |
| --- | --- |
| Task | Text Generation (MoE) |
| **Architecture** | `Qwen2MoeForCausalLM` |
| Parameters | 14.3B total / 2.7B active |
| Hugging Face Organization | [Qwen](https://huggingface.co/Qwen) |
| Decoder Layers | 24 |
| Hidden Size | 2,048 |
| Attention | 16 attention heads / 16 key-value heads |
| Context Length | 8,192 tokens (checkpoint configuration) |
| Vocabulary Size | 151,936 |
| Experts | 60 routed / 4 selected per token |
| Configured Dtype | `bfloat16` |
