[Qwen3.8-2.4T-A95B](https://huggingface.co/Qwen/Qwen3.8-2.4T-A95B) is Alibaba Cloud's sparse Qwen3.8 text backbone. NeMo AutoModel provides a native CausalLM implementation for full-parameter fine-tuning with FSDP2, expert parallelism, and pipeline parallelism.

## Quick Start

For this recipe, allocate 64 nodes with 4 GPUs each. Complete the setup in [Model Context](#model-context), then run this command from the repository root on every node:

```bash
uv run torchrun --nnodes 64 --nproc-per-node 4 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/qwen/qwen3_8_2_4t_a95b_hellaswag_ep32_pp8.yaml
```

## Model Context

Qwen3.8-2.4T-A95B is a mixture-of-experts (MoE) text model with hybrid attention.

| Property | Value |
|---|---|
| **Task** | Text Generation (MoE, hybrid attention) |
| **Architecture** | Qwen3.8-2.4T-A95B CausalLM |
| **Parameters** | 2.4T total |
| **Layers** | 92 |
| **Experts** | 512 routed experts, top-10 routing |
| **Context Length** | 262,144 tokens |
| **HF Org** | [Qwen](https://huggingface.co/Qwen) |
| Hidden Size | 8,192 |
| Attention | 64 attention heads / 4 key-value heads |
| Vocabulary Size | 248,320 |
| Configured Dtype | `bfloat16` |

### Prepare the Environment

1. Follow the [installation guide](/get-started/installation) and use the same NeMo AutoModel environment and repository checkout on every node.
2. Ensure every node can access the pretrained checkpoint and the `Rowan/hellaswag` dataset.
3. Set `NODE_RANK` to a unique value from `0` to `63` on each node. Set `MASTER_ADDR` to the same reachable hostname or IP address of node `0` on every node.

See the [Slurm Launcher Guide](/job-launchers/slurm-cluster) for cluster setup and the [Large MoE Fine-Tuning Guide](/recipes-e2e-examples/large-moe-fine-tuning) for expert and pipeline parallelism configuration.

### Architecture

- The text entry point uses the native Qwen3.8-2.4T-A95B CausalLM path.
- The decoder combines attention, GatedDeltaNet linear attention, routed experts, shared experts, and optional multi-token prediction.
- The HF state-dict adapter handles both grouped BF16 expert checkpoints and split block-FP8 per-expert checkpoints.
- GatedDeltaNet state tensors that require fp32 precision keep the expected checkpoint contract.

### Validated Configuration

| Area | Validated Configuration |
|---|---|
| FSDP2 | Full-parameter training |
| Expert Parallelism | EP32 |
| Pipeline Parallelism | PP8 |
| Workload | HellaSwag next-token prediction |
| Scale | 64 GB200 nodes with 4 GPUs each (256 GPUs) |
| Duration | 100 training steps |

The validated 64-node run loaded the public split-FP8 checkpoint and completed a full-model HellaSwag SFT run. This validates the training mechanics and checkpoint layout, not model convergence.

The recipe loads pretrained weights and trains on `Rowan/hellaswag`. It sets `checkpoint.enabled: false`, so it does not save fine-tuned weights. Enable checkpoint saving before launching if you need to retain the trained model.
