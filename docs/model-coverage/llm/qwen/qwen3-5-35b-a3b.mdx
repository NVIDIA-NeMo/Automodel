[Qwen3.5-35B-A3B](https://huggingface.co/Qwen/Qwen3.5-35B-A3B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Qwen3_5MoeForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run automodel examples/vlm_finetune/qwen3_5_moe/qwen3_5_35b_neat_packing.yaml --nproc-per-node 8
```

## Model Context

| Property | Value |
| --- | --- |
| Task | Text generation |
| Architecture | `Qwen3_5MoeForConditionalGeneration` |
| Parameters | 35.95B checkpoint parameters |
| Decoder Layers | 40 |
| Hidden Size | 2,048 |
| Attention | 16 attention heads / 2 key-value heads |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 248,320 |
| Experts | 256 routed / 8 selected per token |

### Configuration

| Setting | Configuration |
| --- | --- |

| Features | Activation checkpointing (activation_checkpointing=true), LoRA, Transformer Engine, DeepEP (dispatcher=deepep) |
