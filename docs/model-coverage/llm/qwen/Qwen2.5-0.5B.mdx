[Qwen2.5-0.5B](https://huggingface.co/Qwen/Qwen2.5-0.5B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Qwen2ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation) and the MagiAttention setup in [Model Context](#model-context). From the repository root, run the mock prefix-tree rollout example on one GPU:

```bash
uv run automodel examples/llm_finetune/qwen/qwen25_magi_prefix_tree_rollouts.yaml --nproc-per-node 1
```

## Model Context

Qwen2.5-0.5B is used for text generation. Its model size is 494.0M checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `Qwen2ForCausalLM` |
| Parameters | 494.0M checkpoint parameters |
| Decoder Layers | 24 |
| Hidden Size | 896 |
| Attention | 14 attention heads and 2 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 151,936 |
| Configured Dtype | `bfloat16` |

### Configuration

These settings describe the shared-prefix training check.

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; `tp_size=1`, `pp_size=1`, `cp_size=1`, `ep_size=1` |
| Nodes | - |
| Features | Shared-prefix rollout groups, MagiAttention |
| Advanced | `local_batch_size=1`, `rope_fusion=false`, `linear=torch` |

### Related Recipe

The [FineProofs chat recipe](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/qwen/qwen2_5_0p5b_instruct_fineproofs_chat.yaml) fine-tunes `Qwen/Qwen2.5-0.5B-Instruct` with low-rank adaptation (LoRA) on `lm-provers/FineProofs-SFT`.

### Workflow Notes

For MagiAttention, use the source-checkout installation with `uv sync --locked --all-groups --extra all`. The `--all-groups` option includes the `magi` dependency group required by this recipe.

The shared-prefix recipe loads pretrained base weights and trains on synthetic rollout groups with context parallelism disabled (`cp_size=1`). It sets `checkpoint.enabled: false`, so the run does not save trained weights.
