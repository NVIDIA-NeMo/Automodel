[Qwen2.5-32B-Instruct](https://huggingface.co/Qwen/Qwen2.5-32B-Instruct) has checked-in NeMo AutoModel recipes for low-rank adaptation (LoRA) benchmarks on synthetic text data.
The Hugging Face configuration declares the `Qwen2ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run this LoRA benchmark on synthetic data from the repository root. The example launches eight GPUs on one node; see [Model Context](#model-context) for its configuration and checkpoint-saving behavior.

```bash
automodel examples/llm_finetune/qwen/qwen2_5_32b_peft_benchmark.yaml --nproc-per-node 8
```

## Model Context

Qwen2.5-32B-Instruct is used for text generation. Its model size is 32.76B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `Qwen2ForCausalLM` |
| Parameters | 32.76B checkpoint parameters |
| Decoder Layers | 64 |
| Hidden Size | 5,120 |
| Attention | 40 attention heads and 8 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration); recipes use 4,096 tokens |
| Vocabulary Size | 152,064 |
| Configured Dtype | `bfloat16` |

The linked recipes load pretrained weights and run 10-step LoRA benchmarks on synthetic data. They set `checkpoint.enabled: false`, so they do not save trained weights or adapters. For task-specific training, follow the [LLM fine-tuning guide](/recipes-e2e-examples/sft-peft).

### Quick Start Configuration

These settings describe the Quick Start example. The GPU count is an example launch topology; the recipe does not specify a minimum GPU model or memory capacity.

| Setting | Configuration |
| --- | --- |
| Hardware | Eight GPUs in the example launch |
| Strategy | Fully Sharded Data Parallel v2 (FSDP2); `tp_size: 1`, `pp_size: 4`, `cp_size: 1` |
| Nodes | 1 |
| Features | Activation checkpointing (`activation_checkpointing: true`), LoRA |
| Precision | BFloat16 (`bf16`) |
