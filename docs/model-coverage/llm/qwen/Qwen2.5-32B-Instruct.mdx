[Qwen2.5-32B-Instruct](https://huggingface.co/Qwen/Qwen2.5-32B-Instruct) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Qwen2ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/qwen/qwen2_5_32b_peft_benchmark.yaml --nproc-per-node 8
```

## Model Context

Qwen2.5-32B-Instruct is used for text generation. Its model size is 32.76B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `Qwen2ForCausalLM` |
| Parameters | 32.76B checkpoint parameters |
| Decoder Layers | 64 |
| Hidden Size | 5,120 |
| Attention | 40 attention heads / 8 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 152,064 |
| Configured Dtype | `bfloat16` |
