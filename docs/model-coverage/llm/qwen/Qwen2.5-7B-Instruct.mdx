[Qwen2.5](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct) is Qwen's latest series of large language models for text generation. The Qwen2.5-7B-Instruct checkpoint uses the `Qwen2ForCausalLM` architecture and supports long-context extension through YaRN.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run automodel examples/llm_finetune/qwen/qwen2_5_7b_instruct_chat.yaml --nproc-per-node 8
```

## Model Context

Qwen2.5-7B-Instruct is used for text generation. Its model size is 7B parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `Qwen2ForCausalLM` |
| Parameters | 7B |
| Hugging Face Organization | [Qwen](https://huggingface.co/Qwen) |
| Decoder Layers | 28 |
| Hidden Size | 3,584 |
| Attention | 28 attention heads / 4 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 152,064 |
| Configured Dtype | `bfloat16` |
