[Qwen2.5-7B-Instruct](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct) is an instruction-tuned language model in the Qwen2.5 family for text generation. It uses the `Qwen2ForCausalLM` architecture. The [upstream model card](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct/blob/a09a35458c702b33eeacc393d103063234e8bc28/README.md#processing-long-texts) describes context extension through YaRN; the recipes below use the default checkpoint configuration.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation) and complete the [recipe setup](#recipe-setup). From the repository root, run this example on one node with eight GPUs:

```bash
uv run automodel examples/llm_finetune/qwen/qwen2_5_7b_instruct_chat.yaml --nproc-per-node 8
```

## Model Context

Qwen2.5-7B-Instruct is used for text generation. The [checkpoint metadata](https://huggingface.co/api/models/Qwen/Qwen2.5-7B-Instruct/revision/a09a35458c702b33eeacc393d103063234e8bc28) reports 7,615,616,512 parameters (about 7.62B).

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `Qwen2ForCausalLM` |
| Parameters | About 7.62B |
| Hugging Face Organization | [Qwen](https://huggingface.co/Qwen) |
| Decoder Layers | 28 |
| Hidden Size | 3,584 |
| Attention | 28 attention heads / 4 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 152,064 |
| Configured Dtype | `bfloat16` |

### Fine-Tune the Base Checkpoint

To fine-tune the base checkpoint `Qwen/Qwen2.5-7B` on SQuAD, run from the repository root:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/qwen/qwen2_5_7b_squad.yaml
```

### Recipe Setup

Before launching [qwen2_5_7b_instruct_chat.yaml](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/qwen/qwen2_5_7b_instruct_chat.yaml):

1. Prepare training and validation JSONL files. Each line can contain a `messages` list with `role` and `content` fields, for example:

   ```json
   {"messages": [{"role": "user", "content": "What is the capital of France?"}, {"role": "assistant", "content": "Paris."}]}
   ```

2. In the YAML, replace `dataset.path_or_dataset_id: your/path/to/train.jsonl` and `validation_dataset.path_or_dataset_id: your/path/to/validation.jsonl` with the corresponding file paths.

### Workflow Notes

The chat recipe loads the pretrained instruction-tuned checkpoint and applies low-rank adaptation (LoRA) with fully sharded data parallelism (FSDP2). The launch example uses one node with eight GPUs. Checkpoint saving is enabled under `checkpoints/`.
