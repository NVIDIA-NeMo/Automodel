[Qwen3-32B](https://huggingface.co/Qwen/Qwen3-32B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Qwen3ForCausalLM` architecture.

## Fine-Tune Qwen3-32B

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/qwen/qwen3_32b_tulu3.yaml --nproc-per-node 8
```

## Standard Recipe Configuration

Start with the [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/qwen/qwen3_32b_tulu3.yaml).

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, pp_size=1, cp_size=1 |
| Nodes | 1 |
| Features | Activation checkpointing (activation_checkpointing=true) |
| Advanced | sequence length 2048 |
