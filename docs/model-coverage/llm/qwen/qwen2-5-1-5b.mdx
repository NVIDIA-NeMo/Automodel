[Qwen2.5-1.5B](https://huggingface.co/Qwen/Qwen2.5-1.5B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Qwen2ForCausalLM` architecture.

## Fine-Tune Qwen2.5-1.5B

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/qwen/qwen2_5_1p5b_tulu3_gradient_sketch.yaml --nproc-per-node 8
```
