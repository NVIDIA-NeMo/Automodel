[Qwen3-4B-Base](https://huggingface.co/Qwen/Qwen3-4B-Base) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Qwen3ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run torchrun --nproc-per-node 8 \
  examples/llm_finetune/finetune.py --config examples/convergence/tulu3/models/qwen3-4b/qwen3_4b_cp1_flashoptim.yaml
```

## Model Context

Qwen3-4B-Base is used for text generation. Its model size is 4.02B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `Qwen3ForCausalLM` |
| Parameters | 4.02B checkpoint parameters |
| Decoder Layers | 36 |
| Hidden Size | 2,560 |
| Attention | 32 attention heads / 8 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 151,936 |
| Configured Dtype | `bfloat16` |

### Configuration

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, pp_size=1, cp_size=1 |
| Nodes | - |
| Features | Checkpointing (enabled=true), Activation checkpointing (activation_checkpointing=true) |
| Advanced | sequence length 2048 |
