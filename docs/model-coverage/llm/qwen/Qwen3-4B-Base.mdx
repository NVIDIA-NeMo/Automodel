[Qwen3-4B-Base](https://huggingface.co/Qwen/Qwen3-4B-Base) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Qwen3ForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation) and complete the [recipe setup](#recipe-setup). From the repository root, run this full fine-tuning example on Tulu-3 using one node with 8 GPUs:

```bash
uv run --group dev torchrun --nproc-per-node 8 \
  examples/llm_finetune/finetune.py --config examples/convergence/tulu3/models/qwen3-4b/qwen3_4b_cp1_flashoptim.yaml
```

## Model Context

Qwen3-4B-Base is used for text generation. Its model size is 4.02B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `Qwen3ForCausalLM` |
| Parameters | 4.02B checkpoint parameters |
| Decoder Layers | 36 |
| Hidden Size | 2,560 |
| Attention | 32 attention heads and 8 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 151,936 |
| Configured Dtype | `bfloat16` |

### Configuration

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs in the example launch |
| Strategy | Fully Sharded Data Parallel (FSDP2); `tp_size=1`, `pp_size=1`, `cp_size=1` |
| Nodes | 1 in the example launch |
| Features | Checkpoint saving (`enabled=true`); activation checkpointing (`activation_checkpointing=true`) |
| Sequence Length | `seq_length=2048`, with training-data truncation disabled (`truncation=false`); samples can exceed 2,048 tokens |

### More Recipes for This Model

- [Fine-tune with context parallelism](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/convergence/tulu3/models/qwen3-4b/qwen3_4b_cp2_flashoptim.yaml): `cp_size=2` with FlashAdamW on 8 GPUs.

### Recipe Setup

Both workflows use `FusedLinearCrossEntropy`, which requires `cut-cross-entropy` from the repository's `dev` dependency group. The Quick Start selects this group with `--group dev`. FlashAdamW is included in the base dependencies; the alternate FusedAdam recipe also requires Transformer Engine from the `cuda` extra, which is included in `all`.

The recipes load `allenai/tulu-3-sft-mixture` from Hugging Face and use the local chat template at `examples/convergence/tulu3/models/qwen3-4b/chat_template.jinja`. Run from the repository root so this path resolves.

### Workflow Notes

The two CP=1 recipes load the pretrained `Qwen/Qwen3-4B-Base` weights using the Hugging Face implementation (`force_hf: true`). Both enable checkpoint saving to `checkpoints_convergence/qwen3_4b_tulu3_cp1/` and request a final consolidated SafeTensors checkpoint.
