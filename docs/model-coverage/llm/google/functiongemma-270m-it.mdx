[FunctionGemma](https://huggingface.co/google/functiongemma-270m-it) is a compact Gemma model specialized for function calling.

## Quick Start

Complete the [prerequisites](#prerequisites), then run this eight-GPU example from the repository root.

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/gemma/functiongemma_xlam.yaml
```

## Model Context

`google/functiongemma-270m-it` generates function calls from text. It is intended for task-specific fine-tuning.

| Property | Value |
|---|---|
| **Task** | Text-Only Function Calling |
| **Architecture** | `Gemma3ForCausalLM` |
| **Parameters** | 270M |
| **Hugging Face Organization** | [google](https://huggingface.co/google) |
| Decoder Layers | 18 |
| Hidden Size | 640 |
| Attention | 4 attention heads and 1 key-value head |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 262,144 |
| Configured Dtype | `bfloat16` |

### Prerequisites

[Install NeMo AutoModel](/get-started/installation), accept Google's usage license on the [model page](https://huggingface.co/google/functiongemma-270m-it), and authenticate the training environment with a Hugging Face token that can access the checkpoint.
