[Gemma-4-31B](https://huggingface.co/google/gemma-4-31B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Gemma4ForConditionalGeneration` architecture.

## Fine-Tune Gemma-4-31B

Follow the [installation instructions](/get-started/installation), then review the checked-in recipe and
its declared topology below before choosing a local or cluster launcher.

Use the [Slurm launcher guide](/job-launchers/slurm-cluster) for the multi-node run.

## Standard Recipe Configuration

Start with the [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/convergence/tulu3/models/gemma4-31b/gemma4_31b_tulu3_packed2k_cp1_gbs32_4node.yaml).

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, cp_size=1 |
| Nodes | 4 |
| Features | Checkpointing (enabled=true), Activation checkpointing (activation_checkpointing=true) |
| Advanced | torch.bfloat16 |
