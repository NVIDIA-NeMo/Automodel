[FunctionGemma](https://huggingface.co/google/functiongemma-270m-it) is a compact Gemma model specialized for function calling.

## Fine-Tune functiongemma-270m-it

Before starting, accept the checkpoint license on
[Hugging Face](https://huggingface.co/google/functiongemma-270m-it) and export
`HF_TOKEN` in the host shell. This quick start also requires Docker, the NVIDIA
Container Toolkit, and eight GPUs. For other installation methods, see the
[Installation Guide](/get-started/installation).

Run this complete block in a host shell. It downloads the container, installs
the mounted checkout, starts fine-tuning, and keeps downloaded files and
checkpoints on the host.

```bash
git clone --depth=1 https://github.com/NVIDIA-NeMo/Automodel.git
cd Automodel
mkdir -p .cache/huggingface checkpoints

docker pull nvcr.io/nvidia/nemo-automodel:26.08.00
docker run --gpus all --network=host -it --rm \
  --shm-size=32g \
  -e HF_TOKEN \
  -v "$(pwd)":/opt/Automodel \
  -v "$(pwd)/.cache/huggingface":/root/.cache/huggingface \
  -w /opt/Automodel \
  nvcr.io/nvidia/nemo-automodel:26.08.00 \
  /bin/bash -lc '
    bash docker/common/update_pyproject_pytorch.sh /opt/Automodel &&
    uv sync --locked --extra all --all-groups &&
    uv run automodel --nproc-per-node=8 examples/llm_finetune/gemma/functiongemma_xlam.yaml
  '
```
