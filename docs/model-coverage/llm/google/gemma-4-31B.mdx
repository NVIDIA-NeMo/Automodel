[Gemma-4-31B](https://huggingface.co/google/gemma-4-31B) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `Gemma4ForConditionalGeneration` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). Allocate 4 nodes with 8 GPUs each; run on every node with `NODE_RANK` and `MASTER_ADDR` set. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run torchrun --nnodes 4 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/convergence/tulu3/models/gemma4-31b/gemma4_31b_tulu3_packed2k_cp1_gbs32_4node.yaml
```

## Model Context

gemma-4-31B is used for text generation. Its model size is 32.68B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `Gemma4ForConditionalGeneration` |
| Parameters | 32.68B checkpoint parameters |
| Decoder Layers | 60 |
| Hidden Size | 5,376 |
| Attention | 32 attention heads; 16 key-value heads in sliding layers / 4 in global layers |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 262,144 |
| Configured Dtype | `bfloat16` |

### Configuration

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, cp_size=1 |
| Nodes | 4 |
| Features | Checkpointing (enabled=true), Activation checkpointing (activation_checkpointing=true) |
| Advanced | torch.bfloat16 |
