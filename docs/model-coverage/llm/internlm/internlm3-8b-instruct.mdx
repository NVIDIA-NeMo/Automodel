[InternLM](https://github.com/InternLM/InternLM) is a bilingual (Chinese-English) language model series from Shanghai AI Laboratory, with versions 1, 2, and 3 each improving on reasoning, instruction following, and long-context capabilities.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/internlm/internlm3_8b_instruct_squad_peft.yaml --nproc-per-node 8
```

## Model Context

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `InternLMForCausalLM` / `InternLM2ForCausalLM` / `InternLM3ForCausalLM` |
| Parameters | 8B |
| Hugging Face Organization | [internlm](https://huggingface.co/internlm) |
| Decoder Layers | 48 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads / 2 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 128,512 |
| Configured Dtype | `bfloat16` |

- `InternLMForCausalLM` - InternLM v1
- `InternLM2ForCausalLM` - InternLM2
- `InternLM3ForCausalLM` - InternLM3
