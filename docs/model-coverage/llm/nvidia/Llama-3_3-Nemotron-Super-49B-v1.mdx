[Llama-3.3-Nemotron-Super-49B-v1](https://huggingface.co/nvidia/Llama-3_3-Nemotron-Super-49B-v1) is an NVIDIA model derived from Llama-3.3-70B-Instruct through Neural Architecture Search (NAS)-based pruning and knowledge distillation, resulting in a 49B model with strong reasoning capabilities. It uses the `DeciLMForCausalLM` architecture.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/nvidia/llama_3_3_nemotron_super_49b_v1_squad_peft.yaml --nproc-per-node 8
```

## Model Context

Llama-3_3-Nemotron-Super-49B-v1 is used for text generation. Its model size is 49B parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `DeciLMForCausalLM` |
| Parameters | 49B |
| Hugging Face Organization | [nvidia](https://huggingface.co/nvidia) |
| Decoder Layers | 80 |
| Hidden Size | 8,192 |
| Attention | 64 heads in attention-enabled blocks; 31 of the 80 blocks skip attention |
| Context Length | 131,072 tokens (checkpoint configuration) |
| Vocabulary Size | 128,256 |
| Configured Dtype | `bfloat16` |
