[NVIDIA-Nemotron-Nano-9B-v2](https://huggingface.co/nvidia/NVIDIA-Nemotron-Nano-9B-v2) has NeMo AutoModel recipes for full fine-tuning and low-rank adaptation (LoRA) on SQuAD.
The Hugging Face configuration declares the `NemotronHForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), including the Nemotron dependencies described in Model Context. From the repository root, launch full fine-tuning on SQuAD with eight GPUs on one node:

```bash
automodel examples/llm_finetune/nemotron/nemotron_nano_9b_squad.yaml --nproc-per-node 8
```

## Model Context

NVIDIA-Nemotron-Nano-9B-v2 is used for text generation. Its model size is 8.89B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `NemotronHForCausalLM` |
| Parameters | 8.89B checkpoint parameters |
| Decoder Layers | 56 |
| Hidden Size | 4,480 |
| Attention | 40 attention heads / 8 key-value heads |
| Context Length | 131,072 tokens (checkpoint configuration) |
| Vocabulary Size | 131,072 |
| Configured Dtype | `bfloat16` |

### Configuration

Both recipes load pretrained weights through the Hugging Face implementation (`force_hf: true`, `trust_remote_code: true`) and train on SQuAD.

Nemotron Nano requires `mamba-ssm` and `causal-conv1d`. The installation guide recommends the NeMo AutoModel container, which includes these dependencies.

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs in the Quick Start example; GPU model and memory are not specified |
| Strategy | Fully Sharded Data Parallel version 2 (FSDP2); `tp_size: 1`, `cp_size: 1` |
| Nodes | 1 in the Quick Start example |
| Features | Model checkpoint saving enabled; `safetensors` format with `save_consolidated: true` |
| Advanced | `torch.compile` disabled |
