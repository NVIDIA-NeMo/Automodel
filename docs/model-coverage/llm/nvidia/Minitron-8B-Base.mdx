[Minitron-8B-Base](https://huggingface.co/nvidia/Minitron-8B-Base/blob/e2c30f2d4c8751f21b33be2b403d10d5f373ffc1/README.md) is NVIDIA's 8B-parameter base language model, produced by pruning Nemotron-4 15B and continuing training with distillation. Use this page to run low-rank adaptation (LoRA) fine-tuning on SQuAD with NeMo AutoModel.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/nvidia/minitron_8b_base_squad_peft.yaml --nproc-per-node 8
```

## Model Context

Minitron-8B-Base is used for text generation. Its model size is 8B parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `NemotronForCausalLM` |
| Parameters | 8B |
| Hugging Face Organization | [nvidia](https://huggingface.co/nvidia) |
| Decoder Layers | 32 |
| Hidden Size | 4,096 |
| Attention | 48 attention heads / 8 key-value heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 256,000 |
| Configured Dtype | `bfloat16` |

### Recipe Setup

The [LoRA recipe](https://github.com/NVIDIA-NeMo/Automodel/blob/538848ea2e2dcc6f80a6eb8899fef72ede173ca5/examples/llm_finetune/nvidia/minitron_8b_base_squad_peft.yaml) loads pretrained weights and configures 100 training steps with 1,024 training samples and 64 validation samples from `rajpurkar/squad`, truncated to 512 tokens. It uses Fully Sharded Data Parallel version 2 (FSDP2) with activation checkpointing. Checkpoint saving is enabled every 50 steps under `checkpoints/minitron_8b_base`.
