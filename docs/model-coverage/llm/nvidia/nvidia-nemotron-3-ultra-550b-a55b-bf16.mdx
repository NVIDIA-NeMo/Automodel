[NVIDIA-Nemotron-3-Ultra-550B-A55B-BF16](https://huggingface.co/nvidia/NVIDIA-Nemotron-3-Ultra-550B-A55B-BF16) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `NemotronHForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). Allocate 32 nodes with 8 GPUs each; run on every node with `NODE_RANK` and `MASTER_ADDR` set. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run torchrun --nnodes 32 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/nemotron/nemotron_ultra_v3_squad.yaml
```

## Model Context

| Property | Value |
| --- | --- |
| Task | Text generation |
| Architecture | `NemotronHForCausalLM` |
| Parameters | 560.52B checkpoint parameters |
| Hidden Size | 8,192 |
| Attention | 64 attention heads / 2 key-value heads |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 131,072 |
| Experts | 512 routed / 1 shared / 22 selected per token |
