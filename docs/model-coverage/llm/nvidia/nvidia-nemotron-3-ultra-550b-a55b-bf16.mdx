## Fine-Tune NVIDIA-Nemotron-3-Ultra-550B-A55B-BF16

## Standard Recipe Configuration

Start with the [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/nemotron/nemotron_ultra_v3_squad.yaml).

| Setting | Configuration |
| --- | --- |
| Hardware | - |
| Strategy | FSDP2; tp_size=1, pp_size=4, cp_size=1, ep_size=64 |
| Nodes | 32 |
| Features | Checkpointing (enabled=true), Activation checkpointing (activation_checkpointing=true), Packed sequences (packed_sequence_size=4096), Transformer Engine, HybridEP (dispatcher=hybridep) |
| Advanced | attention=te, linear=te, experts=gmm, dispatcher=hybridep |
