[NVIDIA-Nemotron-Nano-9B-v2](https://huggingface.co/nvidia/NVIDIA-Nemotron-Nano-9B-v2) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `NemotronHForCausalLM` architecture.

## Fine-Tune NVIDIA-Nemotron-Nano-9B-v2

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/nemotron/nemotron_nano_9b_squad.yaml --nproc-per-node 8
```

Full-parameter FSDP2 training requires fp32 parameter storage: set `model.dtype: float32` and keep `mp_policy.param_dtype: bfloat16`. The model's fp32 parameters (the Mamba `A_log`, `dt_bias`, and `D`) then stay in fp32 inside each layer's FSDP unit; bf16 storage fails at sharding time.
