[NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16](https://huggingface.co/nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `NemotronHForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation) and check the [model prerequisites](#model-context). From the repository root, launch low-rank adaptation (LoRA) fine-tuning on HellaSwag using eight GPUs on one node:

```bash
automodel examples/llm_finetune/nemotron/nemotron_nano_v3_5_lightning_hellaswag_peft.yaml --nproc-per-node 8
```

## Model Context

NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16 is used for text generation. Its model size is 31.58B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `NemotronHForCausalLM` |
| Parameters | 31.58B checkpoint parameters |
| Decoder Layers | 52 |
| Hidden Size | 2,688 |
| Attention | 32 attention heads / 2 key-value heads |
| Context Length | 262,144 tokens (checkpoint configuration) |
| Vocabulary Size | 131,072 |
| Experts | 128 routed / 1 shared / 6 selected per token |
| Configured Dtype | `bfloat16` |

### Configuration

The following settings describe the eight-GPU Quick Start recipe. Both recipes load pretrained weights, train on HellaSwag, and enable checkpoint saving. The single-GPU recipe sets every parallelism size to one and enables activation checkpointing and memory-efficient LoRA.

Use an environment with the Nemotron CUDA dependencies, including `mamba-ssm` and `causal-conv1d`. The [installation guide](/get-started/installation) recommends the NeMo AutoModel container for these dependencies.

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs for the Quick Start example |
| Strategy | Fully Sharded Data Parallelism (FSDP2); `tp_size=1`, `cp_size=1`, `ep_size=8` |
| Nodes | 1 |
| Features | Checkpoint saving (`checkpoint.enabled=true`), LoRA, Transformer Engine, DeepEP |
| Advanced | `attn=te`, `linear=te`, `experts=torch_mm`, `dispatcher=deepep` |
