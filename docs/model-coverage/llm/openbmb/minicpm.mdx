[MiniCPM](https://github.com/OpenBMB/MiniCPM) is a compact language model series from OpenBMB and Tsinghua University, designed to deliver strong performance at small parameter counts using model merging and continuous training techniques.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Fine-Tune MiniCPM5-1B

From the repository root, run:

```bash
# Full fine-tuning
uv run automodel examples/llm_finetune/minicpm/minicpm5_1b_squad.yaml --nproc-per-node 8

# LoRA fine-tuning
uv run automodel examples/llm_finetune/minicpm/minicpm5_1b_squad_peft.yaml --nproc-per-node 8
```

## Model Reference

### Model Summary

| Property | Value |
| --- | --- |
| Task | Text Generation |
| Architecture | `MiniCPMForCausalLM` / `MiniCPM3ForCausalLM` / `MiniCPM5ForCausalLM` |
| Parameters | 1B - 4B |
| Hugging Face Organization | [openbmb](https://huggingface.co/openbmb) |

### Available Models

- **MiniCPM5-1B** (`MiniCPM5ForCausalLM`): 1B
- **MiniCPM3-4B** (`MiniCPM3ForCausalLM`): 4B
- **MiniCPM-2B-sft-bf16** (`MiniCPMForCausalLM`): 2B, SFT
- **MiniCPM-2B-dpo-bf16** (`MiniCPMForCausalLM`): 2B, DPO

### Model Architectures

- `MiniCPMForCausalLM` - MiniCPM v1/v2
- `MiniCPM3ForCausalLM` - MiniCPM3
- `MiniCPM5ForCausalLM` - MiniCPM5
