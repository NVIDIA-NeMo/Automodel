[Step-3.5-Flash](https://huggingface.co/stepfun-ai/Step-3.5-Flash) is a Mixture-of-Experts language model from Stepfun AI, designed for efficient inference.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Fine-Tune Step-3.5-Flash

<Note>
This recipe was validated on **16 nodes x 8 GPUs (128 H100s)**. See the [Launcher Guide](/job-launchers/slurm-cluster) for multi-node setup.

</Note>

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/llm_finetune/stepfun/step_3.5_flash_hellaswag_pp.yaml
```
