[Step-5-Preview](https://huggingface.co/stepfun-ai/Step-5-Preview) is the
8-bit floating-point (FP8) checkpoint of StepFun's Step 5 Preview model. Its configuration declares
FP8 quantization with the `e4m3` format, dynamic activation quantization, and 128 x 128
weight blocks.

## BF16 Training Recipes

The checked-in Step 5 supervised fine-tuning (SFT), low-rank adaptation
(LoRA), and long-context training recipes use
`stepfun-ai/Step-5-Preview-BF16`. Follow the
[Step-5-Preview-BF16 training guide](/model-coverage/large-language-models/stepfun-ai/Step-5-Preview-BF16)
for the recipe links, hardware requirements, and launch instructions.

## Model Reference

### Model Architecture

| Property | Value |
| --- | --- |
| **Architecture** | `Step5ForConditionalGeneration` |
| Checkpoint | `stepfun-ai/Step-5-Preview` |
| Weight Quantization | FP8, `e4m3` |
| Activation Scheme | Dynamic |
| Weight Block Size | 128 x 128 |
