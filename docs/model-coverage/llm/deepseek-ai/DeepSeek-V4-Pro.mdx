[DeepSeek-V4 Pro](https://huggingface.co/deepseek-ai/DeepSeek-V4-Pro) is a fine-grained mixture-of-experts (MoE) language model supported by NeMo AutoModel's native DeepSeek-V4 implementation.

## Quick Start

Follow the [installation instructions](/get-started/installation) and [Recipe Setup](#recipe-setup). Allocate 64 nodes with 8 H100 GPUs each. From the repository root on every node, launch the 20-step HellaSwag fine-tuning smoke test using the same `MASTER_ADDR` and `MASTER_PORT`. Checkpoint saving is disabled.

```bash
torchrun --nproc-per-node=8 \
  --nnodes=64 \
  --rdzv-backend=c10d \
  --rdzv-endpoint="${MASTER_ADDR}:${MASTER_PORT}" \
  -m nemo_automodel.recipes.llm.train_ft \
  -c examples/llm_finetune/deepseek_v4/deepseek_v4_pro_hellaswag_all_tilelang_pp8_ep64_20steps.yaml
```

## Model Context

DeepSeek-V4-Pro is a MoE model for text generation. The recipe trains the language backbone with the auxiliary multi-token prediction (MTP) module disabled (`num_nextn_predict_layers: 0`).

| Property | Value |
|---|---|
| **Task** | Text Generation (MoE) |
| **Architecture** | `DeepseekV4ForCausalLM` |
| **Experts** | 384 routed, 1 shared; 6 routed experts per token |
| **Hugging Face Organization** | [deepseek-ai](https://huggingface.co/deepseek-ai) |
| Decoder Layers | 61 |
| Hidden Size | 7,168 |
| Attention | 128 attention heads and 1 key-value head |
| Context Length | 1,048,576 tokens (checkpoint configuration) |
| Vocabulary Size | 129,280 |
| Configured Dtype | `bfloat16` |
| Parameters | 1.573T language backbone; 1.599T including the auxiliary MTP module |

### Recipe Setup

1. Prepare 64 nodes with 8 H100 GPUs per node using the [Slurm Launcher Guide](/job-launchers/slurm-cluster) or an external cluster allocation. The recipe uses pipeline parallelism of 8 (PP8) and expert parallelism of 64 (EP64) across 512 GPUs.
2. Ensure the environment includes the recipe's TileLang attention backend and HybridEP dispatcher, and can access the `deepseek-ai/DeepSeek-V4-Pro` checkpoint and `rowan/hellaswag` dataset on Hugging Face.
3. Set `MASTER_ADDR` to a rendezvous host reachable from all nodes and `MASTER_PORT` to an available port on that host. Use the same values on every node, then run the Quick Start command once per node.

See the [Large MoE Fine-Tuning Guide](/recipes-e2e-examples/large-moe-fine-tuning)
for the full multi-node environment setup.

### Workflow Notes

The checked-in recipe is a smoke and throughput test: `step_scheduler.max_steps` is 20 and `checkpoint.enabled` is `false`. For a longer run that saves trained weights, adjust the training duration and enable checkpoint saving with an interval appropriate for that duration.
