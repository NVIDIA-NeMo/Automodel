[DeepSeek-V3](https://github.com/deepseek-ai/DeepSeek-V3) is a large-scale Mixture-of-Experts model with 671B total parameters and 37B activated per token. It features Multi-head Latent Attention (MLA), innovative load balancing, and Multi-Token Prediction (MTP). DeepSeek-V3.2 is an updated release with further improvements.

[Moonlight](https://huggingface.co/moonshotai/Moonlight-16B-A3B) by Moonshot AI also uses this architecture with 16B total / 3B activated parameters.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). Allocate 128 nodes with 8 GPUs each; run on every node with `NODE_RANK` and `MASTER_ADDR` set. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run torchrun --nnodes 128 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_benchmark/deepseek/deepseek_v3_te_deepep_1024.yaml
```

## Model Context

| Property | Value |
| --- | --- |
| Task | Text Generation (MoE) |
| **Architecture** | `DeepseekV3ForCausalLM` / `DeepseekV32ForCausalLM` |
| Parameters | 671B total / 37B active |
| Hugging Face Organization | [deepseek-ai](https://huggingface.co/deepseek-ai) |
| Decoder Layers | 61 |
| Hidden Size | 7,168 |
| Attention | 128 attention heads / 128 key-value heads |
| Context Length | 163,840 tokens (checkpoint configuration) |
| Vocabulary Size | 129,280 |
| Experts | 256 routed / 1 shared / 8 selected per token |
| Configured Dtype | `bfloat16` |
