DeepSeek LLM 7B Chat is an instruction-tuned text generation model from [DeepSeek AI](https://github.com/deepseek-ai). This checkpoint uses the `LlamaForCausalLM` architecture.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/deepseek_ai/deepseek_llm_7b_chat_squad_peft.yaml --nproc-per-node 8
```

## Model Context

deepseek-llm-7b-chat is used for text generation. Its model size is 7B parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation |
| **Architecture** | `LlamaForCausalLM` |
| Parameters | 7B |
| Hugging Face Organization | [deepseek-ai](https://huggingface.co/deepseek-ai) |
| Decoder Layers | 30 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads / 32 key-value heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 102,400 |
| Configured Dtype | `bfloat16` |

### Recipe Setup

The [recipe](https://github.com/NVIDIA-NeMo/Automodel/blob/538848ea2e2dcc6f80a6eb8899fef72ede173ca5/examples/llm_finetune/deepseek_ai/deepseek_llm_7b_chat_squad_peft.yaml) uses low-rank adaptation (LoRA) with rank 8, fully sharded data parallelism (FSDP2), and `bfloat16` precision. It loads SQuAD from `rajpurkar/squad` with sequences up to 512 tokens.
