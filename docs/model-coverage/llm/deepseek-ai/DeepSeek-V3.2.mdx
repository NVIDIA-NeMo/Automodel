[DeepSeek-V3.2](https://huggingface.co/deepseek-ai/DeepSeek-V3.2) has a checked-in NeMo AutoModel benchmark for low-rank adaptation (LoRA) training on synthetic data.
The Hugging Face configuration declares the `DeepseekV32ForCausalLM` architecture.

## Quick Start

Run the LoRA benchmark on 16 nodes with 8 GPUs each. Complete the setup in [Model Context](#model-context), including `NODE_RANK` and `MASTER_ADDR`, then run this command from the repository root on every node.

```bash
uv run torchrun --nnodes 16 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_benchmark/deepseek/dsv32_lora.yaml
```

## Model Context

DeepSeek-V3.2 is a text-generation model with 685.36B checkpoint parameters. The benchmark initializes the model from its configuration without loading pretrained weights and uses 4,096-token synthetic sequences. Checkpoint saving is disabled in this recipe.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `DeepseekV32ForCausalLM` |
| Parameters | 685.36B checkpoint parameters |
| Decoder Layers | 61 |
| Hidden Size | 7,168 |
| Attention | 128 attention heads / 128 key-value heads |
| Context Length | 163,840 tokens (checkpoint configuration); 4,096 tokens in the benchmark |
| Vocabulary Size | 129,280 |
| Experts | 256 routed / 1 shared / 8 selected per token |
| Configured Dtype | `bfloat16` |

### Configuration

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs per node in the launch above; GPU model unspecified by the recipe |
| Strategy | FSDP2; `tp_size=1`, `pp_size=4`, `cp_size=1`, `ep_size=32` |
| Nodes | 16 |
| Features | Activation checkpointing (`activation_checkpointing=true`), LoRA, Transformer Engine, HybridEP (`dispatcher=hybridep`) |
| Advanced | `attn=te`, `linear=te`, `experts=torch_mm`, `dispatcher=hybridep` |

### Workflow Notes

Follow the [installation instructions](/get-started/installation) and ensure that Transformer Engine and HybridEP are installed on every node for the selected backends.

Use the same repository checkout and environment on all 16 nodes. Set `NODE_RANK` to a unique value from `0` through `15`, and set `MASTER_ADDR` to the address of node `0`, reachable from every node on port `29500`.
