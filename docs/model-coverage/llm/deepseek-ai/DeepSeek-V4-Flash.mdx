[DeepSeek-V4 Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash) is DeepSeek's fine-grained mixture-of-experts (MoE) language model. It has 43 MoE layers, with 256 routed experts and one shared expert per layer. Each token selects six routed experts. Use the NeMo AutoModel recipe below for full fine-tuning on HellaSwag.

## Quick Start

Complete the [recipe prerequisites](#prepare-the-recipe-environment). From the repository root on every node, run full fine-tuning on HellaSwag with 16 nodes and 8 GPUs per node:

```bash
uv run torchrun --nnodes 16 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/deepseek_v4/deepseek_v4_flash_hellaswag.yaml
```

## Model Context

DeepSeek-V4-Flash generates text using its MoE backbone. It has 284.3 billion backbone parameters and 290.9 billion parameters including the auxiliary multi-token prediction (MTP) module.

| Property | Value |
| --- | --- |
| Task | Text Generation (MoE) |
| **Architecture** | `DeepseekV4ForCausalLM` |
| Experts | 256 routed experts and 1 shared expert per layer |
| Hugging Face Organization | [deepseek-ai](https://huggingface.co/deepseek-ai) |
| Decoder Layers | 43 |
| Hidden Size | 4,096 |
| Attention | 64 attention heads and 1 key-value head |
| Context Length | 1,048,576 tokens (checkpoint configuration) |
| Vocabulary Size | 129,280 |
| Configured Dtype | `bfloat16` |
| Parameters | 284.3B in the language backbone; 290.9B including the auxiliary MTP module |

### Architecture Details

Layers use sliding-window attention (SWA), compressed sparse attention (CSA), or heavily compressed attention (HCA), selected through `compress_ratios`. The first `num_hash_layers` blocks route tokens through a fixed token-to-expert lookup table. Every block maintains four Hyper-Connection streams (`hc_mult=4`), mixed with a learned Sinkhorn router that normalizes columns first.

### Prepare the Recipe Environment

<Note>
The [checked-in recipe](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/deepseek_v4/deepseek_v4_flash_hellaswag.yaml) stops after 100 steps (`step_scheduler.max_steps: 100`) and does not save trained weights (`checkpoint.enabled: false`).
</Note>

1. Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation). Ensure the environment includes TileLang and HybridEP, selected by the recipe's `model.backend.attn` and `model.backend.dispatcher` settings.
2. Match the recipe's example topology: 16 nodes with 8 NVIDIA H100 GPUs each (128 GPUs). Use the same repository revision and environment on every node.
3. Set `NODE_RANK` to a unique value from `0` through `15` on each node. Set `MASTER_ADDR` to the rank-0 node's address, reachable from every node on port `29500`.
4. Make the `deepseek-ai/DeepSeek-V4-Flash` checkpoint and `rowan/hellaswag` dataset accessible through Hugging Face or local caches on every node.
