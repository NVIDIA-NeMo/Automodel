[DeepSeek-V4 Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4-Flash) is DeepSeek's latest fine-grained Mixture-of-Experts language model. It uses a 43-layer all-MoE backbone with 256 routed experts plus one shared expert per block, top-6 routing, and a hybrid per-layer attention zoo (SWA / CSA / HCA) selectable through `compress_ratios`. The first `num_hash_layers` blocks use a hash-clustering gate, and every block maintains `hc_mult=4` Hyper-Connection streams mixed via a learned col-norm-first Sinkhorn router.

## Quick Start

Allocate 16 nodes with 8 GPUs each. Set `NODE_RANK` and `MASTER_ADDR` on every node; complete the recipe prerequisites in Model Context before launching.

```bash
uv run torchrun --nnodes 16 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/deepseek_v4/deepseek_v4_flash_hellaswag.yaml
```

## Model Context

DeepSeek-V4-Flash is used for text generation (moe). Its model size is 284.3B language backbone / 290.9B including the auxiliary MTP module parameters.

| Property | Value |
| --- | --- |
| Task | Text Generation (MoE) |
| **Architecture** | `DeepseekV4ForCausalLM` |
| Experts | fine-grained MoE, 256 routed + 1 shared expert |
| Hugging Face Organization | [deepseek-ai](https://huggingface.co/deepseek-ai) |
| Decoder Layers | 43 |
| Hidden Size | 4,096 |
| Attention | 64 attention heads / 1 key-value heads |
| Context Length | 1,048,576 tokens (checkpoint configuration) |
| Vocabulary Size | 129,280 |
| Configured Dtype | `bfloat16` |
| Parameters | 284.3B language backbone / 290.9B including the auxiliary MTP module |
