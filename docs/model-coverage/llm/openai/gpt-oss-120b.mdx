[GPT-OSS 120B](https://huggingface.co/openai/gpt-oss-120b) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `GptOssForCausalLM` architecture.

## Quick Start

Complete the prerequisites in Model Context, then run this command from the repository root on each of 8 nodes with 8 GPUs per node:

```bash
uv run torchrun --nnodes 8 --nproc-per-node 8 \
  --node-rank "$NODE_RANK" --master-addr "$MASTER_ADDR" --master-port 29500 \
  -m nemo_automodel.cli.app examples/llm_finetune/gpt_oss/gpt_oss_120b.yaml
```

## Model Context

gpt-oss-120b is used for text generation. It has 117B total parameters, with 5.1B active per token.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `GptOssForCausalLM` |
| Decoder Layers | 36 |
| Hidden Size | 2,880 |
| Attention | 64 attention heads and 8 key-value heads |
| Context Length | 131,072 tokens (checkpoint configuration) |
| Vocabulary Size | 201,088 |
| Experts | 128 routed experts; 4 selected per token |
| Parameters | 117B total; 5.1B active per token |

Before launching, follow the [installation instructions](/get-started/installation) and use the same checkout and environment, including HybridEP, on every node. Set `NODE_RANK` to a unique value from `0` through `7`. Set `MASTER_ADDR` to the rank-0 node's hostname or IP address, reachable from every node on port `29500`.

EP64 means expert parallelism across 64 ranks. The recipe defaults to `step_scheduler.local_batch_size=8` and `global_batch_size=512`, which are compatible with 64 data-parallel ranks.

Full fine-tuning loads pretrained weights and enables checkpoint saving. The benchmark initializes weights from configuration, uses synthetic data with `fake_balanced_gate=true`, and disables checkpoint saving.

### Configuration

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs per node in the Quick Start example |
| Strategy | FSDP2; `tp_size=1`, `pp_size=1`, `cp_size=1`, `ep_size=64` |
| Nodes | 8 |
| Features | Checkpoint saving (`enabled=true`), HybridEP (`dispatcher=hybridep`) |
| Advanced | `experts=torch_mm`, `dispatcher=hybridep` |
