[Baichuan2-7B-Chat](https://huggingface.co/baichuan-inc/Baichuan2-7B-Chat) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `BaichuanForCausalLM` architecture.

## Quick Start

### Fine-Tune Baichuan2-7B-Chat

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/llm_finetune/baichuan/baichuan_2_7b_squad.yaml --nproc-per-node 8
```
