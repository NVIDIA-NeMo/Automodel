[Baichuan2-7B-Chat](https://huggingface.co/baichuan-inc/Baichuan2-7B-Chat) has a checked-in NeMo AutoModel recipe for text generation.
The Hugging Face configuration declares the `BaichuanForCausalLM` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run full fine-tuning on SQuAD from the repository root. This example uses eight GPUs; adjust `--nproc-per-node` to the number of available GPUs:

```bash
automodel examples/llm_finetune/baichuan/baichuan_2_7b_squad.yaml --nproc-per-node 8
```

## Model Context

Baichuan2-7B-Chat is used for text generation. Its model size is 7B parameters.

| Property | Value |
| --- | --- |
| Task | Text generation |
| **Architecture** | `BaichuanForCausalLM` |
| Decoder Layers | 32 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 125,696 |
| Configured Dtype | `bfloat16` |
| Parameters | 7B |

### Configuration

These settings describe the SQuAD full fine-tuning recipe used in Quick Start.

| Setting | Configuration |
| --- | --- |
| Hardware | GPU type not specified in the recipe |
| Strategy | Fully Sharded Data Parallel (FSDP2); `tp_size: 1`, `cp_size: 1` |
| Nodes | Not specified in the recipe |
| Features | Checkpoint saving enabled (`checkpoint.enabled: true`) |
| Advanced | Compilation disabled (`compile.enabled: false`) |
