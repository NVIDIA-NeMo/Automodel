[OLMoE](https://allenai.org/olmo) is Allen AI's open Mixture-of-Experts language model. It activates 1B parameters per token from a 7B total parameter pool.

Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. This is an example configuration; GPU training and memory use still require validation.

```bash
uv run automodel examples/llm_finetune/allenai/olmoe_1b_7b_0924_squad_peft.yaml --nproc-per-node 8
```

## Model Context

| Property | Value |
| --- | --- |
| Task | Text Generation (MoE) |
| **Architecture** | `OLMoEForCausalLM` |
| Parameters | 7B total / 1B active |
| Hugging Face Organization | [allenai](https://huggingface.co/allenai) |
| Decoder Layers | 16 |
| Hidden Size | 2,048 |
| Attention | 16 attention heads / 16 key-value heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 50,304 |
| Experts | 64 routed / 8 selected per token |
| Configured Dtype | `bfloat16` |
