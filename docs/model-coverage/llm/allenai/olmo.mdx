[OLMo](https://allenai.org/olmo) (Open Language Model) is Allen AI's fully open language model - open weights, open training data, and open training code. OLMo-1B and OLMo-7B are trained on Dolma.

Use this page as a checkpoint and architecture reference. Set up NeMo AutoModel with the
[latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the
[installation instructions](/get-started/installation).

## Quick Start

This page provides checkpoint and architecture reference information rather
than a model-specific launch command. Follow the
[installation instructions](/get-started/installation) to set up NeMo AutoModel.
