[Llama-nemotron-embed-VL-1B-v2](https://huggingface.co/nvidia/llama-nemotron-embed-vl-1b-v2) has a checked-in NeMo AutoModel recipe for embedding fine-tuning.
The Hugging Face configuration declares the `LlamaNemotronVLModel` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), install the `fa` extra, prepare the ColPali data, and update `dataset.data_dir_list` as described in the [prerequisites](#workflow-notes). Run the fine-tuning recipe from the repository root; this example launches eight GPU processes:

```bash
automodel examples/retrieval/bi_encoder/nemotron_vl_1b/nemotron_vl_1b_example.yaml --nproc-per-node 8
```

## Model Context

llama-nemotron-embed-vl-1b-v2 is used for feature extraction. Its model size is 1.68B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Feature extraction |
| **Architecture** | `LlamaNemotronVLModel` |
| Parameters | 1.68B checkpoint parameters |
| Layers | 16 (language backbone) |
| Hidden Size | 2,048 (language backbone) |
| Attention | 32 attention heads and 8 key-value heads (language backbone) |
| Context Length | 10,240 tokens (maximum evaluated in the upstream model card) |
| Language Position Limit | 131,072 (`llm_config.max_position_embeddings`) |
| Vocabulary Size | 128,266 (language backbone) |
| Configured Dtype | `bfloat16` |

### Workflow Notes

The recipe selects FlashAttention-2 (`model.attn_implementation: flash_attention_2`). Install `flash-attn` through the `fa` extra; base and `[all]` installs exclude this extra. For a source checkout, run `uv sync --locked --all-groups --extra all --extra fa` from the repository root during installation.

1. Prepare the ColPali source data by following the [recipe's dataset instructions](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/bi_encoder/nemotron_vl_1b/README.md).
2. In the recipe YAML, replace the ColPali placeholder in `dataset.data_dir_list` with the generated `colpali_train.json` path. The MIRACL source uses an `hf://` URI and loads directly from Hugging Face.

The recipe sets `q_max_length: 512` and `p_max_length: 4096` for query and passage inputs. The [upstream model card](https://huggingface.co/nvidia/llama-nemotron-embed-vl-1b-v2/blob/582e3bf72aee355e3c59ed89de53543c5b0657ee/README.md) reports evaluation up to 10,240 tokens, including visual tokens; the language backbone's position limit is a separate configuration value.
