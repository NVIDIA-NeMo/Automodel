[Llama-nemotron-embed-VL-1B-v2](https://huggingface.co/nvidia/llama-nemotron-embed-vl-1b-v2) has a checked-in NeMo AutoModel recipe for feature extraction.
The Hugging Face configuration declares the `LlamaNemotronVLModel` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
automodel examples/retrieval/bi_encoder/nemotron_vl_1b/nemotron_vl_1b_example.yaml --nproc-per-node 8
```
