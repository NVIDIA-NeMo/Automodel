Nemotron 3.5 Embed models encode text queries and documents containing an image,
text, or both. They combine a Pixtral vision encoder with a language model from
[Nemotron 3 Embed](/model-coverage/embedding-models/nvidia/Nemotron-3-Embed).

## Released Checkpoints

## Fine-Tune the 8B Model

The [8B multimodal embedding example](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/nemotron_3_5/embed_8b_multimodal.yaml)
trains the vision encoder and multimodal projector with a contrastive loss while
keeping the language model frozen. Follow the
[fine-tuning README](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/nemotron_3_5/README.md)
for the starting checkpoint, dataset format, dependencies, and launch command.

The example loads the released NVIDIA checkpoint and its processor directly.
No text and vision checkpoint assembly is needed for this fine-tuning workflow.
It adapts the existing model to your data; it does not reproduce the original
training stages, data mixture, or reported results.

## Original Training Approach

The 8B model starts from a trained Nemotron 3 text component and Ministral 3 vision
components, then trains the vision encoder and projector with the language model frozen.
The 1B model uses distillation from the 8B multimodal teacher with a frozen language model.
The [original training approach](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/nemotron_3_5/README.md#original-training-approach)
explains initialization and which preparation steps the examples leave to you.
The Nemotron 3 text distillation example covers a separate, text-only workflow.

For second-stage relevance scoring, refer to
[Nemotron 3.5 Rerank](/model-coverage/reranking-models/nvidia/Nemotron-3.5-Rerank).
