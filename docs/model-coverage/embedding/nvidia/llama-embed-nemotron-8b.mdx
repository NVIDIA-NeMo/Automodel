[`nvidia/llama-embed-nemotron-8b`](https://huggingface.co/nvidia/llama-embed-nemotron-8b)
is NVIDIA's text embedding model for dense retrieval. It uses a Llama backbone
with bidirectional attention. NeMo AutoModel loads the embedding model through
`NeMoAutoModelBiEncoder`.

## Training Workflow

The [Llama Embed Nemotron 8B training example](/recipes-e2e-examples/retrieval-base-models#llama-embed-nemotron-8b-training-example)
initializes from `meta-llama/Llama-3.1-8B` and trains on the configured Nemotron
retrieval dataset subsets. The guide includes data preparation and the launch
command. This example trains from base weights; it does not load the released
NVIDIA embedding checkpoint.

For continued training, preserve the released checkpoint's tokenizer, pooling,
normalization, and query and passage formatting. Refer to the
[retrieval fine-tuning guide](/recipes-e2e-examples/retrieval-finetune) for the
training and export workflow.
