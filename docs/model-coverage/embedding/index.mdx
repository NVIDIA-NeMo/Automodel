## Introduction

Embedding models transform text or images into dense vector representations that power semantic search, dense retrieval, retrieval-augmented generation (RAG), and classification tasks. NeMo AutoModel includes custom bidirectional backbones and configures supported Hugging Face `AutoModel` backbones with non-causal attention for retrieval training.

For cross-encoder pairwise scoring, see [Reranking Models](/model-coverage/reranking-models/overview).

Embedding models use bi-encoders to produce dense representations for queries and documents independently. They are the standard path for embedding generation and first-stage dense retrieval.

## Train from a Base Model

To create a custom embedding model from Llama or Ministral weights, follow
[Train Retrieval Models from Base Checkpoints](/recipes-e2e-examples/retrieval-base-models).
The guide separates the starting checkpoint, retrieval task, and resulting model.
Base checkpoints remain documented under language and vision-language model coverage.

The retrieval implementations include `LlamaBidirectionalModel`, `LlamaNemotronVLModel`,
stock Hugging Face `Ministral3Model`, and multimodal `Mistral3BidirectionalModel`.
The legacy `Ministral3BidirectionalModel` remains available for existing checkpoints.
Refer to the [backbone reference](/recipes-e2e-examples/retrieval-base-models#backbone-reference)
for attention selection, text-tower extraction, and Hugging Face fallback behavior.

## Supported Workflows

- **Fine-tuning (Bi-Encoder):** Contrastive learning on query-document pairs to produce embedding models
- **LoRA/PEFT:** Parameter-efficient fine-tuning for embedding backbones
- **ONNX Export:** Export trained embedding models for deployment (case-by-case, model-dependent)

## Dataset

Retrieval fine-tuning requires query-document pairs: each example is a query paired with one positive document and one or more negative documents. Both inline JSONL and corpus ID-based JSON formats are supported. See the [Retrieval Dataset](/datasets/retrieval-dataset) guide.
