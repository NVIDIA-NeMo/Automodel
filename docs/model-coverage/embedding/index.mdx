Embedding models encode queries and documents independently into vectors for semantic search
and first-stage retrieval. Fine-tune a released model to adapt these representations to your data.
For joint query-document scoring, refer to [Reranking Models](/model-coverage/reranking-models/overview).

## Fine-Tune an Embedding Model

Follow the [Embedding and Reranking Fine-Tuning Guide](/recipes-e2e-examples/retrieval-finetune)
for data preparation, configuration, training, and checkpoint export. Preserve the checkpoint's
tokenizer, pooling, normalization, and query and document formatting when adapting a recipe.

These resources cover additional workflows:

- [Nemotron embedding recipe](https://github.com/NVIDIA-NeMo/Nemotron/tree/main/docs/nemotron/embed):
  data preparation, fine-tuning, evaluation, and deployment from your document corpus.
- [Nemotron 3 text distillation](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/distillation/README.md):
  continue training the released 1B student with an 8B teacher.
- [Nemotron 3.5 multimodal examples](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/nemotron_3_5/README.md):
  fine-tune the released 8B embedding model's vision components.

Choose a checked-in configuration for these released checkpoints:

| Configuration | Fine-Tuning Workflow |
| --- | --- |
| [nemotron3_embed_1b_distill.yaml](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/distillation/nemotron3_embed_1b_distill.yaml) | Continue text distillation from Nemotron 3 Embed 8B into the released 1B student. |
| [embed_8b_multimodal.yaml](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/nemotron_3_5/embed_8b_multimodal.yaml) | Adapt Nemotron 3.5 Embed 8B vision components with a frozen language model. |
