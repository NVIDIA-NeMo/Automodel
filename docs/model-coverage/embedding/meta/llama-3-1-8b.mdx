[`meta-llama/Llama-3.1-8B`](https://huggingface.co/meta-llama/Llama-3.1-8B) is the
base checkpoint configured by the retrieval recipe below. The recipe trains a
retrieval model from that checkpoint; it does not initialize from an NVIDIA
Nemotron embedding or reranking checkpoint.

## Fine-Tune Llama-3.1-8B

Follow the [installation instructions](/get-started/installation), accept the
checkpoint publisher's access terms, and run from the repository root:

```bash
uv run automodel examples/retrieval/bi_encoder/llama_embed_nemotron_8b/llama_embed_nemotron_8b.yaml --nproc-per-node 8
```

The [recipe configuration](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/bi_encoder/llama_embed_nemotron_8b/llama_embed_nemotron_8b.yaml)
defines the dataset, attention mode, pooling, optimizer, and checkpoint settings.
Validate training and memory use on your hardware before scaling the workload.
