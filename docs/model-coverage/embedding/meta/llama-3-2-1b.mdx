[Llama-3.2-1B](https://huggingface.co/meta-llama/Llama-3.2-1B) has a checked-in NeMo AutoModel recipe for feature extraction.
The Hugging Face configuration declares the `LlamaForCausalLM` architecture.

## Quick Start

### Fine-Tune Llama-3.2-1B

Follow the [installation instructions](/get-started/installation), then run the recipe from the repository root:

```bash
uv run automodel examples/retrieval/bi_encoder/llama3_2_1b.yaml --nproc-per-node 8
```
