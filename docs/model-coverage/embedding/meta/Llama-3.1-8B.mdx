[meta-llama/Llama-3.1-8B](https://huggingface.co/meta-llama/Llama-3.1-8B) is the checkpoint used by the NeMo AutoModel bi-encoder training recipe below.

## Quick Start

Follow the [installation instructions](/get-started/installation), prepare the [recipe data](#recipe-setup), and launch from the repository root on eight GPUs. Validate memory use for your hardware.

```bash
uv run automodel examples/retrieval/bi_encoder/llama_embed_nemotron_8b/llama_embed_nemotron_8b.yaml --nproc-per-node 8
```

### Recipe Setup

The checked-in configuration uses FSDP2 with tensor and context parallel sizes of one. It selects `meta-llama/Llama-3.1-8B` directly for bi-encoder training. The language-model checkpoint is adapted with average pooling and noncausal attention for embedding training; it is not the pretrained NVIDIA embedding checkpoint. Download and prepare the local JSON datasets listed in `dataset.data_dir_list` before launching.

Checkpoint dimensions and the rounded tensor count come from the revision-pinned sources below. The checkpoint context limit is separate from the training sequence length configured by the recipe.
