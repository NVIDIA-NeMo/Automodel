[Nemotron-3.5-Rerank-8B-BF16](https://huggingface.co/nvidia/Nemotron-3.5-Rerank-8B-BF16)
scores each text query together with a document containing an image, text, or both.
It combines a Pixtral vision encoder, a bidirectional Ministral3 language model,
and a scoring head. Higher output logits indicate greater relevance.

## Model Reference

### Model Architecture

| Property | Value |
| --- | --- |
| **Architecture** | `Mistral3ForSequenceClassification` |
| AutoModel Backbone | `Mistral3VLBidirectionalForSequenceClassification` |
| Task | Multimodal reranking |
| AutoModel Wrapper | `NeMoAutoModelCrossEncoder` |
| Inputs | A text query paired with an image, text, or combined image-text document |
| Output | One relevance logit per query-document pair |

## Fine-Tuning

The [8B multimodal reranking example](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/nemotron_3_5/rerank_8b_multimodal.yaml)
updates all model parameters with listwise cross-entropy, including the language
model. It loads the released NVIDIA checkpoint, including its trained scoring
head, vision encoder, and projector.

Follow the [fine-tuning README](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/nemotron_3_5/README.md)
for the dataset format, dependencies, and launch command. This workflow adapts
the released model to your data. It does not require an intermediate text-trained
checkpoint or reproduce the original training pipeline.

## Original Training Approach

Training first adapts a Ministral 3 8B backbone for text reranking, then continues
from that reranker checkpoint on image and combined image-text data.
The [original training approach](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/retrieval/nemotron_3_5/README.md#original-training-approach)
explains this initialization and which stages the examples do not provide.

The [model card](https://huggingface.co/nvidia/Nemotron-3.5-Rerank-8B-BF16)
documents inference, input formatting, training data, and evaluation. For
first-stage candidate retrieval, refer to
[Nemotron 3.5 Embed](/model-coverage/embedding-models/nvidia/Nemotron-3.5-Embed).
