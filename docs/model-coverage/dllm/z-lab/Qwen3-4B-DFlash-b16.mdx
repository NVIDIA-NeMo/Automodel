[Qwen3-4B-DFlash-b16](https://huggingface.co/z-lab/Qwen3-4B-DFlash-b16) is a diffusion draft model trained against a frozen Qwen3 target for speculative decoding.

## Quick Start

After [installing NeMo AutoModel](/get-started/installation), run this eight-GPU example from the repository root to fine-tune the draft model on Tulu-3 while keeping `Qwen/Qwen3-4B` frozen:

```bash
uv run torchrun --nproc-per-node=8 nemo_automodel/recipes/dllm/train_ft.py \
  -c examples/dllm_sft/dflash_sft.yaml
```

## Model Context

Qwen3-4B-DFlash-b16 is used for diffusion draft-model training. Its model size is 537.4M checkpoint parameters.

| Property | Value |
|---|---|
| **Task** | Diffusion Draft-Model Training |
| **Architecture** | `DFlashDraftModel` with Hugging Face `trust_remote_code` |
| **Target** | `Qwen/Qwen3-4B` |
| **HF Org** | [z-lab](https://huggingface.co/z-lab) |
| Parameters | 537.4M checkpoint parameters |
| Decoder Layers | 5 |
| Hidden Size | 2,560 |
| Attention | 32 attention heads / 8 key-value heads |
| Context Length | 40,960 tokens (checkpoint configuration) |
| Vocabulary Size | 151,936 |
| Configured Dtype | `bfloat16` |

### Recipe Notes

The recipe uses fully sharded data parallelism (FSDP2), `bfloat16` model weights, and a training sequence length of 3,072 tokens. The 40,960-token value above comes from the checkpoint configuration.

See the [dLLM Fine-Tuning Guide](/recipes-e2e-examples/dllm-fine-tuning).
