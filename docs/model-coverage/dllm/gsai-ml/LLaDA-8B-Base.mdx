[LLaDA](https://huggingface.co/GSAI-ML/LLaDA-8B-Base) is a diffusion language model that generates text through iterative masked-token denoising.

## Quick Start

After [installing NeMo AutoModel](/get-started/installation), run the full fine-tuning recipe from the repository root. This example uses eight GPUs:

```bash
uv run automodel --nproc-per-node=8 examples/dllm_sft/llada_sft.yaml
```

## Model Context

LLaDA-8B-Base is used for diffusion language modeling. Its model size is 8B parameters.

| Property | Value |
|---|---|
| **Task** | Diffusion Language Modeling |
| **Architecture** | `LLaDAModelLM` with Hugging Face `trust_remote_code` |
| **Parameters** | 8B |
| **HF Org** | [GSAI-ML](https://huggingface.co/GSAI-ML) |
| Decoder Layers | 32 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 126,464 |
