[LLaDA2.1-mini](https://huggingface.co/inclusionAI/LLaDA2.1-mini) is a mixture-of-experts (MoE) diffusion language model supported through its Hugging Face remote-code implementation.

## Quick Start

After [installing NeMo AutoModel](/get-started/installation), run this full fine-tuning example on eight GPUs from the repository root:

```bash
uv run automodel --nproc-per-node=8 examples/dllm_sft/llada2_sft.yaml
```

## Model Context

The checkpoint configuration defines the following architecture settings.

| Property | Value |
|---|---|
| **Task** | Diffusion Language Modeling (MoE) |
| **Architecture** | `LLaDA2MoeModelLM` with Hugging Face `trust_remote_code` |
| **Hugging Face Organization** | [inclusionAI](https://huggingface.co/inclusionAI) |
| Parameters | 16.26B checkpoint parameters |
| Decoder Layers | 20 |
| Hidden Size | 2,048 |
| Attention | 16 attention heads and 4 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 157,184 |
| Experts | 256 routed experts and 1 shared expert; 8 routed experts selected per token |
| Configured Dtype | `bfloat16` |
