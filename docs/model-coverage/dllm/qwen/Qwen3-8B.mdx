The Introspective Diffusion Language Model (I-DLM) recipe converts the autoregressive [`Qwen/Qwen3-8B`](https://huggingface.co/Qwen/Qwen3-8B) checkpoint into a diffusion language model using an all-masked block-diffusion objective.

## Quick Start

After [installing NeMo AutoModel](/get-started/installation), run this example from the repository root on one node with eight GPUs:

```bash
uv run torchrun --nproc-per-node=8 nemo_automodel/recipes/dllm/train_ft.py \
  -c examples/dllm_sft/qwen3_8b_idlm.yaml
```

## Model Context

Qwen3-8B is used for diffusion language modeling. Its model size is 8B parameters.

| Property | Value |
|---|---|
| **Task** | Diffusion Language Modeling |
| **Architecture** | `Qwen3ForCausalLM` with the I-DLM objective |
| **Parameters** | 8B |
| **Hugging Face Organization** | [Qwen](https://huggingface.co/Qwen) |
| Decoder Layers | 36 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads / 8 key-value heads |
| Context Length | 40,960 tokens (checkpoint configuration) |
| Vocabulary Size | 151,936 |
| Configured Dtype | `bfloat16` |
