[Nemotron-Labs-Diffusion](https://huggingface.co/nvidia/Nemotron-Labs-Diffusion-8B-Base) is NVIDIA's 8B diffusion language model. Use the recipes below to adapt it to instruction-following conversations through full supervised fine-tuning or LoRA.

## Quick Start

Run full-parameter supervised fine-tuning on `allenai/tulu-3-sft-mixture` using eight GPUs. The recipe combines diffusion and autoregressive training losses and saves checkpoints under `dllm_checkpoints/nemotron_labs_diffusion_sft/`. Launch from the repository root:

```bash
uv run automodel --nproc-per-node=8 examples/dllm_sft/nemotron_labs_diffusion_sft.yaml
```

## Model Context

Nemotron-Labs-Diffusion-8B-Base is used for diffusion language modeling. Its model size is 8B parameters.

| Property | Value |
|---|---|
| **Task** | Diffusion Language Modeling |
| **Architecture** | `NemotronLabsDiffusionModel` with Hugging Face `trust_remote_code` |
| **Parameters** | 8B |
| **HF Org** | [nvidia](https://huggingface.co/nvidia) |
| Decoder Layers | 34 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads / 8 key-value heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 131,072 |
| Configured Dtype | `bfloat16` |
