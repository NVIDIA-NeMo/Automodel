[Nemotron-Labs-Diffusion](https://huggingface.co/nvidia/Nemotron-Labs-Diffusion-8B-Base) is NVIDIA's 8B diffusion language model. Use the recipes below to adapt it to instruction-following conversations through full supervised fine-tuning or low-rank adaptation (LoRA).

## Quick Start

Run full-parameter supervised fine-tuning on `allenai/tulu-3-sft-mixture` using eight GPUs. The recipe combines diffusion and autoregressive training losses and saves checkpoints under `dllm_checkpoints/nemotron_labs_diffusion_sft/`. Launch from the repository root:

```bash
uv run automodel --nproc-per-node=8 examples/dllm_sft/nemotron_labs_diffusion_sft.yaml
```

## Model Context

The following properties describe the pretrained Nemotron-Labs-Diffusion-8B-Base checkpoint used by these recipes.

| Property | Value |
|---|---|
| **Task** | Diffusion Language Modeling |
| **Architecture** | `NemotronLabsDiffusionModel` with Hugging Face `trust_remote_code` |
| **Parameters** | 8B |
| **Hugging Face Organization** | [nvidia](https://huggingface.co/nvidia) |
| Decoder Layers | 34 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads and 8 key-value heads |
| Context Length | 4,096 tokens (checkpoint configuration) |
| Vocabulary Size | 131,072 |
| Configured Dtype | `bfloat16` |

### Recipe Notes

Both recipes set `dataset.seq_length: 8192`, while the checkpoint configuration sets `max_position_embeddings: 4096`. See the [dLLM Fine-Tuning Guide](/recipes-e2e-examples/dllm-fine-tuning) for training configuration details.
