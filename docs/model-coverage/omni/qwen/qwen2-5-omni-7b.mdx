[Qwen2.5-Omni-7B](https://huggingface.co/Qwen/Qwen2.5-Omni-7B) has a checked-in NeMo AutoModel recipe for any to any.
The Hugging Face configuration declares the `Qwen2_5OmniModel` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation). From the repository root, use 8 GPUs. Complete the [recipe setup](#recipe-setup) before launching.

```bash
uv run automodel examples/audio_finetune/qwen2_5_omni_asr/ami_sft_7b.yaml --nproc-per-node 8
```
