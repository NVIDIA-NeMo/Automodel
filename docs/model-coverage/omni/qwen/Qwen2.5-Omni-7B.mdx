[Qwen2.5-Omni-7B](https://huggingface.co/Qwen/Qwen2.5-Omni-7B) has a NeMo AutoModel recipe for fine-tuning its Thinker component for English speech recognition on the AMI meeting corpus.
The Hugging Face configuration declares the `Qwen2_5OmniModel` architecture.

## Quick Start

Follow the [installation instructions](/get-started/installation) and [recipe setup](#recipe-setup). From the repository root, launch speech recognition fine-tuning on AMI. This example uses one node with 8 GPUs.

```bash
uv run --extra all automodel examples/audio_finetune/qwen2_5_omni_asr/ami_sft_7b.yaml --nproc-per-node 8
```

## Model Context

NeMo AutoModel fine-tunes Qwen2.5-Omni's Thinker for audio-to-text transcription. The dimensions below describe Thinker's text decoder; the parameter count covers the full upstream checkpoint, including Talker and speech waveform generation components.

| Property | Value |
| --- | --- |
| Task | English speech recognition (audio to text) |
| **Architecture** | `Qwen2_5OmniModel` |
| Parameters | 10.73B across the full upstream checkpoint, including speech generation components |
| Decoder Layers | 28 |
| Hidden Size | 3,584 |
| Attention | 28 attention heads and 4 key-value heads |
| Context Length | 32,768 tokens (checkpoint configuration) |
| Vocabulary Size | 152,064 |
| Configured Dtype | `bfloat16` |

### Configuration

| Setting | Configuration |
| --- | --- |
| Hardware | 8 GPUs in the launch example; GPU model not specified in the recipe |
| Strategy | Fully Sharded Data Parallel (FSDP2); `tp_size=1`, `pp_size=1`, `cp_size=1` |
| Nodes | 1 in the launch example |
| Features | Checkpoint saving (`enabled=true`), activation checkpointing (`activation_checkpointing=true`) |
| Backend Settings | `attn: sdpa`, `linear: te` (Transformer Engine) |

### Recipe Setup

The launch command enables the `all` extra, which includes `cuda` for Transformer Engine, `vlm` for audio decoding with `soundfile`, and `cli` for the launcher. Use the [installation instructions](/get-started/installation) to prepare the environment.

The recipe loads pretrained weights from `Qwen/Qwen2.5-Omni-7B` and the `train` split of `edinburghcstr/ami`, configuration `ihm`, from Hugging Face. It uses 16 kHz audio and filters clips shorter than one second. Ensure the environment can download both the checkpoint and dataset.

### Workflow Notes

The [recipe](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/audio_finetune/qwen2_5_omni_asr/ami_sft_7b.yaml) trains Thinker's audio tower and language model while freezing its vision tower. It sets a global batch size of 64 and a local batch size of 8. Checkpoint saving is enabled under `result/checkpoints/qwen2_5_omni_asr_ami_7b`.
