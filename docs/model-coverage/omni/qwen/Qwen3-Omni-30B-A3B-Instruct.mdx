[Qwen3-Omni](https://qwenlm.github.io/blog/qwen3/) is Alibaba Cloud's omnimodal model supporting text, image, audio, and video inputs in a single unified architecture with a MoE language backbone. NeMo AutoModel supports supervised ASR fine-tuning of its audio-capable Thinker stack.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

From the repository root, run:

```bash
uv run automodel --nproc-per-node=8 examples/vlm_finetune/qwen3/qwen3_omni_moe_30b_te_deepep.yaml
```

## Model Context

Qwen3-Omni-30B-A3B-Instruct is used for omnimodal (text/image/audio/video). Its model size is 30B total / 3B active parameters.

| Property | Value |
| --- | --- |
| Task | Omnimodal (Text/Image/Audio/Video) |
| **Architecture** | `Qwen3OmniForConditionalGeneration` |
| Parameters | 30B total / 3B active |
| Hugging Face Organization | [Qwen](https://huggingface.co/Qwen) |
| Decoder Layers | 48 |
| Hidden Size | 2,048 |
| Attention | 32 attention heads / 4 key-value heads |
| Context Length | 65,536 tokens (checkpoint configuration) |
| Vocabulary Size | 152,064 |
| Experts | 128 routed / 8 selected per token |
| Configured Dtype | `bfloat16` |
