[HunyuanVideo 1.5](https://huggingface.co/hunyuanvideo-community/HunyuanVideo-1.5-Diffusers-720p_t2v) is an 8.3B-parameter text-to-video diffusion model from the Hunyuan community, supporting 720p resolution video generation with flow matching training.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

Prepare a HunyuanVideo cache using [Dataset Preparation](/datasets/diffusion-dataset). In `examples/diffusion/finetune/hunyuan_t2v_flow.yaml`, set `data.dataloader.cache_dir` to the cache and `checkpoint.checkpoint_dir` to your output directory.

From the repository root, run full fine-tuning with eight GPUs:

```bash
uv run torchrun --nproc-per-node=8 \
  examples/diffusion/finetune/finetune.py \
  -c examples/diffusion/finetune/hunyuan_t2v_flow.yaml
```
