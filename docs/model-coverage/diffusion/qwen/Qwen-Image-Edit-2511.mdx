[Qwen-Image-Edit-2511](https://huggingface.co/Qwen/Qwen-Image-Edit-2511) has a checked-in NeMo AutoModel recipe for image to image.

## Quick Start

Follow the [installation instructions](/get-started/installation), then complete the
[preparation steps](#prepare-for-fine-tuning). From the repository root, launch full fine-tuning
on eight GPUs on one node:

```bash
uv run torchrun --nproc-per-node=8 \
  examples/diffusion/finetune/finetune.py \
  -c examples/diffusion/finetune/qwen_image_edit_2511_flow.yaml
```

## Model Context

Qwen-Image-Edit-2511 is used for image to image. Its model size is 20.43B checkpoint parameters.

| Property | Value |
| --- | --- |
| Task | Image to image |
| Parameters | 20.43B checkpoint parameters |
| Transformer Blocks | 60 |
| Hidden Size | 3,072 |
| Attention | 24 attention heads |
| **Architecture** | `QwenImageTransformer2DModel` |

### Prepare for Fine-Tuning

Install the `diffusion` and `diffusion-media` extras described in the
[diffusion fine-tuning guide](/recipes-e2e-examples/diffusion-fine-tuning).
Prepare an image-editing cache with the `image-edit` subcommand in
[`preprocessing_multiprocess.py`](https://github.com/NVIDIA-NeMo/Automodel/blob/main/tools/diffusion/preprocessing_multiprocess.py)
and `--processor qwen_image_edit`.
In `qwen_image_edit_2511_flow.yaml`, set `data.dataloader.cache_dir` to the prepared cache directory
and `checkpoint.checkpoint_dir` to your checkpoint output directory before launching training.

### Fine-Tuning Configuration

The fine-tuning recipe declares these example settings:

| Setting | Configuration |
| --- | --- |
| Hardware | 8 H100 GPUs |
| Strategy | Fully Sharded Data Parallel version 2 (FSDP2); `dp_size=8` |
| Nodes | 1 |
| Features | Activation checkpointing; checkpoint saving |
| Advanced | `bfloat16`; native attention |
