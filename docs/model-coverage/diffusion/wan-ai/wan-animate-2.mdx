[Wan-Animate-2](https://huggingface.co/Wan-AI) is a character-animation flow-matching DiT from Wan AI. Given a reference image of a character and a driving video of someone moving, it generates the reference character performing the driving motion. It uses no pose extractor: the driving video is consumed directly, and motion transfers through frame-aligned attention.

## Available Models

Wan-Animate-2 14B is the published checkpoint name. The transformer defined by its [released configuration](https://huggingface.co/Wan-AI/Wan2.2-Animate-2-14B-Diffusers/blob/7d48412d7b903ff3a89f4f5a960d99e1899605a1/transformer/config.json)
has approximately 16.4 billion parameters across 40 layers. The pipeline uses Wan's VAE,
UMT5-XXL text encoder, and CLIP ViT-H image conditioning.

Training is limited to full-parameter and LoRA fine-tuning of the base checkpoint on a single node, from a cached triplet dataset. Tensor parallelism, context parallelism, multi-resolution bucketing, and a per-rank batch larger than one are outside the supported recipe. The 10-step distilled checkpoint is not supported for training. The flow-matching objective regresses the full-trajectory velocity and would erode the step distillation.

The recipe requires `diffusers>=0.40.0` and the current public checkpoint in the released Diffusers format.

## Fine-Tuning

See the [Wan-Animate-2 Fine-Tuning Guide](/recipes-e2e-examples/wan-animate-2) for the triplet dataset format, preprocessing, and launch commands.

<Warning>
For motion-transfer training, avoid using the target clip as its own driving input: the model can
learn a copying shortcut and ignore the reference image, making a low training loss misleading.
Preprocessing warns when both paths identify the same file and continues processing.

</Warning>
