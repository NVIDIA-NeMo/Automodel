[Wan 2.2 T2V-A14B](https://huggingface.co/Wan-AI/Wan2.2-T2V-A14B-Diffusers) is a text-to-video diffusion transformer (DiT) trained with flow matching. Its **two-stage denoising pipeline** uses `transformer` for high-noise timesteps and `transformer_2` for low-noise timesteps, switching at `boundary_ratio * num_train_timesteps` (`boundary_ratio=0.875`). Each transformer has approximately 14 billion parameters.

Set up NeMo AutoModel with the [latest container](https://catalog.ngc.nvidia.com/orgs/nvidia/containers/nemo-automodel) or follow the [installation instructions](/get-started/installation).

## Quick Start

Prepare the cache as described in [Model Context](#model-context), then replace `/path/to/wan22_cache` below. From the repository root, run the high-noise stage on eight GPUs:

```bash
uv run --extra diffusion torchrun --nproc-per-node=8 \
  examples/diffusion/finetune/finetune.py \
  -c examples/diffusion/finetune/wan2_2_t2v_flow.yaml \
  --model.stage=high_noise \
  --data.dataloader.cache_dir=/path/to/wan22_cache \
  --checkpoint.checkpoint_dir=./WAN22_CKPT/wan22_high \
  --fsdp.cpu_offload=true
```

The commands select the `diffusion` extra for model dependencies and `diffusion-media` for OpenCV preprocessing and video export. See [diffusion environment setup](/recipes-e2e-examples/diffusion-fine-tuning#install-nemo-automodel) for source and container installation.

### Fine-Tune Both Denoising Stages

NeMo AutoModel fine-tunes the transformers **one at a time**. Run these commands from the repository root, replacing the example data paths with your own:

1. **Preprocess once** to produce a cached `.meta` set reusable across both stages. Each video directory must contain a `meta.json` file with a list of objects containing `file_name` and `caption` fields for the videos:

   ```bash
   uv run --extra diffusion --extra diffusion-media python -m tools.diffusion.preprocessing_multiprocess video \
       --video_dir /path/to/videos --output_dir /path/to/wan22_cache \
       --processor wan2.2 --caption_format meta_json --caption_field caption \
       --resolution_preset 512p --target_frames 81
   ```

2. **Fine-tune the high-noise stage** (`pipe.transformer`, sigma in [`boundary_ratio`, 1.0]):

   ```bash
   uv run --extra diffusion torchrun --nproc-per-node=8 \
       examples/diffusion/finetune/finetune.py \
       -c examples/diffusion/finetune/wan2_2_t2v_flow.yaml \
       --model.stage=high_noise \
       --data.dataloader.cache_dir=/path/to/wan22_cache \
       --checkpoint.checkpoint_dir=./WAN22_CKPT/wan22_high \
       --fsdp.cpu_offload=true
   ```

3. **Fine-tune the low-noise stage** (`pipe.transformer_2`, sigma in [0.0, `boundary_ratio`]):

   ```bash
   uv run --extra diffusion torchrun --nproc-per-node=8 \
       examples/diffusion/finetune/finetune.py \
       -c examples/diffusion/finetune/wan2_2_t2v_flow.yaml \
       --model.stage=low_noise \
       --data.dataloader.cache_dir=/path/to/wan22_cache \
       --checkpoint.checkpoint_dir=./WAN22_CKPT/wan22_low \
       --fsdp.cpu_offload=true
   ```

4. **Run inference** with both stage checkpoints. Replace each checkpoint path below with a saved `epoch_*_step_*` subdirectory from the corresponding training run:

   ```bash
   uv run --extra diffusion --extra diffusion-media python examples/diffusion/generate/generate.py \
       -c examples/diffusion/generate/configs/generate_wan22.yaml \
       --model.checkpoint_high_noise=/path/to/high_noise_checkpoint \
       --model.checkpoint_low_noise=/path/to/low_noise_checkpoint
   ```

<Note>

The recipe uses Fully Sharded Data Parallel (FSDP2) with eight data-parallel ranks and activation checkpointing. It retains only the active transformer before device placement and sharding. The examples enable `fsdp.cpu_offload` to keep sharded parameters and optimizer state in host RAM.

</Note>
