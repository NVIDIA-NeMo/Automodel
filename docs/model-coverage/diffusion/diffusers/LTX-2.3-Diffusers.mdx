[LTX-2.3](https://huggingface.co/diffusers/LTX-2.3-Diffusers) is a text-to-video diffusion model supported by NeMo AutoModel's flow-matching training recipe.

## Quick Start

Before launching, follow the [Diffusion Fine-Tuning Guide](/recipes-e2e-examples/diffusion-fine-tuning) to install the diffusion dependencies and prepare an LTX-2.3 video and audio cache. In the selected YAML recipe, set `data.dataloader.cache_dir` to that cache and `checkpoint.checkpoint_dir` to your checkpoint output directory.

From the repository root, launch the full fine-tuning recipe on one node with eight GPUs:

```bash
uv run torchrun --nproc-per-node=8 examples/diffusion/finetune/finetune.py \
  -c examples/diffusion/finetune/ltx2_3_t2v_flow.yaml
```

## Model Context

LTX-2.3-Diffusers is used for text-to-video. Its model size is 18.99B checkpoint parameters.

| Property | Value |
|---|---|
| **Task** | Text-to-Video |
| **Architecture** | Diffusion Transformer (Flow Matching) |
| **Hugging Face Organization** | [diffusers](https://huggingface.co/diffusers) |
| Parameters | 18.99B checkpoint parameters |
| Transformer Blocks | 48 |
| Hidden Size | 4,096 |
| Attention | 32 attention heads |
