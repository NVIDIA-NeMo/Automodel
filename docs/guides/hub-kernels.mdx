NeMo AutoModel forwards Hugging Face Transformers' Hub kernel APIs through
`NeMoAutoModel*.from_pretrained` / `from_config`. The same knobs work as in
Transformers ([Loading kernels](https://huggingface.co/docs/transformers/en/kernel_doc/loading_kernels)):

| Setting | What it changes |
|---------|-----------------|
| `attn_implementation: kernels-community/flash-attn2` | Attention only |
| `use_kernels: true` | Non-attention layers (RMSNorm, MLP, Linear, activations, RoPE, fused CE, …) |
| `kernel_config` | Optional per-op Hub mapping (enables `use_kernels`) |
| `allow_all_kernels: true` | Allow Hub repos outside the trusted `kernels-community` org |

You do **not** need `use_kernels` when you only want Hub flash attention.

Requires the [`kernels`](https://huggingface.co/docs/kernels) package
(`kernels>=0.11.0`, matching Transformers).

## Install

```bash
uv sync --extra hub_kernels
# or
uv pip install "nemo-automodel[hub_kernels]"
```

See [Install NeMo AutoModel](/get-started/installation). The `hub_kernels` extra
is not part of `[all]`.

## Attention only

```yaml
model:
  _target_: nemo_automodel.NeMoAutoModelForCausalLM.from_pretrained
  pretrained_model_name_or_path: Qwen/Qwen2.5-7B
  attn_implementation: kernels-community/flash-attn2
```

Also supported (same as Transformers):

- `flash_attention_2` / `flash_attention_3` / `flash_attention_4` — pip `flash-attn`
  when installed, otherwise Hub FA2/3/4 when `kernels` is available.
- Version pins: `kernels-community/flash-attn2@v2.1.0` or
  `kernels-community/flash-attn2@>=2.0,<3.0`.
- Non-`kernels-community` attention repos need `allow_all_kernels: true`.

Example recipe: [`examples/llm_finetune/qwen/qwen2_5_7b_squad_hub_kernels.yaml`](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_finetune/qwen/qwen2_5_7b_squad_hub_kernels.yaml).

## Layer kernels (`use_kernels`)

```yaml
model:
  _target_: nemo_automodel.NeMoAutoModelForCausalLM.from_pretrained
  pretrained_model_name_or_path: Qwen/Qwen2.5-7B
  use_kernels: true
  # AutoModel skips pip Liger when use_kernels is true
  use_liger_kernel: false
```

Defaults come from Transformers' device-aware Hub map (CUDA uses
`kernels-community/liger-kernels` for RMSNorm / MLP / Linear / loss, plus
activation and rotary repos). Override with `kernel_config`:

```yaml
model:
  _target_: nemo_automodel.NeMoAutoModelForCausalLM.from_pretrained
  pretrained_model_name_or_path: Qwen/Qwen2.5-7B
  use_kernels: true
  use_liger_kernel: false
  kernel_config:
    _target_: transformers.KernelConfig
    kernel_mapping:
      RMSNorm: kernels-community/rmsnorm
```

Combine with Hub attention when you want both:

```yaml
  attn_implementation: kernels-community/flash-attn2
  use_kernels: true
  use_liger_kernel: false
```

Hub kernels follow `model.train()` / `model.eval()` (training vs inference
variants). AutoModel training recipes keep the model in train mode.

Benchmark configs:

- [`qwen2_5_7b_hub_kernels.yaml`](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_benchmark/qwen/qwen2_5_7b_hub_kernels.yaml) — attention only
- [`qwen2_5_7b_hub_kernels_layers.yaml`](https://github.com/NVIDIA-NeMo/Automodel/blob/main/examples/llm_benchmark/qwen/qwen2_5_7b_hub_kernels_layers.yaml) — attention + layers

## Native models (`BackendConfig`)

Custom NeMo model factories do not use Hugging Face attention dispatch. For those
paths, set:

```yaml
model:
  backend:
    attn: hub
    hub_kernels:
      attn_repo: kernels-community/flash-attn2
```

Layer replacements for custom models still use top-level `use_kernels: true`.

## What to prefer when

| Goal | Recommended settings |
|------|----------------------|
| Avoid compiling `flash-attn` | `hub_kernels` extra + Hub `attn_implementation` |
| Match Transformers default Hub layers | `use_kernels: true` |
| Pin or remap individual ops | `kernel_config` + `use_kernels: true` |
| TE / DeepEP / TileLang / QuACK | Keep existing `backend:` fields; do not mix TE attention with Hub FA |
| EAGLE ring attention / some VLMs | Still need pip `flash-attn` (direct imports) |

## Limitations

- Transformer Engine attention and Hub flash attention are mutually exclusive.
- Some vision and speculative paths still import pip `flash-attn` directly
  (Kimi VL, BAGEL packed inference, LLaVA-OneVision Rice ViT, EAGLE).
- Scoped CUDA graphs (`backend.cuda_graph`) require `attn: te`, not `hub`.

For offline or reproducible deploys, pin kernels with `kernels lock` and
`kernels download` as described in the [Hugging Face kernels docs](https://huggingface.co/docs/kernels)
and [Transformers loading guide](https://huggingface.co/docs/transformers/en/kernel_doc/loading_kernels).
