Use this page to find where to start with your data. Every NeMo AutoModel training recipe loads its data through a dataset loader named in the recipe configuration. Built-in loaders cover common file formats and Hugging Face Hub datasets, and a recipe can also load data with your own Python code, without changes to NeMo AutoModel.

The guides linked below explain each data format and loader and include configuration examples. To see which Hugging Face datasets the checked-in examples train on, browse the [dataset catalog](#dataset-catalog).

## Find a Data Guide

| Task | Your Data | Start Here |
| --- | --- | --- |
| Language model fine-tuning | Instruction or question-answer records with your own column names, in local JSON or JSONL files or on the Hugging Face Hub | [Column-mapped dataset](/datasets/columnmapped-dataset) |
| Language model fine-tuning | Instruction data that is too large to download first, or that is stored in Delta Lake or Databricks | [Streaming column-mapped dataset](/datasets/columnmapped-iterable) |

## Bring Your Own Data

- **Map your columns.** If your instruction data uses its own field names, the [column-mapped dataset](/datasets/columnmapped-dataset) reads it without new code.
- **Load data with your own code.** A recipe can call a dataset function or class from your own Python file. See custom dataset configuration for [text](/datasets/text-dataset#yaml-based-custom-dataset-configuration) and [multi-modal](/datasets/multi-modal-dataset#yaml-based-custom-dataset-configuration) data.
- **Request a loader.** If a dataset you need is missing, open a [GitHub issue](https://github.com/NVIDIA-NeMo/Automodel/issues) with a short description and an example schema so the team can prioritize support.

## Training Options for Any Dataset

- **Packed sequences** combine variable-length samples to reduce padding and improve throughput. See [packed sequence support](/datasets/text-dataset#packed-sequence-support-in-nemo-automodel), which also covers padding sequence lengths for FP8 training.
- **Validation data** uses a separate dataset and data loader that mirror the training settings.
- **Data loader workers** for vision-language training are selected automatically. See [data loader workers](/datasets/multi-modal-dataset#dataloader-workers) to tune them.
- **Chat templates** format conversations and determine which tokens count toward the loss for chat-formatted data. See the [chat dataset](/datasets/chat-dataset#chat-template-requirements) and [multi-modal dataset](/datasets/multi-modal-dataset#custom-chat-template) guides for template requirements and overrides.
